# 拾趣

**还有剩余的 Codex token？不妨用来读读故事。**

写代码之余，把已有的 Codex 订阅额度用来选故事、改编和配图，让中国古典故事变成自己的插画故事书。macOS 可使用本机已登录的 Codex CLI，无需另配 API 密钥；Windows 使用 Gemini。

从《聊斋志异》《西游记》《庄子》等 24 部作品中挑选故事，选择画风和篇幅，在电脑或手机上阅读，也可以导出 PDF 或一张长图保存。故事、图片和阅读进度保存在你的电脑上。

应用使用单一本地书架，不设用户计费、Token 扣减或生成次数配额。模型输入分块、输出长度、并发和自动重试保护用于保证生成稳定；上游服务的权限、计费和额度仍由提供方决定。

Codex 文本和图片生成共用订阅额度，图片可能消耗得更快；能否生成仍取决于套餐权限和可用配额。

**首次运行从空书架开始。选择一本书，连接生成服务后创作第一篇故事；已有书库中的故事会继续保留。**

## 桌面版入门

### 选择版本

**已有 Node 24、想用 Codex 订阅读故事？推荐 Lite。使用 Gemini，或不想配置 Node？推荐 Standard。** 请选择与你的系统和处理器匹配的桌面安装包。

| 版本     | 推荐给谁                            | 运行环境与生成服务                                                        | Apple Silicon（M 系列）Mac 下载                                                                         | Windows x64 下载 |
| -------- | ----------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | --- |
| Lite     | 已有 Node 24 的 Codex 订阅用户      | 使用电脑上的 Node 24（推荐 24.22.1）；Codex CLI 需自行安装并登录          | [下载 Lite](https://github.com/yysun/shiqu/releases/latest/download/shiqu-lite-macos-arm64.dmg)         | [下载 Lite](https://github.com/yysun/shiqu/releases/latest/download/shiqu-lite-windows-x64-setup.exe) |
| Standard | Gemini 用户，或不想配置 Node 的用户 | 已内置 Node 24；Gemini 需 API 密钥，使用 Codex 时仍需另装并登录 Codex CLI | [下载 Standard](https://github.com/yysun/shiqu/releases/latest/download/shiqu-standard-macos-arm64.dmg) | [下载 Standard](https://github.com/yysun/shiqu/releases/latest/download/shiqu-standard-windows-x64-setup.exe) |

**macOS 两版均支持 Codex 和 Gemini，Windows 两版仅支持 Gemini；Standard 与 Lite 的区别是是否内置 Node。** Node 是拾趣的运行环境，Codex CLI 是可选的 AI 生成工具。两个版本都不包含 Codex CLI；已经能使用 Codex，也不代表电脑上已有 Lite 所需的 Node 24。尚未安装 Node 24 的 Codex 用户，或不确定选哪个时，仍推荐 Standard。使用 Gemini 则不需要 Codex CLI。

macOS 要求 **13.5 或更新版本**。Windows 安装包要求 **Windows 10/11 x64**，需要 WebView2（缺失时安装程序会联网下载），生成服务请选择 Gemini；拾趣的原生 Windows Codex 集成尚未适配。Linux 需要 WebKitGTK 和托盘支持。

Standard 和 Lite 共用设置及故事数据，是替代安装的两个版本，不要同时运行。

### 下载与安装

[最新版本与 SHA-256 校验文件](https://github.com/yysun/shiqu/releases/latest) · [所有版本](https://github.com/yysun/shiqu/releases)。下载链接随最新正式版本自动更新，首次发布成功后生效。提供 Apple Silicon（M 系列）Mac 与 Windows x64 安装包，不提供 Intel Mac、Windows ARM64 或 Linux 安装包。Windows 链接在包含本次改动的正式版本发布后生效；此前可从 Actions 手动构建获取。

安装包**未签名、未经过 Apple 公证**。打开 DMG 后，将应用拖入「应用程序」。首次启动若被 macOS 拦截，请在尝试打开后前往「系统设置 → 隐私与安全性」，按系统提示选择「仍要打开」；只为你信任的下载执行此操作。

Windows：运行 `-setup.exe`，按提示安装到当前用户。安装包未签名，SmartScreen 可能提示风险；仅对确认可信的下载选择「更多信息 → 仍要运行」。Lite 先安装 Node 24（推荐 24.22.1）；未检测到时，在设置中选择 `C:\Program Files\nodejs\node.exe` 或实际安装路径。Windows 的默认设置目录为 `%APPDATA%\com.shiqu.desktop\`，默认故事目录为其中的 `library`。

### 第一次打开

1. 打开拾趣。想先体验阅读，可以跳过 AI 配置。
2. 要制作新故事，进入「设置」，选择并配置下方的生成服务。
3. 点击「保存设置」，再点击「启动服务」（有未保存的更改时显示「保存并启动」）。
4. 点击「在浏览器打开」，开始阅读或制作故事。也可直接输入本机 IP 和端口，无需配对。

桌面窗口用于管理书架、查看生成队列和设置；完整阅读与故事制作在浏览器中进行。关闭桌面窗口后，服务仍在托盘运行；选择「退出拾趣」才会停止服务。

### 配置生成服务

| 方式   | 你需要准备                                                          | 费用与限制                                             |
| ------ | ------------------------------------------------------------------- | ------------------------------------------------------ |
| Gemini | 有效的 Gemini API 密钥，在「设置」中填写                            | 按你的 Gemini 项目计费，需要相应模型权限和配额         |
| Codex  | macOS 本机安装并通过 ChatGPT 账户登录的 Codex CLI，在「设置」中选择 Codex | 使用订阅额度，文本和图片共用额度；需要套餐或工作区支持 |

Codex CLI 不包含在桌面安装包中。首次使用需在终端运行 `codex login`；如果应用找不到它，可在设置中选择可执行文件。模型可留空以使用 CLI 默认值；使用 Sol 时，推理档位建议先选 `low`。Codex 不会回退到 Gemini 或 API 计费，自定义网页来源请改用 Gemini。

「检查连接」只检查访问或登录状态，不生成内容，也不保证实际生成配额。修改提供方、密钥或其他设置前，请先停止服务，保存后重新启动。

**密钥以明文保存在本机设置数据库中，由系统文件权限保护，并非加密存储。** 浏览器和手机无法读取密钥，但可连接服务的设备可以使用生成服务。桌面版不读取项目的 `.env` 文件。

## 在手机上阅读

手机无需安装应用，也不需要单独配置 AI 服务。局域网访问始终开启；互联网访问由你单独启用。

| 访问方式 | 手机所在网络 | 访问链接 |
| --- | --- | --- |
| 局域网（始终开启） | 与电脑处于同一网络 | IP 和端口，无需配对 ID |
| 互联网（默认关闭） | 其他 Wi-Fi 或蜂窝网络 | 免费临时 HTTPS 地址，使用私密链接配对 |

免费的是隧道服务；制作故事仍使用你配置的 Gemini 费用或 Codex 订阅额度。

**同一 Wi-Fi / 局域网：** 启动服务，在「手机接着读」中选择局域网地址并扫码。直接连接电脑的 IP 和端口，无需配对 ID、令牌或 cookie；防火墙需允许此端口。所有可连接设备共享书架和生成权限，HTTP 连接仅限可信网络。

**其他 Wi-Fi / 蜂窝网络：**

1. 在电脑上安装 [Cloudflare cloudflared](https://developers.cloudflare.com/tunnel/downloads/)。macOS 可使用 `brew install cloudflared`。Standard 和 Lite 均需另行安装此工具。
2. 停止拾趣服务，开启「允许互联网访问」。默认自动查找 cloudflared；找不到时填写其可执行文件的绝对路径，例如 `/opt/homebrew/bin/cloudflared`。
3. 保存并启动服务，等待免费隧道连接（最长约 45 秒）。选择「互联网」访问方式，扫描私密二维码，或复制完整私密链接到手机浏览器。
4. 手机自动配对后打开电脑上的同一书架，可阅读、整理和制作故事。无需 Cloudflare 账户或域名。

**完整二维码和链接包含访问凭据，请勿公开分享。** 裸公网地址不会开放书架；完整私密链接可以授予书架和生成权限。打开完整私密链接会自动完成配对；同一书架的访问者共享权限。配对有效期为 12 小时；停止服务后立即失效，重启后需重新扫码。没有多用户隔离。

互联网连接使用 HTTPS，流量经过 Cloudflare，故事数据仍保存在电脑上。免费 Quick Tunnel 每次启动会分配新地址，没有可用性保证，最多支持 200 个并发请求，不支持 SSE；拾趣使用 NDJSON / 轮询。该服务适用于临时访问，不承诺长期在线。隧道进程退出后公网二维码会撤下，局域网继续运行；停止并重启服务可重试。若找不到 cloudflared 或建立隧道失败，仅互联网访问不可用；本机与局域网服务继续运行，「在浏览器打开」仍可使用。升级旧版本不会自动开启互联网访问。

使用期间，**电脑需要保持唤醒，拾趣服务需要保持运行**。关闭互联网访问后，同一网络仍可通过局域网访问。退出应用会停止服务器、隧道和生成进程。

## 制作与阅读故事

### 做一本故事书

1. 选择书目和主题，点击「加入队列并找故事」。书籍、主题和已有制作要求先保存在书架，再由队列提取候选；离开、刷新或重启不会丢失任务。候选批次也会保存，可回看或「再找一批」。
2. 选中候选后准备原文和数量建议，在「制作确认」统一确认故事、画风、画幅数、制作要求及叙事详略；使用推荐画风或自行改选。待选择、待确认时不会生成分镜或图片。
3. 选择「简短 / 适中 / 详细」（默认适中），等待原文保存和插图数量建议。
4. 用滑块或数字调整为 **1–80 幅**，确认后开始生成。1 幅是「单幅概述」；确认前不会生成完整分镜或图片，确认后数量固定。超过 20 幅时先制定全篇提纲，再按每批最多 20 幅编排分镜；每批完成即保存，失败或暂停后复用已保存批次。新生成分镜全部保存后，再结合已核原文和完整分镜，一次生成三个有实际区别的结语候选；候选保存后，由全篇审核显式接收主题和制作要求，对照原文择优：原文决定是否成立，主题参与合格句之间的取舍，不为套题曲解事实或强造反转；记录所选编号与理由，并原样采用该句，不增加单独的择优请求。没有合格候选时才修订所选句，再复核。结语失败只重试结语，不重新编排已保存分镜。之后进入文本队列全篇审片，一起检查分镜的动作、画面、递进、连续性、原文事实，以及结语的立意是否符合完整因果与最终结局、表达是否只是重复情节或人物动机。结语采用独立提示词，生成与审核共享标准：理解必须完整，表达可以简洁抽象；能用于别的生活处境不等于空泛，写入更多故事细节也不等于更有余味。审核会对照全篇尤其是末幅，要求将剧情注解重新提炼为一层认识或感受。审核还会检查是否存在明显更好的结语：有原文依据的意味损失或表达弱化，即使不构成事实错误也可要求改善，但须说明保留什么、改进方向及具体收益；同等成立的另一种读法不触发改写。按需修订问题画幅，每批最多 20 幅；结语有问题则在问题画幅修好后单独重写，再复核全篇。只改结语不触发重绘。审核、修复、复核组成闭环，最多自动修复 3 轮；修复没有实际变化或到上限仍未通过时保留问题、批次进度和历史并停止，可手动继续；审片通过后才开始绘图。旧故事已有完整分镜不自动追加审片调用。
5. 开始制作后自动生成整篇，离开阅读页面也会继续；在生成进度旁使用「暂停生成 / 恢复生成」控制，无需另行开启后台模式。

画风推荐随选题给出，不单独增加模型调用；插图数量建议会增加一次文本请求，分镜后的三个结语候选合用一次文本请求，择优并入原有全篇审核，不额外增加请求。建议会保存在书架，稍后继续无需重复推荐。详略不对应固定幅数，短故事不会强行凑页。

新生成插图按 **9:16 竖幅**构图。Codex 通过提示词请求 864 × 1536；Gemini 请求原生 9:16 / 1K。返回图片只检查格式与尺寸元数据是否有效，不设置分辨率、比例或最低尺寸的拒收门槛，也不裁切、拉伸或补边。手机阅读页在 9:16 范围内等比完整展示原图。后台兼容图片接口的 `IMAGE_SIZE` 默认 `864x1536`；自定义请求尺寸仅按[官方支持规则](https://developers.openai.com/api/docs/guides/image-generation#size-and-quality-options)校验（9:16、宽高为 16 的倍数、最长边不超过 3840 像素、总像素为 655,360–8,294,400），不将请求尺寸用作返回图片的保存门槛。

生成需要联网，速度取决于提供方，快速翻页时仍可能等待。故事默认生成整篇，无需保持阅读窗口打开；正在打开的故事会优先绘制首幅、当前幅及其后 6 幅；服务启动后自动继续未完成任务，新建任务仍需先选择故事并完成制作确认。生成进度旁的「暂停生成」对所有窗口生效，重启后仍保持暂停，只有「恢复生成」才会继续。已经开始的任务仍会完成并保存。删除故事会停止生成，恢复到书架不会自动重启。升级前处于阅读模式的未完成故事会保留进度并暂停，点击「恢复生成」后按整篇继续；已开启后台生成的故事保留原有状态。

阅读设置中的制作要求、画风、幅数和分镜均可修改，提交前显示重做范围。修改保存为独立新版，原版保留；仅改配文或余味时保留原图，画面指令只影响相关幅号，全局画风/人物/制作要求变化则影响全篇。

成功保存的分镜和图片会保留并复用。服务启动后会恢复未暂停故事的排队任务；正常停止服务时进行中的任务会在下次启动时自动恢复，意外中断的任务须等待原有锁到期后恢复。同一任务最多自动运行 3 次，之后需要手动重试。如果提供方已接受请求，但结果尚未保存就发生中断，自动恢复或手动重试可能再次消耗费用或额度。提供方明确返回的失败不会因重启或恢复生成反复重试，请按提示手动重试。图片文件丢失或损坏时，手动重试会重新绘制该幅，可能再次消耗费用或额度；如重绘的是首幅，已完成的画面不会随之更新。手动暂停状态随故事保存。共享同一书库的服务须使用相同版本。

### 阅读和导出

- **翻页**：点击或轻点画面左侧四分之一返回，右侧四分之一前进，中间区域不翻页；也支持滑动、滚轮和翻页箭头。结尾页右侧返回打开故事前的主页或书架。
- **查看内容**：阅读时可以查看原文、分镜和制作说明，也可以收藏故事。阅读进度会保存，删除的故事可以恢复。
- **整理书架**：桌面端和阅读端均可按故事名、原典书名、主题或画风检索，默认按原典书名分组，也可切换不分组。阅读端单篇分组使用横向全宽卡片，右上角可收藏、不再收藏或删除。桌面端删除故事前会确认，删除后可撤销；书架删除状态与阅读端同步。
- **导出 PDF**：全部插图生成后，在「阅读偏好设置」或故事末页导出。
- **一页输出（PNG）**：把全部插图、页码、说明和结尾感悟排成一张总览图，布局随幅数调整。

导出在浏览器本地完成，不会发起新的 AI 请求。当前不提供配音或视频生成。

### 可以读哪些书

内置书库包含 24 部作品，按主题从随应用提供的原文中选题，每批最多推荐五篇来源可核对的完整故事。

| 类别       | 书目                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| 志怪与博物 | 聊斋志异、山海经、搜神记、阅微草堂笔记、子不语、酉阳杂俎、太平广记、博物志 |
| 古典小说   | 西游记、三国演义、红楼梦、水浒传、儒林外史                                 |
| 白话小说   | 喻世明言、警世通言、醒世恒言、初刻拍案惊奇、二刻拍案惊奇                   |
| 诸子典籍   | 庄子、列子                                                                 |
| 历史与策论 | 史记、战国策                                                               |
| 笔记小说   | 世说新语                                                                   |
| 日常生活   | 浮生六记                                                                   |

原文保留原有字符（包括繁体字），改编故事使用简体中文。大部头作品可能按原文顺序分批选题，不保证推荐覆盖全书或是全书最优。原文转录尚未全面校对：《浮生六记》仅收录现存四篇；《史记》十表保存实际表格及空单元格；《战国策》按 Kanripo tls 版的 501 章分段。来源、版本及已知质量问题见 [data/README.md](data/README.md) 和 [data/library/catalog.json](data/library/catalog.json)。

## 数据与备份

故事、图片、原文和阅读进度保存在电脑的「故事数据目录」，手机访问的是同一份数据。可在桌面版「设置」中查看目录；**更换目录只会切换书架，不会自动搬移或合并文件**。

macOS 默认位置：

```text
~/Library/Application Support/com.shiqu.desktop/
├── desktop.sqlite       设置与凭据（包含明文密钥）
└── library/
    ├── shiqu.sqlite     故事、阅读进度与生成记录
    └── media/           图片、已保存原文与缓存
```

备份与恢复：

1. 停止使用这份书架的所有服务，包括桌面版和开发版。
2. 复制整个故事数据目录，包括数据库、可能存在的 SQLite 日志文件和 `media/`。不要只复制数据库，否则会丢失图片。
3. 若要保留设置，另行备份 `desktop.sqlite`；它包含明文凭据，请妥善保管。
4. 恢复时，先停服，将备份放到空目录，再在设置中选择该目录并启动。

不要用一个书架直接覆盖另一个书架。旧开发目录的数据不会自动合并；升级或降级前请先备份，旧版本可能无法显示新版生成的图片。

## 常见问题

**手机扫了码却打不开？** 确认电脑未休眠、服务仍运行。局域网链接要求设备处于同一网络且防火墙允许端口；访客 Wi-Fi 可能隔离设备。跨网络请选择互联网私密链接，重启后重新扫码。新公网域名可能需要等待 DNS 生效；隧道无法连接时检查电脑网络及 cloudflared 安装，也可关闭互联网访问继续使用局域网。

**端口被占用？** 停止服务，在「设置」中换一个端口，再启动。

**没有密钥能用吗？** 首次运行没有内置示例。制作新故事需要可用的 Gemini 密钥或已登录且有额度的 Codex。

**连接检查成功，为什么生成失败？** 登录或模型可访问不代表生成配额充足。请检查账户权限、配额和界面提示；Codex 图片生成可能比文本更快消耗额度。

**Lite 找不到 Node？** 请选择 Node 24 的可执行文件。macOS 的 nvm 用户通常可在 `~/.nvm/versions/node/v24.22.1/bin/node` 找到；桌面应用未必继承终端 PATH。不想配置运行环境可改用 Standard。

**关闭窗口后还在运行？** 这是正常行为。可从系统托盘重新打开窗口、停止服务或退出拾趣。

## 开发者

前端为 React + Vite，后端为 Node REST API，数据使用 Node 内置 SQLite 和本地媒体目录。开发只需 **Node 24.22.1** 与 **pnpm 11.25.0**，无需独立数据库。

```bash
nvm install
nvm use
corepack enable pnpm
pnpm run setup
pnpm dev
```

打开终端打印的本机访问地址；手机使用同一终端中的局域网二维码。默认前端端口为 `3000`，API 为 `3002`。与桌面版同时运行时可用：

```bash
SHIQU_API_PORT=3003 pnpm dev --port 3001
```

开发版从 `.env` 读取 AI 配置，**不读取桌面保存的密钥**。默认书架跟随桌面版的数据目录；可用 `SHIQU_DATA_DIR` 显式覆盖。两端共享书架时均需使用当前版本，两端均无需配对。私有书库及备份不得放入 Vite 的 `public` 目录。

Codex 配置示例（先安装并登录 CLI）：

```bash
pnpm add -g @openai/codex@0.165.0
pnpm run codex:login
pnpm run codex:status
```

```dotenv
SHIQU_AI_PROVIDER=codex
CODEX_MODEL=gpt-6.1-sol
CODEX_REASONING_EFFORT=low
```

文本任务独立分配推理预算：`SHIQU_REASONING_SUGGEST=medium`（选题）、`SHIQU_REASONING_ART=low`（画风）、`SHIQU_REASONING_FRAMES=medium`（画幅数）、`SHIQU_REASONING_OUTLINE=high`（提纲）、`SHIQU_REASONING_PLAN=high`（分镜）、`SHIQU_REASONING_REVIEW=high`（初审/复核）、`SHIQU_REASONING_REPAIR=high`（修订）。结语撰写沿用分镜档位，结语修订沿用修订档位。这些也是缺省值，可逐项覆盖；不自动升档。Codex 支持 low/medium/high/xhigh/max，具体取决于模型和 CLI；Gemini 支持 low/medium/high，不支持值报错，不静默降档。旧 `CODEX_REASONING_EFFORT` 仍用于未分类及图片工具调用，不再覆盖已分类文本任务，也不代表图片质量。已生成步骤不因改档重做；新选题和画风缓存按对应档位隔离。生成检查点用量记录中的 `reasoningEffort` 对 Codex 是线程确认值，对 Gemini 是请求值。

显式真实审核对比（会使用现有 Codex 订阅；普通测试不会运行）：

```bash
pnpm exec node --env-file-if-exists=.env --experimental-strip-types scripts/compare-storyboard-reasoning.mjs --input /absolute/path/to/before-row.json --out .data/evidence/reasoning-comparison --model gpt-6.1-sol --effort medium
```

将 `--effort` 依次改为 high、xhigh，保持相同输入、模型和输出目录。输入为含 `selection`、`document` JSON 字符串的单条故事备份；脚本只审核，输出完整报告、实际档位、输入及请求哈希、用量和耗时，不生成图片、不写书库。成功结果再次运行直接复用；失败单独留档。各档一次只提供案例观察，不代表稳定优劣。

其他变量见 [.env.example](.env.example)，修改后重启服务。无浏览器设备可用 `pnpm run codex:login -- --device-auth`。

常用检查：

```bash
pnpm test
pnpm typecheck
pnpm lint
```

测试使用模拟模型响应，不发起付费生成。桌面 UI 使用 Vite 开发服务器验证；只有需要打包时才运行构建命令。桌面开发、平台依赖和打包说明见 [desktop/README.md](desktop/README.md)。主要代码位于 `client/`（界面）、`lib/`（业务逻辑）、`server/`（HTTP 与存储）、`db/` 与 `drizzle/`（数据库）、`desktop/` 与 `src-tauri/`（桌面版）。
