# 故事修订端到端

1. 完成的本地受控故事：阅读设置中编辑制作要求/画风/画幅数/分镜，保存草稿后有清晰影响；取消/关闭不创建 session 或生成任务。
2. 仅修订中间一幅旁白：提交新版本，展示重新审片、复用全部图片；审片通过后图片字节不变，无 image 调用；可阅读原版且原配文保持。
3. 修改中间一幅提示词：预览只有该幅需重绘；提交后受控队列只绘此幅，先审后画，失败重试不丢其他图。
4. 修改画风：编排保留、重新审片、全部重绘；制作要求/幅数变化：重编排后再审片，幅数确切；多项修改一次提交。
5. 无变化禁用提交，同基线两个不同 requestId 并发仅一个成功，过期修改反馈冲突；同 requestId 相同内容幂等、不同内容拒绝；重编排与手改冲突明确选择，长文本和输入边界有效；小屏无横向溢出。
6. 新版状态页/设置可返回原版，刷新/服务重启后仍可继续新版；分别中断复制/插入/父版暂停/子版激活，不能同时新增付费任务。删除父版不影响新版图片与导出。

REST/队列测试提供受控生产效果的证据；IAB 对真实《大葫芦》只编辑并取消，不实际入队。另以临时受控开发实例验证提交和版本导航。

7. 新队列兼容：新版本引用的复制资产被识别为自己的有效参考；新版生成中移除第一幅或出版结果，只在用户显式重试后重绘该幅，原版状态和文件不变；浏览新版发送 focus、切回原版/关闭结束新版 viewer demand。服务端受控测试证明无自动付费重绘。
8. 提交前已承诺复用的图文件丢失/损坏/无法读取：提交失败、草稿可继续编辑、不产生新版和绘图任务。若改画风导致有意重绘，旧文件不阻碍已明确确认的重绘。
9. 打开新版失败：原版已收藏且停在第2幅，提交配文修订后令新版 GET 暂时失败；恢复到原版第2幅，收藏不变，持久化 progress/favorite 均不被清空，新版仍能在书架找回。
