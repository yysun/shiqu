# 制作定向精简验收场景

使用生产队列、修订、书库初始化、导出和读者入口，数据在隔离目录中。

| 初始条件 | 操作 | 可观察结果 |
| --- | --- | --- |
| 定长 10 幅直接创建和选题已准备，各自有已核原文 | 分别运行至制成 | 新建分别为 4 次、确认后为 3 次文字调用，各绘图 10 次；逐幅产物和审片记录齐全 |
| 定长 25 幅 | 继续至首轮审片；在首批和续批分别重试相同输入，再检查不同画风、人物或前文的回执 | 分镜两批，第二批沿用前文，全 25 幅无漏重号，无独立提纲、人物或画面描述调用；同输入采用一次，不同输入的迟到回执不写回 |
| 已完成 10 幅，有只出现在部分画幅的人物 | 分别只改第 2 幅配文、只改该人物、转换画风 | 配文只复核受影响范围，最多 1 次文字和 1 次绘图；人物仅重绘出现幅；换画风最多 2 次文字和 10 次绘图 |
| 完成作品含手改配文和画面描述，家族中已有同输入的自动产物 | 换画风两次、改人物、清空描述并继续 | 画风转换依次使用上一版手改描述，手改标记保持；配文原样保留；清空后重新生成描述并解除标记 |
| 将被删或重排的幅含手改 | 预览，取消，重试并确认；让自动修订尝试删除该幅 | 预览显示原幅号与具体内容，取消无写入，确认只需一个标志；自动修订停在需读者处理 |
| 0.17 的完成及手改作品、未采用的同输入付费回执，以及格式 1、2、3 库各一份 | 用新版本只读和普通启动；旧格式经 0.17 升级再打开；对完成稿阅读并导出 | 拒绝前后旧格式文件及媒体相同且没有备份。经过 0.17 的库可打开。图片和归档字节、手改标记不变；同输入回执采用一次 |
| 0.17 和新版本各新建一本书库 | 比较 schema、回执与种子；在隔离的新库应用下一次普通迁移 | 两边一致。下一迁移先验证整库备份，原生等待最新回执 |
| 取得授权的五篇样本，含自动幅数短篇、自动幅数长篇和多人物 | 同模型分别运行 0.17 与新实现的生产文字流程，禁用绘图并取首份幅数核对和全面审片回执 | 记录首轮通过率、首次幅数核对及异常，每种指标均达到需求；无绘图 |
