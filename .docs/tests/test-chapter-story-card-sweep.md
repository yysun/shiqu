# 章节卡补齐独立故事验收

1. 整篇卡有多个独立事件。核对后在原章目录看到整篇卡与新增卡，打开新增卡显示其原文范围。选择新增卡准备时保存该范围。
2. 整篇只有一个不可拆的事件。核对完成可报告无需新增，整篇卡保持可用。
3. 模型只返回半段、出处不可读或响应缺少已分配章节。记录对应候选拒绝或待处理，继续其余篇章，完成报告区分原因。
4. 已有整篇卡及独立故事卡，重复检查和合并。卡片身份与原始内容保持，新增卡只出现一次。
5. 相邻章节共同记录一个完整事件。新增跨章卡可在「按故事」查看，选材保存全部必要段落和真实章序。
6. 篇章没有整篇卡。原文全篇可读且本身构成一个故事时，全篇范围可以入库；原文整篇受阻且其中有可选的独立段落时，单独核对该候选范围。重复合并仍只保留一条。
