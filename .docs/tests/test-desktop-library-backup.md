# 桌面书库备份与恢复验收

使用临时书库、备份目录和设置。桌面界面用 `pnpm desktop:preview` 在 in-app browser 核对，原生请求使用实际桌面 Node 协议运行。

1. 当前服务停止或启动失败时，打开本机与存储。可刷新默认备份列表，看到时间、大小、来源与路径，可从列表外选取外置快照。
2. 手动建立默认快照和指定目录快照，校验通过后显示实际路径。书库被其他进程占用时备份失败，可在停止占用服务后重试。丢失或破坏文件后，重新校验报告错误。
3. 取消删除保留快照。确认删除普通快照后只移除该快照。同一备份正被校验或恢复、升级日志仍引用它或安全状态未知时，删除失败，快照仍可读。
4. 将含图文和制作记录的 0024 V1 备份恢复到新目录，确认文案提示 0025。新库格式为 2，选中前原设置保留，显式选择后服务仍未启动。比较源文件及清单，再用匹配 V1 应用还原另一新目录并读取。损坏、目标已存在和迁移失败时，原备份不被改动。
