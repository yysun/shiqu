# 横图套图及试印用户场景

1. 在隔离书库创建有四幅完整工笔竖图的故事。首次启动时选水彩，保存四个横图结果。另绘一套时选水墨。检查每次确认才提交，绘图调用使用该套画风，逐幅失败重试保留该套画风，竖图与设置原样。
2. 重绘第 2 幅竖图，从当前稿选择水彩套图，输出的四幅横图与原套相同，横图新增调用为零。调序后按新页序出图。改写或删减场景后选择原套，验证标记及原套的分镜配文。
3. 水墨套仅保存第 1、3 幅时导出横版与 Letter 双面 PDF。检查第 2、4 幅配文与原位、试印标记、封面依据第 1 或 3 幅、无新绘图以及没有混用水彩图。零幅套图用文字封面，画幅位置依旧保留。
4. 另一套图正在生成时，选择原来的完整一套，实际仍按所选套图下载。通过当前和前序同一故事版本均能获取已授权的历史套图，拒绝其他作品的套图 ID。模拟缺文件与旧格式套图。
5. 在应用内浏览器检查横图步骤、选画风确认、套图选择和缺图封面。除隔离受控环境外只做无写入核查。
6. 隔离复现《画壁》：完整水彩套图之后开始水墨套图并暂停。两套均可见；续跑或正在收尾时删除会被拒绝。收尾后确认删除水墨套图，打印列表和指定 ID 导出都只能读取仍存在的套图，保留水彩图片和竖图。用新画风另绘四幅，检查被删的排队任务从未派发，已完成水彩套图不能从此入口删除。
