# 默认主题更新验收场景

1. 在读者界面打开选题，核对八个预设及顺序，加上「其它」。比较点击「命运与选择」和通过「其它」输入同名文字；记录请求来源及实际送入检索的文本。继续找故事、打开出处并选一篇，确认仍能进入准备环节，保存的 selection.theme 仍为简短主题名。
2. 隔离书库启用本机 Ollama，给验收书目建立故事卡索引。分别查「命运与选择」与「爱与缘分」，观察请求一次提交整条定义，相关卡出现在候选中并有可核对的出处。向量候选只承诺语义相似，相关的反例也可能出现。
3. 用相同原典故事卡关闭向量再查，另以不可用的嵌入服务覆盖回退。通过生产文字模型的故事卡协议，核对「困境影响关键选择」和「只是陷入困境」，以及「两人情意推动情节」和「只是提及婚爱」的正反例。只命中合格的情节；检索不引用梗概外事实。
4. 通过生产建议入口验证相同查询可以复用判断，旧的 OR 判断不能命中新定义。同名自定义不展开定义；在保存且暂停的自选书籍任务中切换同名预设与自定义输入，只有相同来源的候选可恢复；新请求分别传整条定义与原句。旧故事、候选和制作要求可按原数据读取。
