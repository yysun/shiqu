# 轻量书架浏览器验证

- 隔离同一书库快照，以相同浏览器视口、模式和缓存条件，先后刷新旧版与新版书架。记录从导航到故事卡片可见的时间、列表请求耗时和体积。
- 刷新时检查网络无详情读取。打开现有可阅读卡片，检查只读取该篇详情，展示上次位置和完整分镜；重读从第一幅开始。
- 两次未修改的书架轮询之间确认没有完整分镜和重复卡片。模拟隔离任务状态更新，确认只返回变化卡片；模拟新版替换与删除，确认旧卡片不被复活。

## 实测记录

应用内浏览器，同一份 63 条真实书库的 SQLite 和媒体副本，两份生产构建，仅绑定回环地址，制作调度关闭。各刷新三次，导航开始至卡片首次渲染帧，封面图片完成时间单独于此指标。测试脚本只注入隔离构建。

| 指标 | 基线 | 新版 |
| --- | ---: | ---: |
| 首屏样本，毫秒 | 5874 / 3001 / 2901 | 410 / 383 / 360 |
| 首屏中位数，毫秒 | 3001 | 383 |
| 列表响应中位数，毫秒 | 2953 | 349 |
| 列表响应体，字节 | 1919507 | 64888 |

首次展示 63 张卡片时没有单篇详情请求。选择卡片后只读取一次详情，实测 85527 字节、18 毫秒，打开上次读到的第 20 幅。隔离服务无变化的增量响应为 27 字节，实际端口 3000 已返回 63 张摘要卡片。

受控 Chrome 浏览器回归 5 项通过，覆盖启动等待、单篇按需请求、续读及收藏、恢复删除、发现页手势和旧深链接与新点击并发。Playwright 默认 Chromium 缺失，隔离运行指定已安装的 Chrome。

Node 24.22.1 下 typecheck、lint、隔离生产构建通过。首轮影响计划跑完 174 个文件，5 个快层用例通过，1498 个全层用例中 1497 个通过。唯一失败是新摘要模块在会员关系用例的清单中缺少登记，修复后清单测试 4 项全部通过。Rust 格式检查与 25 个库测试通过，按 CI 规则排除依赖发行包的 1 项。
