# 书库服务双向接入

1. 通过 CLI 启动浏览器服务，用同库、另一端口启动桌面 stdin 控制。状态返回原服务 PID 和地址；通过 CLI 写入故事，从原阅读器读取；常规停止释放书库，重新启动获得新服务。
2. 由 CLI 书库命令启动自动工作进程，并夹住一条命令。启动桌面控制，已接收命令正常返回，原 Node PID 和命令地址继续使用，阅读器上线。等待超过原空闲窗口后仍可访问。停止后控制台可重新启动书库。
3. 在另一书库核对行为；摆入旧地址和未通过身份验证的监听者。桌面不向陌生监听者提交设置或管理请求；启动端口冲突时既有 CLI 可继续操作。
4. 通过接入通道停止及立即停止带受控模型任务的服务；等候后正常退出，强停取消请求，并核对下一次启动恢复。确认发出后服务异常清理并退出时，接入端报告失败。暂停前有等待与没有等待的故事分别重启验证。
5. 让桌面接入通道异常断开，原浏览器书架和 CLI 仍可用。重新接入，收到正常停止确认后再断开，原服务仍释放书库。自动工作进程忙时同时发起接入和新命令，已经接受的工作先完成，新请求得到忙状态，接入后可重试。
6. 浏览器通过 IPv6 回环启动时，桌面能使用同端口的本机地址打开书架。自动进程等待已有命令时断开接入，命令能收尾，仍按原策略退出。
7. 桌面接入浏览器 CLI 后，从原终端按 Ctrl-C。步骤保存期间控制台显示正在停止，原服务释放书库后显示已停止。原服务异常退出或桌面桥接意外中断时，控制台显示失败。
