# 独立横图验收

1. 明确发起四幅横图并挂起一幅。保存画风和幅数修订，继续竖图制作。来源横图独立完成；新版无自动横图调用。
2. 横图暂停后继续制作竖图。只有横图步骤的恢复命令解锁横图。服务重启后仍保持各自的状态。
3. 在新版的打印对话框选择旧套图，核对仍使用旧版全部幅序、封面及配文。当前竖图试排仍可用。
4. 恢复已付费可读图片，验证重试没有新增调用。确认原有已完成横图可导出。
5. 在旧流程中启动横图后保存修订。旧版接续需要明确操作，已完成或已付费且恢复可读的画幅无需再次绘制。
6. 发起第二套横图后使用第一套的暂停请求，确认返回冲突。重试某幅时再让另一幅丢失，确认只派发已授权的画幅。
