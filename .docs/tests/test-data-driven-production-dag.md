## 1. 保存后等待继续（场景 13）

- 初始：一篇已完成、一篇正在审片、一篇已暂停的故事。
- 操作：在每篇的修订编辑器改一幅画面描述，点「保存修改」，刷新页面，再点所属步骤内的「继续制作」。
- 结果：保存后三篇都在所属步骤显示「已保存，等待继续」及接续说明；刷新后仍在；点击前新版模型调用数为零；点击后先复核受影响结论，再重绘该幅。

## 2. 保存前预估与只改配文（场景 16）

- 初始：已完成的 12 幅故事，无依赖结语的验收条目；第 1 幅曾被重绘，第 3 幅使用旧首幅参考。
- 操作：打开修订编辑器，手改第 4 幅配文，不勾选「同时更新画面描述」；查看保存前预估，然后保存并继续。
- 结果：预估显示接续点为审片、将失效的图片数为 0、使用旧参考的画幅数为 1；只有一次审片调用；画面描述生成与绘图调用数为零；第 4 幅图片不变。

## 3. 手改处理选项（场景 28、33）

- 操作 A：手改一幅画面描述后换画风，保存。
- 结果 A：保存前提示该处手改，提供「以手改为基准」与「放弃手改」；选择前者后，转换结果仍标为手改。
- 操作 B：手改一幅配文后修改制作要求，保存。
- 结果 B：只提供「放弃这处手改」与「取消本次保存」。

## 4. 无关编辑保留待重绘故障（场景 42）

- 初始：第 2 幅已确认丢图。
- 操作：只改第 20 幅画面描述并保存；重启服务；点「继续制作」。
- 结果：第 20 幅复核并重绘；第 2 幅仍显示待重绘，未被绘制；点「重绘第 2 幅」后才绘制。

## 5. 放行单条结论（场景 18）

- 初始：第 5 幅逐幅结论阻断。
- 操作：放行第 5 幅；随后手改第 20 幅画面描述，保存并继续；再手改第 5 幅画面描述。
- 结果：改第 20 幅后第 5 幅放行仍有效；改第 5 幅后放行失效，第 5 幅需复核。

## 6. 服务故障与模型快照（场景 21、22）

- 操作 A：在设置中移除当前图片服务的密钥，让两篇故事继续绘图。
- 结果 A：两篇显示同一服务故障，没有逐篇步骤故障；恢复密钥后无需逐篇重试即继续。
- 操作 B：一篇确认制作后，在设置中更换图片模型；新建另一篇；再对第一篇点「应用当前模型设置」。
- 结果 B：第一篇在应用前沿用快照模型，新故事使用新模型；应用后已有图片沿用，之后的调用使用新模型。

## 7. CLI 修订语义

- 操作：`stories edit ID --input style.json`，`stories status ID`，`stories continue ID`，`run ID --until completed`。
- 结果：edit 后状态为等待继续、模型调用数为零；continue 后状态为已授权；run 执行接续；重复同一请求标识不产生第二次提交。

## 8. 升级已有书库（场景 38、44–46）

- 初始：复制一份含已完成、绘图中途（含一幅已付费待发布的图片结果）、缺审核记录、旧放行故事的书库到临时目录。
- 操作：用新版本打开，转换过程中重启一次；再用旧版应用打开升级后的书库。
- 结果：升级前生成经核对的整库备份；待发布的图片结果被发布，没有重新绘制；已完成故事保持完成且模型调用数为零；绘图中途的故事从缺失画幅接续；重启后转换结果与一次完成相同；旧版应用拒绝打开该书库。

## 路径审计的范围与结论

从登记表追到读者动作、正式路由、队列领取、产物发布和状态回传。每个用例核对当前版的输入和产物、执行授权、实际任务及界面。循环覆盖首次、继续、耗尽、无进展与解除阻断。批量覆盖 1、20、21、80 幅，另验自动和固定幅数的审核门槛。

检查覆盖登记表的 30 个产物节点、20 类调用与 5 种执行门槛。跨节点依赖和门槛通过无环检查，按画幅展开的首图引用由首幅与后续幅的执行用例检查。新故事主干可到达成品。已经定位的断点涉及等价设置提交、改名回包、运行幅号、有结论及无结论的审核接续、重编后的故障归属和手改画面入画人物。另有历史版恢复、身份重排等设计路径缺少公开入口。公开入口缺失或正式行为不符的路径不计为通过。

| 实现入口 | 核对的分流 |
| --- | --- |
| 选题和制作确认 | 候选查找、换范围、直接原文、合并原文、准备成功或失败、留空和值继承、等待选择、首次确认、旧确认作废 |
| 正式制作 | 原文和事实梗概、人物、提纲、分批叙事、画面描述及画风转换、标题和结语、固定幅数和自动幅数 |
| 审片与修复 | 逐幅与全篇结论、按证据登记、选择结语后二次审核、初审通过、各类局部与结构修订、手改保护、明确放行 |
| 绘图与完成 | 首图参考、并行非首幅、旧图复用、竖图、横图、单幅重绘、首图替换、媒体可读、复制和导出 |
| 编辑和版本 | 只读、展示写入、等价保存、普通修订待继续、替换、历史、并发提交、重复命令、迟到任务与旧版本隔离 |
| 故障和重启 | 内容拦截、服务异常、超时、可重试、修复额度、保留已付费结果、丢图匹配、单幅／批次／条目故障、旧库升级与回滚 |
| 书架、故事设置和阅读器 | 待继续、排队、实际执行、暂停收尾、并行故障、终止、完成，写入回包与轮询的状态一致 |

## 跨路径的不变量

| 路径 | 可执行检查与判定 |
| --- | --- |
| 选题入口 | 分别走候选、直接原文和合并原文。先验证来源与建议，再尝试越权制作。确认前没有正式生成 |
| 批次与幅数 | 对固定 1、20、21、80 幅和自动 21 幅核对分镜、描述、审核门槛及成图。批次幅号唯一，所有产物齐备才完成 |
| 只读与展示写入 | 查看历史、提示词、打开关闭窗口，以及改展示名、署名、收藏、阅读位置。比对版本、授权、任务和调用。阅读报告可调整队列优先级 |
| 同状态的写入响应 | 在途任务挂起时改名或署名。写入回包和即时查询状态一致，计时和按钮不闪回。改名 C013 已复现，署名按同一判定复测 |
| UI 状态优先级 | 待确认、待继续、排队、在途、暂停收尾、故障并行、全部失败、完成分别核对。计时、幅号和操作归同一次实际任务 |
| 审片阻断后可达性 | 对手改、冲突、耗尽、无进展分别验零绘图，再尝试可见的重试、编辑、放行或重编。过期令牌拒绝 |
| 审核调用失败、没有结论 | 原文、完整分镜和结语均就绪时模拟审核请求失败。核对审核步骤的重试与暂停后的人工放行入口。当前故障号授权后保持暂停、零绘图，明确恢复才可绘图；保留跳过记录。稿件不齐或其他步骤失败时拒绝放行。C017 复现当前缺口 |
| 队列与服务故障 | 模拟内容拦截、401、402、429、超时、进程中断、保存失败与丢图。分别核对重试授权、共有故障、退避、次数上限、回执复用 |
| 首图参考与阅读优先 | 分别有书籍参考、本篇首图和旧版参考。换画风等新首图；只重绘首图保留其他图。读到靠后幅时核对实际领取顺序与文案 |
| 预估、保存、继续 | 预估零写入；等价输入没有新版本；普通修订待继续；单幅确认直接派发。核对重放、竞态、晚到及历史版保护 |
| 故障身份 | 单幅、一个多幅批次和一个验收条目各有故障。另改不相关输入时延续到所有正确实例；不可绕过显式授权。新键等待匹配，失败态无孤立旧键 |
| 完成、复制与导出 | 用已完成、旧规完成、未完成和待继续但有旧图的版本核对入口。复制核对所选版本及身份；导出核对当前版完成、图数和媒体可读 |
| 升级、重启与回滚 | 隔离快照停在准备、待确认、部分分镜、待发布、故障、待继续、完成。恢复后比较原文、媒体字节、授权和回执 |
| 设计入口 | 通过公开入口寻找恢复历史版、重排或拆分、同时更新画面描述、编辑绘图参数、恢复审核、按条目放行。记录明确范围取舍、入口缺失或实际拒绝 |
