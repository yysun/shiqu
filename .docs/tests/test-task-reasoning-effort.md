# 按任务推理验收

1. 旧桌面设置无任务字段：读取补推荐默认；保存/重启保持七任务配置和既有密钥；非法任务/档位拒绝且不删除密钥。
2. 同一 Codex runner 连续/并发请求不同档位，分别在子进程 config 和 thread 响应确认；任务配置优先于旧全局，不支持/未采用值拒绝调用；status 无推理。
3. 两提供方七类任务发送对应档位；review/repair/outline/planBatch 的任务来自明确参数。Gemini 不支持的显式值拒绝，不降档；图片调用保持原语义。
4. 选题与画风缓存更改对应任务档位后不能命中另一档位结果；无关任务配置变化不重复通读。
5. 应用内打开 pnpm desktop:preview 的设置页，看到七任务默认配置及提供方允许档位；浏览器预览仍只读，不保存真实设置。
6. 显式运行真实对比脚本，输入为备份原版《大葫芦》；medium/high/xhigh 固定模型、输入、提示且各运行一次，输出经正式 schema 验证。报告有用量/耗时/错误及质量分析，试验前后书库配文、提示和图片哈希一致。
