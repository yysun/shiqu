# 图片保存冲突后的恢复场景

1. 受控故事已保存部分图片，旧 image version 有 queued/failed/正在生成任务；当前 version 继续制作。观察和重试均不得重新运行旧绘图、显示旧失败或用晚到结果覆盖当前图片。
2. 当前 image 已成功，publication 失败且 document 对应位置保存另一个有效 URL。显式重试后恢复进度，不再重复冲突；保存恢复本身不增加图片模型调用，其他已完成页保持原值。
3. 当前真正缺失图片、暂时文件读取失败、手动暂停/停止沿用既有行为；旧任务过滤不得隐式重绘或恢复暂停。
4. 实际阅读重试组件在 publication 失败时显示“重试生成”，解释仅重试保存；按钮仍调用既有显式重试回调。
