# 排队选题端到端

1. 新建选择书籍和主题后点击开始；立即有session及书架条目。受控提取挂起时关闭、刷新再从书架打开，书籍/主题/要求仍在；期间无分镜或绘图。
2. 提取结束显示保存的候选，刷新仍可选择；查看原文/画风建议/再找一批/历史批次；空候选保持可操作的等待态。
3. 选故事后保存原文并推荐幅数；统一制作确认页有故事、画风、幅数、制作要求与详略。仅选故事不生成分镜/图片。
4. 修改画风不重搜；修改要求重新推荐幅数后建议更新；选择另一个故事废弃旧建议。确认准确幅数后进入既有分镜、审片、绘图队列。
5. 并发与丢失响应：同requestId重放不重复，另一generation选择409；旧frame-count/advance不能绕过确认；暂停后不派发新任务。
6. 与修订共同回归：新生成故事可修订并保留原版，新版未完成仍能回到原版；打开目标失败不改原版收藏和阅读进度。
7. 旧世代失败/排队任务：完成一次失败准备后选择另一个故事，旧错误不污染新状态；注入旧queued job不得执行；旧generation结果保存被拒绝。待选择和待确认不能显示已完成，也不能占用文本工作位。
8. 已保存original、plan尚为空时可查看原文；新建与setup动作各自幂等，进度更新不会让创建重放再发起提取。执行顺序先后端门槛、再界面、最后修订整体验证。
9. 审核前两轮报告问题、后续轮通过：应反复定向修复/复核后才绘图。持续问题达到3轮或修复完全无变化时停止并保留历史，手动继续后可通过；暂停/刷新不丢轮数或已保存修订。
10. 40幅问题拆成两批：前20已保存，后20无变化停止；手动继续只请求后20，不重修前20；历史包含无变化尝试，实际审核次数不被手动续跑的job-key递增夸大。
