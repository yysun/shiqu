# 修订横图与恢复验证

1. 完成四幅图并绘制横图。普通修改画风、继续、重启后，横图状态只包含当前有效产物。使用生产 PDF 渲染验证取用竖图，再明确请求新版横图并核对四次调用。
2. 普通重绘单幅后仅该幅横图需要重新授权。读者确认立即重绘单幅时，验证仅对应竖图与横图各绘制一次。
3. 使第三幅横图失败，修改验收条件并重启。提交通用恢复，核对没有新成功回执，第三幅仍可专用重试。模拟旧版误记成功后再次核对专用重试与恢复后的四幅图。
4. 重放旧版保留的空请求、旧失败任务及排队回执。新版启动后只在读者明确发起时可派发，并优先采用同输入且可读的回执。暂时读不出的有效横图不能进入 PDF，也不应仅因此发起重绘。
