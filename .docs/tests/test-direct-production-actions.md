# 制作编辑一步提交验证

1. 暂停绘图，修改单幅分镜，直接选择重新审核。成功后显示重新审核或下一实际步骤。
2. 在分镜剧本中删合或生成梗概，点击提交动作。检查无额外待应用步骤。
3. 已完成故事编辑画风，确认下一步在同一面板执行。打开制作或验收要求、叙事详略，核对提交语义。
4. 首次制作进入设置编辑，点击开始制作。检查按当前设置进入生产。退出已确认前的编辑仍可继续配置。
5. 模拟提交失败。检查编辑面板与输入均保留，错误就地显示，再次提交可继续。遇到版本冲突可在当前面板加载最新状态。
6. 暂停时只重新生成梗概，检查提交按钮明确说明将保存梗概并恢复制作。
7. 在手机宽度修改分镜，检查重新审核是唯一的实心主按钮。点击一次后关闭编辑面板，新版进入审核。
