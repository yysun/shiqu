# 自备书籍导入验收

全部在隔离书库（`--data-dir` 指向临时目录）中执行，使用公版测试文本，不碰用户的真实书库。

1. **TXT 导入到按章节浏览。** 前提：空的隔离书库，一个 GB18030 编码、带「第一回…第五回」标题的 TXT 文件。操作：在新建故事页选「其他 → 导入这本书」，填写书名并确认版权提示，上传文件。结果：结构页显示 5 章，每章有标题、字数和开头文字；确认后书目中出现该书，「按章节」能打开第三回原文，原文与文件内容逐字一致（未做繁简转换）。
2. **结构调整与版次。** 前提：用例 1 的书处于待确认状态。操作：合并第四、五回，删除开头的「目录」章节，然后确认。结果：显示 4 章，段落编号连续；对同一快照重复同样的调整，得到相同的版次。
3. **质量标记。** 前提：TXT 中含有 `□`、私用区字符和「（原缺）」。结果：结构页列出受影响的章节和段落数量，原文显示时保留这些字符；用含这些段落的故事制作时，按现有规则阻止并说明原因。
4. **故事卡生成、取消与续跑。** 前提：用例 2 的书，使用假提供方或真实提供方。操作：打开「生成故事卡」，查看预估后开始，在第 2 章的 provider request 进行中取消，再继续。结果：预估按实际格式化的 cards prompt、payload 和 schema 计算，计划中每个窗口不超过配置预算，并注明 token 为本地估算；取消会 abort 当前请求、等 teardown 完成且不保存该窗口结果；取消后第 1 章的卡仍可在「按故事」中搜到；每张卡梗概说明起因、关键行动和结果，出处覆盖完整故事，跨相邻章节的事件不会被截断；继续后不重新调用第 1 章；全部完成后，「按主题」走模型核对路径，能返回带出处的候选，并能打开正确原文。
5. **向量索引。** 前提：本机 Ollama 有可用的 Embedding 模型。操作：在「我的 → 嵌入模型」为该书建库，用一句白话情节描述做「按主题」查询。结果：显示语义召回，结果出处正确；关闭向量检索后仍能查到结果。
6. **制作与导出。** 操作：选一张导入书的卡制作故事并导出。结果：故事页显示「本地书库 · 用户导入」及来源说明；ZIP 的 `署名与转载.txt` 包含来源与授权说明。
7. **URL 安全与资源上限。** 操作：分别导入 `http://127.0.0.1/…`、重定向到局域网地址的公网 URL、超过 12 MB 的页面、超过 100 个来源或合计 64 MiB 的输入，以及超过整次导入 5 分钟截止时间的慢页面。结果：请求被拒绝并说明失败 URL 或超限类别，书库中没有半成品。
8. **备份恢复。** 操作：备份书库，恢复到另一个隔离目录，从恢复后的书库打开该书。结果：章节、故事卡和向量都可用，无需重新导入；篡改一个原件的字节后，该书显示「不可用」；书目、嵌入设置和 `books imported` 中的其他书照常列出并可使用。
9. **删除与重新导入。** 操作：重新导入相同文件并沿用原结构，然后删除该书。结果：重新导入后旧故事卡仍有效；删除后书目、`books/` 目录、向量库和故事卡中间结果中都没有该书。用它做过的故事仍能阅读原文；从这个故事重选时提示「书已删除」，不调用模型或网页查原文。
10. **「其他」旧任务。** 前提：升级前保存的 `bookId:'other'` 任务。结果：仍能打开、暂停、继续并选择候选；新建时选择「直接请模型推荐」，候选标注「未核对原文」。
11. **CLI。** 按 `skills/shiqu/SKILL.md` 中的命令顺序执行导入、查看和调整结构、确认、预估、生成故事卡、搜索、删除，结果与界面一致。
12. **EPUB 与编码。** 分别导入以下文件：含 `META-INF/encryption.xml` 的 EPUB、单本解压后超过 64 MiB 的 EPUB、合计解压后超过 256 MiB 的多个 EPUB、包内 href 含 `../` 的 EPUB、Big5 编码的 TXT、GB18030 与 Big5 都能解码的短文件。预期：前四个被拒绝且书库不留半成品；Big5 文件正确显示；最后一个提示用户指定编码。
13. **暂停、重试与结构变更。** 故事卡生成到一半时退出应用再启动，该书显示「已暂停」，不会自动续跑。让一章因提供方错误失败，单独重试后只调用这一章。卡片任务在异步预检前立即占用唯一任务槽，第二个并发请求被拒绝。分别在任务预检期间和 provider request 期间开始删除/替换：维护操作必须等待任务收束，期间的新卡片请求被拒绝，不能覆盖新版卡片或进度。重新导入时保留一个原文段落完全相同且唯一的章节、修改另一个章节：未变章节的卡保留并重绑到新版次，变更章节回到待生成；旧版次向量不参与检索，重建后新向量可用。
14. **非古典文本。** 导入一段无标点的现代中文文本。确认页事先提示限制；生成故事卡时，失败章节写明原因，其余章节不受影响。
15. **独立缓存键索引。** 前提：已生成至少一个故事卡窗口，`card-cache-keys.json` 存在。操作：损坏 `card-progress.json` 后删除该书；分别损坏缓存键索引、注入一个缓存删除失败，尝试删除和替换。结果：进度损坏时仍依据独立索引清除所有本书缓存；索引损坏或缓存清理失败时，删除和替换都返回失败并保留原书，替换草稿也保留。
16. **替换崩溃恢复。** 前提：旧书已确认，另有完整有效的替换草稿。操作：分别模拟替换前、旧书改名到 `.book-replace-*` 后、新书移到 `books/<id>` 后的进程退出；再额外模拟新目标无效和待恢复备份无效。重启时触发书库清理。结果：替换前旧书不变；仅有备份时恢复旧书；新目标完整有效时保留新版并清除旧备份；新目标缺失或无效时验证后恢复旧版；待恢复备份无效时保留目录，将该书标为不可用并报错，但其他书仍可列出和读取，不静默删除唯一副本。
