# 连续选题 E2E

前置：隔离数据目录，受控 provider 每次返回一篇不同的故事，延迟下一篇，记录调用数；浏览器使用 in-app browser。

1. 按主题创建选题：首篇显示后无需操作继续出现第二篇；下一篇尚未完成时已有候选可选。
2. 选中首篇：进入准备/制作确认，后续查找停止；释放迟到调用后候选和选择不改变，未确认前不生成画面。
3. 新建选题，首篇出现后关闭界面：释放在途调用，确认没有后续调用；书架停留不启动查找。
4. 重开该选题：已有候选保留，查找继续且不重复已有故事。
5. 返回空结果或模拟失败：停止自动查找，已有候选仍可选择，错误显示重试入口；暂停期间不派发查找。

API/单元补充：两个查看者离开一个继续、最后一个离开停止；断连租约过期停止；选中与自动 more 竞争；缓存逐篇返回及取消后保存进度。
