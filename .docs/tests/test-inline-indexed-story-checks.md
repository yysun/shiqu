# 候选故事就地核对验收场景

1. 用有索引的本地书开始自动选题。阻塞复核响应，确认页面已显示全部召回标题、梗概和核对状态，尚无可选项。缺梗概的旧条目显示标明来源的原文节选。
2. 返回一批含正反判断及贴合度分数的有效原文回执，保留下一批等待。确认每篇的分数显示在本行，列表顺序稳定，匹配项可选。选择后，晚到的旧任务结果不能覆盖所选故事。
3. 在另一轮中断复核，再打开相同选题。确认已发布的状态及可选故事保留，恢复读取缓存后继续核对。
4. 在桌面预览确认状态、数量、梗概和可选按钮直接显示。无索引时确认当前章节和已找到的候选简介同屏。按标题走既有提取路径。
5. 两个选题页共享同一候选批次，第二个在补核过程中打开。确认两个页面都收到已经核对的结果，同时共享同一次补核调用。
