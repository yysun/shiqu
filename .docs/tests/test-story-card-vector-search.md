# 故事卡向量检索验收场景

## Ollama 设置与书库建库

1. 初始条件：隔离的已就绪书库、Ollama 服务运行且已下载一个支持 Embedding 的模型。打开“我的 → 嵌入模型”，输入本地 Ollama 地址并选模型；执行连接测试并保存。预期：显示服务可用、模型身份和维度；设置独立于生成及原文核对模型。
2. 在设置中选择尚未覆盖的《搜神记》并开始建库。预期：可见确定的进度；每条卡只产生标题+梗概向量；卡片都能解析回同版原文出处。
3. 建库途中取消，再重试同一本书。预期：取消书不显示为就绪；重试完成后无重复卡，其他书的索引不变。
4. 修改/替换原文版次或故事卡内容后只更新该书。预期：旧指纹不参与召回，新索引记录只对应当前版次/卡片。
5. 停止 Ollama、选错地址或切换同维度的另一个模型。预期：服务状态可理解；旧向量不被用作新模型查询候选；目录、文字召回仍可用，索引显示待重建。

## 章节、故事和主题

6. 未配置模型时打开选书页，选“章节”并按卷名查找《搜神记》卷十一，打开原文和已有故事卡再返回。预期：能完成，查询/范围/入口保留。
7. 在“故事”入口精确输入《种梨》。预期：唯一精确标题先出现并可直接打开正确出处，不发送 Embedding 请求。
8. 对已建库同一书输入“那个道士当街种梨的故事”。预期：真实请求用所选模型生成查询向量，向量与文字候选合并，正确出处显示在故事候选中。
9. 在“主题”入口搜索未预制说法“求下雨”，默认全书，再选择一章缩小范围。预期：故事卡实时向量、故事卡文字与原文词召回合并、出处去重且最多 50 条；核对候选只来自当前范围，并显示核对进度、匹配依据和可打开出处。
10. 搜索无匹配主题或关闭核对模型。预期：候选显示为未核对，清楚标出范围和下一步；不得宣称已检查完整原文。
11. 对候选未定位的故事/主题点击“继续查找原文”，中途取消一次后继续。预期：显示已读进度和覆盖范围；复用之前已提取故事，不重复已完成批次；只在全部范围读完后显示“已检查完整个所选范围”。无文本模型时说明缺少何种配置。

## 持久化与兼容

12. 保存已完成索引后创建书库备份、在新隔离目录恢复。预期：新书库继续使用匹配模型的向量；模型不兼容时安全回退并提示重建；备份不包含旧官方向量缓存。
13. 在磁盘保留旧手动索引及官方向量包，并构造能命中旧查询参考向量但不命中故事卡的查询。预期：新检索不读取旧查询向量或官方向量；有效可核对故事卡可重新建库，旧文件仍在原处。

## 无本机模型限制

若执行环境无可用 Ollama，使用确定性本地 mock 验证生产 API/存储/召回退路；单独报告真实模型身份验证、延迟与查询质量尚未通过，不能将 mock 结果作为这些指标的证据。

## 原选题页三种检索

进入新建故事并依次切换章节、故事和主题。预期「检索方式」与三个等宽选项同排，且只显示当前方式的输入和结果。章节、故事使用多个关键词筛选。选定主题或填写「其它」中的自定义主题或情节后，点击「开始找故事」，在选题任务中验证主题与情节都用输入文本生成向量，按相似度召回前 50 张卡，直接返回候选，选题不调用文本模型。用 21 张卡验证无向量时模型每批收到 10 张卡的标题和梗概并逐卡返回是或否；第二批命中时只返回命中的卡，无命中时处理最后一张后结束。覆盖无卡、缓存复用和已展示的卡不重复出现。命中、无命中和无卡时都不读取原文。新故事自动拟题，修改提取条件保留已另行设置的故事名。

点击预设「欲望与代价」查询，验证「欲望」「代价」分别嵌入，只命中任一项的卡可以进入结果，两项均召回的卡只显示一次。关闭向量后，确认模型指令允许任一项符合且无需两项之间的关联。通过「其它」手填同样文字，确认保持完整查询。
