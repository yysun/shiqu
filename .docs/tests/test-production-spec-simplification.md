# 制作规范精简验收场景

通过生产初始化、队列、HTTP、CLI 和读者界面执行。使用临时书库、确定性模型替身和可控制的付费回执。记录实际调用、派发顺序、状态和需要读者操作的原因。

| 初始条件 | 操作 | 可观察结果 |
| --- | --- | --- |
| 格式 1、2、3 各有本格式产生的完成、补绘、放行和未完成横图样本；格式 2、3 含等待第二阶段审片的稿件；格式 3 另有可转换与无法转换的残留 v1 稿 | 首次打开；另在迁移写入阶段注入中断再打开；用前版读取升级结果 | 每个样本仅做一次升级备份；迁移期间零模型调用；旧版拒绝打开；失败故事保留原文并显示诊断；可读作品保留原页序、媒体 URL 和 ZIP 条目内容及 WebP 字节；补绘及恢复横图先复用可读结果 |
| 上一版第 2 幅丢图，第 7 幅已发送且结果暂未返回，第 20 幅待手改 | 修改第 20 幅，检查预览并保存，点击继续制作并触发调度，之后才放行第 7 幅的模型回执；分别测试第 7 幅输入一致、不同及已采用新结果 | 预览列出第 2、20 幅且注明丢失；新版没有继承故障或复制图档；同输入的新版等待并免费采用，第 7 幅额外调用为零；不同输入或已采用较新结果时，旧回执不替换新版；历史版保留自己的画幅和故障 |
| 两篇已确认故事有待绘页，另有一篇处于候选查找 | 只打开后排故事各页、关闭阅读器，离开候选选择，再恢复升级前设成阅读模式的故事 | 阅读中的故事优先且按画幅序；关闭后制作继续；离开后没有新候选付费；升级暂停的故事在恢复前零调用 |
| 新稿有至少 30 幅及验收条目，逐幅结论与全篇结论齐备 | 分别改配文、画面描述、次序与人物；让审片回传允许清单外判断；模拟审核失败或在途 | 每轮一次审片；只复核必要的相邻幅与全篇；越界判断丢弃；未知条目阻断绘图；失败时同一放行动作可用，在途不可用，修改对应输入后放行失效 |
| 故事有已绘首幅、手改画幅、重绘说明和不能更改的手改结构 | 分别确认只重绘首幅或同时重绘其余幅，再执行结构修订 | 全量选项等新首幅完成；未选后无标记或提示；仅原样保留的画幅沿用身份和修改；无法保护手改时停在读者处理 |
| 准备期间主动清空一项要求；确认后切换全局文字和图片设置 | 等准备完成、替换选题、确认和继续，最后应用当前模型设置 | 明确清空的值保持；未编辑值采用当前建议；文字立即使用当前全局模型、图片只在应用快照后切换 |
| 有同指纹共享画幅、等待继续、审核失败及绘制故障 | 人为改错摘要、重放同一请求、模拟绘图两次失败与一次成功，并逐个打开故事设置与书架 | 共享推导保持授权和活动一致，重放不新增尝试；成功解除故障；所有处理状态有可操作出口或原因；删除原家族后另一家族的副本仍能导出 |
| 多篇已完成和在产故事已被索引 | 多次触发调度、轮询书架，再仅修改一篇 | 未变化故事不读全文；状态写入和读取一致。命令回执仍可重放，CLI 帮助与技能只描述当前动作 |
