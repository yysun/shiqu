# 暂停编辑与最新版书架 E2E

使用隔离临时 SQLite/媒体目录和受控 provider，不调用真实模型，不修改日常书架。

1. 准备中暂停：已有候选并正在准备原文/推荐；暂停，打开制作要求/画风/幅数，保存草稿；当前调用完成后草稿保留、仍暂停；候选可重新选择。
2. 分镜未完成：已确认制作，阻塞分镜调用；暂停，修改画风/要求/幅数并保存；新版是同族第 2 版且暂停，旧调用完成不会覆盖新设置；重复提交同一请求只有一版；恢复后按新设置完成。
3. 已有图片：原故事部分/全部出图，暂停可编辑；修改画风保留完整分镜，明确继续后重绘；修改幅数/要求重新编排；旧图与旧设置保留。
4. 书架：最新版无图/暂停/失败均只有一张卡片；旧版重新访问不改变选择；独立创建同名故事仍有独立卡片。刷新、重启、搜索、收藏、最近阅读及桌面摘要一致。
5. 删除恢复：删除最新版后旧版不出现；恢复后只显示最新版，收藏及检查点保留，不启动生成。
6. UI：生成前、生成中途、阅读设置均可找到适用编辑入口；保存暂停后的明确恢复控件可见；无历史版本列表；确认制作后重新选故事另开流程。

记录每项的实际观察、测试文件/命令及浏览器会话限制于完成报告。
