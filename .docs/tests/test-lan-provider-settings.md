# LAN 生成设置场景

1. 隔离配置与书库，启动正式 dev/CLI/desktop；从真实私有接口访问设置，读取成功，Profile 显示生成服务与模型。切换提供方、修改文本/图片模型/推理，使用合成密钥保存再读取；运行配置不变并显示重启需求，原生路径不返回。
2. 两个入口读同一修订，先保存一方，再保存另一方；后者明确冲突且不覆盖。密钥保存后输入清空，响应/DOM/日志无已存密钥。
3. LAN peer + 回环或外来 Host、公共 peer + 任何允许 Host、跨站 Origin/fetch-site、无 Origin POST、规范化路径、无/错代理证明均拒绝且无写入。LAN peer + 实际私有 Host + 同源提交成功。不信任 X-Forwarded-For。
4. 桌面私密隧道仍在转发前拒绝设置；LAN 阅读与生成接口保持。仅回环绑定的 CLI 无 LAN 监听，不更改绑定。
5. 浏览器隔离 fixture 经实际 LAN 地址打开 Profile，完成模型保存、重新读取、重启提示与 390px 布局检查；记录会话来源与限制。全程不用真实密钥、不推理、不访问用户书库、不打包。
