# 制作生命周期验收

使用正式应用路由、调度器和队列，书库置于临时目录。脚本通过 Node 测试执行已登记的场景，模型和图片提供方使用可挂起、计数的替身。每个已开放的读者事件覆盖一个接受和一个拒绝场景。系统事件在调度、队列或结果保存入口验证。未提供的动作验证路由仍不可达。需要 UI 核对的场景使用桌面 Vite 预览。

| 场景 | 初始条件与动作 | 观察结果 |
| --- | --- | --- |
| C010 | 某幅正在绘图，提交经规范化后等价的设置 | 返回原版本，仍可运行，租约与调用次数无变化 |
| C011 | 第 2 幅故障，第 5 幅已领取 | 所有界面主显示同一第 5 幅的阶段和计时，另显示第 2 幅待处理 |
| C013 | 有在途绘图，通过改名接口保存，再读详情和书架 | 写入回包与读取得到相同的制作状态、阶段、任务和开始时间 |
| C014 | 自修额度用尽，打开问题列表，编辑意见或另一次运行选择继续自修；重放请求 | 问题关联到结论，编辑被接受；明确授权一次新额度，重放无增量 |
| C015 | 在重编后依次确定不同、相同、相同的硬输入；恢复一个匹配实例 | 每个匹配各有记录，不匹配的图照常付费；恢复只付一次，相同图可读后另一幅免费复用；重启不重建故障 |
| C017 | 稿件齐备，当前审核失败；分别在进行、暂停、停止和等待继续时提交跳过，随后恢复生产或修改绑定输入 | 进行中或故障号过期时拒绝；其余情况下登记结语和跳过证据，无立即绘图；继续后方可绘制，任一绑定输入变更使跳过失效 |
| 并发领取 | 暂停、停止、删除或修订在异步预筛结束到领取之间提交 | 事务中不领取旧任务，付费请求为零 |
| 发送防线 | 每类提供方暂停其付费前准备，期间提交暂停、停止、删除或新版本，再放行准备 | 付费请求为零，任务按原因退回或作废。审计免费请求单独计数；同任务第二次付费前也复核 |
| 迟到结果 | 付费发送之后提交暂停、停止、删除或新版本，再放行结果 | 已付费产物和回执归原版本；无新增未授权任务；恢复删除后维持停止 |
| 图片与服务 | 分别模拟已付费文件暂不可读、必需输入确认不可读、快照不可用或只读 | 暂不可读不消耗尝试次数或重新付费；确认不可读记录目标故障；服务阻断可见并有文档规定的出口 |
| 兼容探针 | 新版写入跳过审核记录、待匹配来源和多幅匹配实例，分别复制书库给 `v0.15.0` 隔离运行，其中至少一幅的身份和指纹在旧版启动后才确定，并包含在旧版运行中使跳过绑定失效的输入变化 | 旧版对新版阻止的工作领取和付费计数均为零；若失败，保存证据并按 REQ 请求单独确认格式升级 |

回归继续覆盖 C008、C009、C012 与现有 DAG 和生命周期套件。规则表测试枚举有限的守卫等价类与事件，每个满足具名约束的组合只能命中一条规则，并在正式实现上执行规则效果。另测多个任务、不同目标和租约到期边界的具体结果。
