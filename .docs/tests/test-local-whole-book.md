# 本地整书选题流程验证

1. 初始：本地 Node 应用与《庄子》《世说新语》书库可用，使用模拟提供方。
   操作：分别为两本书提交主题选题，检查模型输入和返回候选。
   预期：模型收到对应整书全部正文、首尾单元与可用编号；响应仅保留可核对引用，前端显示出处。
2. 初始：已有有效本地候选。
   操作：选择并开启故事，推进一次；分别模拟分镜失败、原文存储失败、正常完成。
   预期：核对与保存先于分镜；失败后原文保留；重试不再选题、不调用公共书籍来源，图片按现有流程生成。
3. 初始：有效候选引用。
   操作：改成其他书/不存在篇章/倒序范围/其他版本/含私用区字形的单元；或提交无引用的旧缓存选题。
   预期：明确拒绝，零分镜、零插画、零远程书籍查询。换书/主题/批次后旧引用不会随新选择提交。
4. 初始：已有完成故事或旧版只有分镜的故事。
   操作：回看原文，或补全可确定的《庄子·齐物论》章节。
   预期：完成故事复用已保存文本；旧版补全仅用本地已确认章节，不重新生成、不发公共来源请求。
5. 初始：真实现有模型配置可用。
   操作：以《庄子》一个主题请求候选，核对原文后仅执行一次分镜文本生成；再在内置浏览器验证候选出处显示。
   预期：候选真实映射本地内容；计划保存相同原文，尚未调用图片生成。若提供方配置、配额或网络阻断，记录模拟验证与真实验证的区别。
6. 初始：资料已整理、生产构建完成。
   操作：校验 24 本原件哈希，两本运行时正文的原文字形、完整篇/则数；检查 Git 待提交范围、生产服务的应用 root 与独立运行数据目录、Docker COPY 边界。
   预期：只有 `data/library` 纳入 Git，只有下载原件与清单，没有重复简体 TXT；不转换正文用字，模型输出简体；运行数据/凭证被忽略；构建运行能从原件加载本地两书且无需挂载研究档案。
