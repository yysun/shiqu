# 书籍替换和导入专项验收

本故事手动执行。用独立目录验证器及恢复副本做破坏性探测，记录实际书名、章节数、卡片数、版本和备份路径。

1. 用正式加载器验证 24 本替换书目及 26 本扩充书目。五本的全部章节能离线读取，哈希和固定原文 URL 对得上，旧 21 本的原文版次与卡片保持一致。
2. 每本从目录或卡片定位 REQ 指定事件，验证出处、原文范围及可进入正式制作。检查哪吒的跨回关键事件与收束，检查隋唐两端的秦琼救唐公和马嵬驿。同版来源的损坏文件或错误引用应被拒绝。
3. 备份指定的活动库，在隔离目录恢复并核对三本旧书及相关修订、任务、媒体、原文、用户故事卡和向量。只在确认恢复原件和数据一致后执行按书清理。将保留作品、共享媒体及索引的前后核对记录下来。
4. 用本机嵌入模型为五本书按书建库，查询时至少各验证一个已知事件，结果能返回已核对的原文出处。向量库其余记录与备份对应，各数据库完整性检查通过。
