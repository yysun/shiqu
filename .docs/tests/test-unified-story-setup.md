# 新建/修订共用流程与编辑

1. 隔离受控库新建选择书籍主题，选择故事到待确认：只显示流程和最终确认，原文/要求/画风/幅数可从步骤打开，叙事详略不存在，plans/images=0。
2. 打开制作要求修改草稿，切到画风和幅数再关闭：流程反映草稿，重新打开仍有修改，服务器尚未确认且不编排绘图；方向键选择画风有效。
3. 原文窗口：没有plan也展示已保存原文与出处，只GET，没有补全POST；关闭返回流程。候选通过重新选择打开，能回看批次并再找一批；重选保留手改设置。
4. 要求修改后明确重新推荐，设置经队列保存、等待推荐后回到流程；没有提前生成。最终确认提交完整草稿，随后生成准确幅数。
5. 已完成故事从阅读设置打开要求/画风/幅数：与新建使用相同标签/字段；分镜仍仅修订可编辑，原版保护与影响摘要保留。关闭后body滚动和原按钮焦点恢复。
6. 375px下流程、编辑和候选无横向溢出；只在隔离库提交，不触发真实模型。
