# 横图套图操作验收

1. 同一画风有暂停 1/22 和已完成 22/22 的两套图。恢复、暂停和待重试操作应在相应行。桌面与窄屏确认删除动作突出，取消后套图仍在。
2. 横图列表直接显示各套。先删除较早的完整横图，确认其 ID 无法再导出且另一套仍可指定输出。再删除最新的完整套图，竖图照常。删除最后一套后列表清空，横版 PDF 请求提示缺图，仍可重新开画。验证套图 ID 的归属，重复提交、主动排队拒绝及已发任务收尾前拒绝。
3. 有完整套图而参考竖图缺失时，继续提供可见的参考图核对反馈。较早版本的操作仍发往该套图来源版。
4. 在窄屏从故事设置或打印入口打开画风，同屏验证已选、确认与可滚动选项。选择底部的画风后确认新套图进入生产。
