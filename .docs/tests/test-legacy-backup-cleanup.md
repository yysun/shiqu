# 旧书库备份清理验收

在隔离书库备份目录准备一份名称和清单文件均可识别的升级快照，去掉归属记录。再准备一份受回退记录引用的同类快照。

1. 刷新列表。缺归属的普通快照可手动删除，回退依赖中的快照不可删除。
2. 打开确认。查看目标路径和来源提醒，取消后快照仍在。重新确认删除后列表只移除目标，书库与受保护快照仍在。
3. 用损坏的备份清单或缺失的媒体复测可识别快照。读取或恢复操作持有锁、删除确认后新增回退依赖、目录身份改变时，原删除请求均应被拒绝。
4. 在旁边创建另一个指向同一备份根的旧别名，或添加正式回退报告，刷新后应禁用缺归属快照的删除。验证去掉归属和补入正确归属后，原确认都不可复用。
