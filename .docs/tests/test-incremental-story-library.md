# 增量故事库服务级端到端

前置：隔离数据目录与受控模型适配器，实际应用REST/SQLite/媒体文件和生成队列；使用简短本地原文，记录 catalog 和 match 调用，禁止外部推理/原文网络调用。

1. 创建主题甲的新任务并提供真实查看者需求。提取先得到不匹配甲的故事A，再得到匹配甲的B。观察B逐篇返回，持久库同时存在A/B；提取输入没有甲。
2. 关闭并重启应用，为主题乙创建新任务。用库中A/B的摘要判断，A符合乙，不重新提取原文；再次查乙不重复匹配。
3. 受控模型对一条摘要返回review：第二次主题判断带该条真实原文，yes后返回；重复review或失败不当成no，库和cursor保留可重试。
4. 同时甲/乙查找共享一轮catalog；关闭一个查看者，另一个仍可得到结果；最后一个离开不派发下一块。选中B拒绝迟到候选/自动续找。
5. 选中B，准备原文和画幅建议；生成输入包含B对应原文/章节上下文，不包含库摘要替代文本；完整确认前不生成分镜或图像，确认后正常完成。

补充故障用例：提取摘要缺失、非法source、重复/未知/缺失匹配ID、缓存损坏、缓存写失败、跨章未完、模型配置或原文版本改变、旧主题缓存游标不能越过未收录文本。
