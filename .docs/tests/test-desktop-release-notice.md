# 桌面版更新提醒验收

通过 `pnpm desktop:preview` 加载正式控制台组件，用隔离的 Tauri 桥接和 GitHub 响应验证界面。原生命令另用源码检查验证。

1. 当前版为 0.11.0，正式新版为 v0.12.0。启动后出现新版提醒。点击「打开官方下载页」，桥接收到打开官方发布页的命令。
2. 当前版为 0.11.0，远端为 v0.11.0。启动后没有新版提醒。手动检查显示「已是最新版本」。
3. 启动检查遇到网络失败。控制台可正常使用，页面不报自动检查错误。手动检查失败有明确反馈，恢复网络后再次检查可显示新版。
4. 普通浏览器预览不调用 GitHub 或桌面原生命令。

执行：`pnpm exec node --test tests/desktop-release-notice.playwright.e2e.mjs`。
