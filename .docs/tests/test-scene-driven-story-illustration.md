# 连环画场景叙事验证

## 正式调用契约

用现有制作 DAG 调用测试的受控提供方准备一组固定幅数的分镜，其中一幅依赖空间关系，另一幅为有明确任务的近景。通过正式提纲、画面描述、局部画面修订、审校、换画风和绘图提示词入口记录请求。核对环境要求进入负责该任务的指令，配文调用契约保持原有职责。横图和竖图都接收保存的环境线索，人物参考图与当幅取景的职责清楚。

## 单篇实图抽查

使用临时目录和现有 Codex 订阅，经正式制作调用生成一则短故事的提纲和画面描述。选一个地点、行动方向或阻隔影响理解的画幅。让文字审校检查同幅故意省略关键空间线索的版本，记录幅号、叙事损失和修法，再走局部画面修订。对同幅换一次画风，核对环境关系、动作和揭示顺序有据地延续。

使用正式绘图请求生成该幅竖图，再以竖图为参考生成同场景的印刷横图。在阅读尺寸看两张图，核对提纲指明的空间关系、行动以及选定画材是否可辨认。保存本次请求与结果供复核。若只获得受控提供方的结果，真实成图条件保留待验证状态。
