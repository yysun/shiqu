# 更新默认主题及检索定义

读者可以在现有「主题」页输入自定义主题或情节。默认主题用于从同一个值得琢磨的问题出发找多则故事。现有部分预设会拆成两个词按 OR 匹配，读者从题面读出的关系可能在检索时丢失。更新后的预设使用简短标题，每项附一条完整的选篇定义，供向量检索与模型匹配共用。

| 默认主题 | 检索定义 |
| --- | --- |
| 人情冷暖 | 人物得势、落难或有求于人时，身边人的帮助、疏远或态度反差显出人情的厚薄。 |
| 爱与缘分 | 两人的情意推动关键情节，两人的选择或各自的处境促成相知、相守、负心或错过。 |
| 善意的处境 | 人物的善举招来猜疑、被人利用，或使自己面对两难，故事写出人物如何应对或这份善意带来的后果。 |
| 聪明与糊涂 | 人物自以为聪明却误判局势，或看似糊涂却抓住要害，行动的结果显出判断与表象的落差。 |
| 命运与选择 | 人物受身份、承诺或时局所限，仍作出一个影响结局的选择。 |
| 欲望的代价 | 人物为求得某样东西而采取行动，也因此失去某样对自己有价值的东西。 |
| 执念与放下 | 人物长期坚持某个愿望、判断或承诺，这份执念让他陷入困境、付出代价，或在具体遭遇后终于放下。 |
| 世事可笑 | 人物的言行、身份或所守的规矩与事情的结果形成荒唐反差，照出一种人情或世风。 |

## 验收标准

- [ ] 「主题」页按表中顺序显示八个预设，保留现有「其它」自定义入口和整个选篇流程。选择预设使用该项完整定义。用户自定义输入即使与标题同名，也按用户原句检索。
- [ ] 当前书有可用向量索引时，以对应的整条定义生成查询向量，按相似度展示语义相关的故事卡。「与」保留在标题中，检索不把预设拆成词分别召回。已有故事卡向量可以继续使用。
- [ ] 向量未启用、当前书无兼容索引或嵌入服务不可用时，模型逐批读取故事卡标题和梗概，用同一条定义判断是否符合。判定须有足够情节支持，定义中的选择、因果和反差关系须成立。并列给出的合格情节可以任选其一。
- [ ] 已保存的主题名、候选和作品制作要求可继续读取。新查询使用对应的定义，定义变化后不会误用旧口径的匹配结果。
- [ ] 用有明确出处的正反例核对两条路径。至少覆盖「命运与选择」中困境实际限制了人物的决定，以及仅有人遭遇困境两个例子，再覆盖一组爱情主题。验证向量路径确实提交整条定义、相关故事能进入候选，也验证无向量路径按定义排除缺少关键关系的近似故事。两条路径分别验收，向量候选保留「语义相关」的含义。

本次更新用于选篇。既有画风、分镜和制作要求沿用现行流程。主题更新可独立于书籍替换交付，验收可使用现有书籍。预设词与检索定义以上表为准。
