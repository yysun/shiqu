# 替换三本内置书籍，再扩充两本

内置书库用于从古典原著挑选能独立改编成连环画的故事。替换阶段换出三本、换入三本，书目为 24 本。扩充阶段再加入《说岳全传》和《镜花缘》，书目为 26 本。每个阶段交付该阶段新增书籍的全本原文、随包故事卡和本地向量索引。

| 换出 | 换入 | 选篇价值 |
| --- | --- | --- |
| 《博物志》 | 《封神演義》 | 哪吒与姜子牙等人物可贯穿多篇。跨回情节可以按完整事件选段。 |
| 《阅微草堂笔记》 | 《三侠五义》 | 包公断案、展昭与白玉堂等人物可以支撑连贯的公案侠义系列。 |
| 《酉阳杂俎》 | 《隋唐演义》 | 从秦琼、单雄信等隋末唐初人物，到武周、唐玄宗和安史之乱，均可从全本选篇。[原著目录](https://zh.wikisource.org/zh-hant/隋唐演義) |

| 扩充书籍 | 选篇价值 |
| --- | --- |
| 《说岳全传》 | 补南宋岳飞故事，可从枪挑小梁王选一个完整事件，也可沿岳飞的生涯做系列。[原著目录](https://zh.wikisource.org/wiki/說岳) |
| 《镜花缘》 | 补海外奇游。先选林之洋在女儿国被选为王妃到脱身的完整事件，展现当地规矩怎样改变人物处境。[原著目录](https://zh.wikisource.org/wiki/鏡花緣) |

## 验收标准

- [ ] 完成替换时内置目录恰为 24 本。三本替换书进入应用、CLI 和随包书库的书目，换出的三本及其内置原件和故事卡退出当前发行书库。其他 21 本的书籍标识、原文版次和可用引用保持稳定。
- [ ] 完成扩充时内置目录恰为 26 本。《说岳全传》和《镜花缘》进入应用、CLI 和随包书库的书目。
- [ ] 五本新书均收录可离线读取的全本，书目和章节浏览覆盖所选版本的全部正文。逐件记录固定来源版本、文件 SHA-256、收录范围、署名、适用条款和已知文本问题。核对章节完整性，沿用现行坏字、缺文和失效引用的校验。最终取用版本以实际核验结果为准。
- [ ] 五本均从全书选取可独立改编的事件，随包提供绑定同版原文的故事卡，可按章节浏览、按故事及主题查找、打开原文并进入正式制作。验收抽查哪吒跨回事件、乌盆诉冤、《隋唐演义》的秦琼救唐公和马嵬驿事变、岳飞枪挑小梁王、林之洋在女儿国的遭遇，确认选段覆盖关键因果和原有收束。
- [ ] 本次整理的本地书库为五本新书直接生成向量。每本书的故事卡一经核验，即用现有本地嵌入模型按书建库。交付时记录各书的版次、卡片数、建库数及实查结果。五本各实查至少一个已知情节，核对候选卡及其原文出处。
- [ ] 随包书目、来源说明、使用文档与产品实际一致。CLI 列书或选书行为有变化时，同步内置技能及相关示例。

## 本次验收的测试范围

- [ ] 替换和导入后的专项验收只为本故事手动发起，覆盖书目、全本原文、故事卡、向量检索及备份恢复和清理结果。验收用例和结果随本故事记录。
- [ ] 本故事的专项用例、脚本和测试数据仅供本次验收使用，不注册到其他测试集、不接入自动测试入口、CI 或发布门禁。仓库现有的通用检查照常适用。

## 换出书目的备份和清理

- [ ] 删除前按书籍 ID 盘点《博物志》《阅微草堂笔记》《酉阳杂俎》的故事、历史修订、相关任务、原文快照、媒体、内置与自建故事卡，以及向量记录。先用现有书库备份流程保存完整的目标本地书库，并归档这三本的内置原件、来源清单和随包故事卡。备份保存在活动书库之外，记录备份路径和每本的数据数量。
- [ ] 在隔离目录验证备份可恢复，核对三本的故事及修订、故事卡、向量记录和媒体。确认可从恢复的副本读取故事及原文快照。备份和验证都通过后，才可开始删除。失败时保留活动书库并报告原因。
- [ ] 从本次整理的活动书库删除三本对应的故事及关联数据、故事卡和向量记录。共用的向量数据库按书清理，保留其余书目的记录。其他作品仍引用的媒体须保留。删除后核对三本均已退出活动书架和检索，其余书目、故事和向量仍可使用，已验证的备份留存。

本次范围是内置目录、五本新书的原文和故事卡，以及指定本地书库的备份、按书清理和向量建库。隋唐题材本次收《隋唐演义》，《说唐演义全传》不列入书目。清理只执行于本次指定的本地书库，普通应用升级不自动删除其他用户书库里的旧作品。新向量保存在本地书库，随书库备份。Git 历史改写、制作样片成图和发布另行处理。五本新书的具体版本待选源核验。
