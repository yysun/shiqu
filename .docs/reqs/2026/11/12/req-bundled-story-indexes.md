# 内置书籍索引随版本发布

新装拾趣需要手动导入故事索引，才能用故事标题、梗概和原文查找候选。现有索引来自内置原文，可以制备成随版本交付的资源。完整向量按书分发，避免所有用户都为很少用到的书付出下载和备份成本。

- [x] 桌面、npm 和源码运行共享随原文发布的轻量故事索引。新书库无需导入、联网或生成查询向量即可搜到已收录的故事，返回当前原文与出处。
- [x] 维护者可从已制备的索引生成逐书发布资源。用户可把官方向量包安装到桌面和 CLI 共用的应用缓存，供不同书库读取。删除缓存后继续用轻量索引。
- [x] 校验书 ID、原文版次、出处和可用向量。缺失、损坏或旧版官方资源不阻断书库。保留已有手动导入和历史索引，以及它们的备份恢复行为。官方资源与新书库备份分开。
- [x] CI 的实际发布入口可从干净检出交付轻量索引。逐书发布资源能独立验证和交付。文档及内置技能与 CLI 同步。

不引入在线查询模型或自动下载。首批仅收录现有完整且可核对的故事卡，其他书继续读原文。此工作不发布远端版本。
