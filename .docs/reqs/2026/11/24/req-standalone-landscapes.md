# 独立横版印刷

> 已被取代：见[制作规范精简 1-1](req-production-spec-simplification.md)。涉及原约定「旧横图通过旧流程手动接续」。升级把已获授权、尚未完成的工作转为暂停的独立套图，读者从标准横图入口恢复。 [独立横图与升级](../../../../story-production-dag.md#节点目录)

- [x] 横图只由读者明确启动或重试，绘图输入在启动时保存。普通修订、继续、重绘或暂停竖图不更改这套横图的任务、进度或成品。
- [x] 横图使用独立暂停和恢复。已经获准的工作在来源版本成为旧版后可继续，删除作品仍阻止新派发。
- [x] 打印时可选择已保存的旧横图套图。采用该套图的幅序、标题和配文；当前竖图仍可用于试排。
- [x] 跟踪画幅范围、重试和付费回执。兼容已有成品，带原授权且未完成的旧流程由读者手动接续，优先采用可读的付费结果。
