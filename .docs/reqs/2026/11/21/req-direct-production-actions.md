# 制作编辑一步提交

> 已被取代：见[制作 DAG 需求](req-data-driven-production-dag.md)。涉及原约定「提交普通修订就开始下一步」。编辑器提交会保存修改，有待做工作时点「继续制作」才执行。首次制作仍须明确确认。 [保存、暂停与继续](../../../../story-production-dag.md#保存暂停与继续)

- [x] 已开始制作的故事在编辑面板直接提交分镜、制作要求、验收要求、画风或叙事详略，并按改动开始下一步。
- [x] 分镜列表内提交删合和新梗概。预览与多选可以在本面板完成。
- [x] 首次制作可直接从设置编辑面板开始。保留选材、准备和第一次明确开工的边界。
- [x] 制作时间线显示实际任务进度。提交失败留在原面板处理。
- [x] 「重新审核」在编辑面板内以实心主按钮显示，点击一次提交并开始审核。
