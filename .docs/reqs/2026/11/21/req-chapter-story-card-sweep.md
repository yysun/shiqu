# 章节卡补齐独立故事

长篇目录原来按篇章制卡。读者选一章时往往只能使用整章，无法直接选择其中可独立讲述的事件。

- [x] 系统核对《史记》《三国演义》《水浒传》《西游记》《红楼梦》《儒林外史》的本地原著篇章。每篇记录新增、核对后无需新增、原文受阻或仍待处理的实际结果。
- [x] 原有整篇卡和已补的篇内卡保持可用。新增卡的标题、梗概和同版原文范围对应一个有独立因果及收束的事件，避免同事件的改名重复、截取未完段落和补写原文没有的事实。
- [x] 可重复核对全书，能接续未处理篇章。重复应用同一批卡不产生重复条目。
- [x] 生产目录可直接浏览和选用新增卡，选材读取对应原文。覆盖结论和仍有缺口的篇章有可核对的记录。

范围依据是现有目录按篇章直接替代故事的六部长篇。已有事件级分段的长篇和已独立分篇的短篇集沿用其现有目录。使用当前 Codex 订阅和仓库内已收录的原文。
