# 分镜剧本批量编辑

- [ ] 单幅左滑露出「修改」「删除」，可用按键打开同一组操作。「修改」打开对应画幅。
- [ ] 「选择」进入多选，可删除所选画幅，或将至少两幅合并为一幅。合并预填旁白并可调整画面提示词。合并结果放在最早选中的位置。
- [ ] 已选画幅以列表顺序处理，剩余画幅重新编号。必须为故事保留至少一幅。
- [ ] 修改先进入草稿。应用后创建新版并审核编辑后的分镜，旧版可查，未受影响的图片按首幅参考规则复用。
- [ ] 列表顶部的「重新生成故事梗概」使用当前画幅（含尚未应用的草稿）生成梗概。结果在列表预览，并可随草稿应用。只更新梗概时沿用已有分镜、审核和图片。
- [ ] 故事名和梗概显示在「重新生成故事梗概」上方，「选择」沿用文字链接样式。
