# 局域网恢复生成设置

LAN 用户与本机用户已经共用书架与生成权限，却无法进入模型设置。恢复可信局域网直接访问时的完整设置能力，避免 Profile 页入口无故消失。

## 验收

- [ ] 开发、CLI、桌面服务在实际私有局域网地址上允许读取和保存提供方、文本/图片模型、推理档位与密钥操作；Profile 保持既有入口与完整表单。
- [ ] 只接受真实回环或私有网络套接字、服务实际接口地址与端口；LAN 来源不能伪造回环 Host。保留同源提交、跨站拒绝、固定路径和开发代理私有证明，拒绝公网来源和任意 Host；桌面互联网隧道仍拒绝设置。
- [ ] 已存密钥永不返回，修订冲突、严格字段校验、共用数据库、运行快照与重启生效行为保持；不新增远程原生路径、网络、启停操作。
- [ ] 使用隔离书库/配置和合成密钥验证实际 dev、CLI、desktop 的 LAN 读写、边界、表单与冲突；同步用户文档和内置技能。记录无法完成的验证。

不改变数据库或依赖，不打包，不修改用户书库或真实模型配置，不自动重启用户运行服务。可信 LAN 设备可修改共享服务配置；公网/隧道不获得此权限。
