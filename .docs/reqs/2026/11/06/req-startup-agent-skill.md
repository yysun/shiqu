# 启动时准备拾趣技能

用户目前需要手动安装技能；桌面虽自带 Node，助手仍依赖系统 npm。把技能准备接入普通 NPX/桌面服务启动，复用已有安装与更新保护，不引入 MCP/API 工作流。

## 验收

- [ ] AC1 普通 CLI 服务成功监听及桌面 start 分支安装缺失的用户级技能；帮助、版本、配置、维护、headless、开发服务和桌面 test/upgrade 不隐式安装。
- [ ] AC2 启动只使用随包技能；旧受管副本仅按已有 autoUpdate 同意更新。保留修改、未知来源和较新副本，不启用自动更新，不修改宿主配置；尊重宿主停用和已启用插件。
- [ ] AC3 `skill auto-install [on|off]` 与单次 `SHIQU_SKILL_AUTO_INSTALL=off` 可控制启动集成，独立于 auto-update。安装失败不影响服务，输出不泄露配置内容。
- [ ] AC4 桌面资源包含同版本技能和生产 CLI，启动登记受哈希保护的绝对 Node/CLI 命令。搬迁后的 CLI 在 PATH 无 npm/npx 时可执行帮助、技能和离线书库读取；保持直接开库的占用约束。
- [ ] AC5 帮助、技能与相关使用文档一致；隔离回归覆盖启动、更新授权、保护与搬迁。通过影响测试、typecheck、lint 与适用原生检查，不修改真实书库/用户技能，不打包桌面应用。

不移植 MCP、CLI --url、插件打包、数据库迁移或画廊。启动不查询注册表、不下载或更新应用，不改变生成提供方。桌面已运行时直接 CLI 仍需先安全停止同库服务。
