# 制作 DAG 的人物参考图需求

## 问题与目标

首幅承担开场叙事，可能是远景，也可能只出现一位主角。《宝玉探病梨香院》第 1 幅能给宝玉定形，宝钗到第 4 幅才出现，第 6 幅才有清楚的近景。待切换的制作 DAG 把全书星标交给首幅，后续统一参考首幅。这使晚登场的角色难以继承已有的全书形象。

在正式制作 DAG 中加入「准备人物参考图」。让反复出现的人物在同篇和跨篇都能被认出来，同时让每幅按自己的分镜表现年龄、服饰、动作、取景与环境。全书参考提供身份线索，本篇人物设定和分镜确定故事中的形象，选定画风决定表现手法。 [现有 DAG 参考图规则](../../../../story-production-dag.md#节点目录)

## 验收条件

- [ ] **全书参考标明人物。** 读者能标明本书星标图中的一个或多个人物，并在同书其他故事使用这些身份参考。既有星标可以查看、标认、替换或取消。身份对应关系未确认时，系统明确提示，并允许读者选用本篇参考。不同书籍、不同用户的参考互不混用。
- [ ] **有图就复用，缺图才生成。** 常规制作在分镜审片通过或读者放行后，依据入画名单为反复出现且需要保持辨识度的人物准备参考。本篇已有符合人物所处阶段和画风的清晰图时可直接采用。全书已有同等适用的身份参考时也可复用。全书图只适合作为身份来源时，用它和本篇设定生成所选画风的定妆图。两处都无可用图时，可依据本篇人物设定定形。单幅或没有重复入画人物的作品可直接按分镜出图。
- [ ] **每幅按实际入画人物用图。** 晚登场的角色在首次需要时就能用自己的参考。多人同框时，每份身份参考明确对应具体人物；一张图可以覆盖多名已标认的角色。环境图和物件特写可独立绘制。参考图帮助保持身份辨识度，本幅分镜决定年龄、换装、人物站位、遮挡、动作及背景。
- [ ] **三种画风可按需预览。** 人物设定可用后，读者可明确请求为同一人物比较三种自选画风。三张样图采用相同的年龄、服饰、姿态和取景。选中的样图可直接用作该画风的参考。常规制作只为本次确认的画风准备参考；之后换画风时沿用已建立的身份特征，并复用或生成符合新画风的定妆图。
- [ ] **参考可追溯、可替换、可恢复。** 读者能查看参考图及其对应人物。每幅记录实际使用的参考版本。生成或读取失败只暂停等待该参考的画幅，读者可重试、改选或明确继续出图。替换参考后提示哪些成图用了旧版，由读者决定重绘范围。在途请求沿用已选快照，已生成待保存的结果可继续保存。
- [ ] **用正式出图验证收益。** 用《红楼梦》两个有重复角色的篇章作对照，保持分镜与画风相同，覆盖晚登场、双人同框、换装和环境特写。逐幅记录人物身份是否可辨、场景是否符合分镜，以及是否沿用了参考图的无关人物或背景。与首图规则相比，按人物选参考组的身份辨识通过幅数更高，场景符合分镜的通过幅数至少相同。另用同一人物验证三种画风预览和选中复用。

## 范围与约束

首批覆盖新制作的正式竖图、人物定妆及三种画风预览。历史作品通过明确的制作或修订操作采用新参考。局部图像编辑、横图重构和整篇多画风出品各自立项。

制作 DAG 切换后接入。正式制作和质量验证走同一入口，验证使用隔离数据。常规流程以准备确有需要的人物为限，额外的画风预览由读者主动发起。
