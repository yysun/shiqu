# 连环画场景叙事需求

## 问题与目标

一些画幅能画清人物和动作，却把决定人物处境的环境压成背景。读者看见管仲退走，仍很难从画面辨认身后的战场和前方的退路。已有的绘画质量要求覆盖构图、明暗、色彩和笔触，制作流程还需要在提纲和分镜中明确这些手段要传达的场景信息。

每幅连环画呈现一个完整的可见瞬间。当地点、身份、距离、阻隔或行动方向影响理解时，场景须与人物共同讲清这一刻。读者在手机上看图时能辨认画面应交代的关系，再借配文理解完整情节。

## 验收条件

- [x] **提纲。** 开场、转场或处境变化需要读者重新认识空间时，能指出哪一幅负责交代它，以及这处环境如何服务当幅的动作、反应或结果。同一地点的连续画幅有足够的空间线索可供承接。固定幅数符合用户设定，单幅故事在同一画面交代核心动作及理解它所需的环境。
- [x] **分镜。** 需要环境说明的画幅，单独阅读画面描述就能确定可见的空间线索、人物与线索的相对位置，以及取景和焦点。同一场所换视点后，关键方位仍能对应。近景、单人画面和留白在完成当幅叙事任务时成立。
- [x] **审校。** 环境或空间关系的缺失会妨碍读者理解时，审校能指出具体幅号、可能的误读和最小修法。布局连续且有助于阅读的画幅，以及有明确作用的近景和留白，可通过文字分镜审校。局部修订保留同幅已有的有效内容和无关画幅。
- [x] **生图。** 竖图和重绘的绘图指令保留分镜规定的环境线索与空间关系。印刷横图调整构图后，同一事件、关键方位和遮挡仍可辨认。成图在阅读尺寸下能看清当幅要传达的路径、边界、距离或人物站位，并呈现所选画风的明暗、色块、线条或笔触。
- [x] **原文与连续性。** 环境细节符合原文和时代，保留人物身份、既定动作、未知信息与揭示顺序。换画风后，原有场景的叙事线索、人物位置与构图关系仍成立。

## 范围与约束

覆盖正式提纲、逐幅画面描述、文字审校、定向修订及竖横图生成。首批从已切换的制作 DAG 生效，面向新制作。历史作品沿用现有修订入口。
