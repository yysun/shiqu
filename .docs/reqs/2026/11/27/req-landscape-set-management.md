# 横图套图操作与删除

- [x] 横图步骤直接列出每套图。读者能在对应套图行暂停、恢复、重试或删除。已完成的套图也能删除，包括唯一一套。待重试和已暂停的套图仍能删除，正在生成或收尾时等待任务处理后再删除。
- [x] 删除需要明确确认。从制作及打印列表仅移除选中的套图。其他套图和竖版可继续使用。删除最后一套后可从横图步骤重新选择画风，默认打印提示缺图。
- [x] 套图直接列在横图步骤内。画风加粗在左，状态与幅数紧跟其后，操作同行靠右，空间不足时整组靠右换行。生成进度只显示一次。套图之间无分隔线，普通套图行与标题间距一致。
- [x] 制作列表和横版、Letter 双面 PDF 的套图下拉框均省去时间戳。同画风多套按现存顺序编号，读者仍可选择对应套图。
- [x] 首次制作和另绘可在弹窗中选择现有画风。390 × 844 时同屏看到已选和确认，短屏只滚动卡片区。关闭弹窗返回原入口。

本要求更新[横图画风、套图选择与试印](req-landscape-print-editions.md)中的删除范围、套图展示及画风入口。两份要求与[打印缺图恢复](../../../../reviews/2026/11/27/export-audit/README.md)共同覆盖本次横图交付。复测覆盖桌面侧栏、窄屏设置及打印入口。现行约定见[使用指南](../../../../user-guide.md)。
