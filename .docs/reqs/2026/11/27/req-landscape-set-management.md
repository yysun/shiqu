# 横图套图操作与删除

- [ ] 横图步骤直接列出每套图。读者能在对应套图行暂停、恢复、重试或删除。已完成的套图也能删除，包括唯一一套。待重试和已暂停的套图仍能删除，正在生成或收尾时等待任务处理后再删除。
- [ ] 删除需要明确确认。从制作及打印列表仅移除选中的套图。其他套图和竖版可继续使用。删除最后一套后可从横图步骤重新选择画风，默认打印提示缺图。
- [ ] 状态、幅数和时间能分开扫读。390 × 844 打开画风选择后，同屏看到已选和确认，可直接选择现有预设。

此要求更新[横图画风、套图选择与试印](req-landscape-print-editions.md)中的删除范围。复测覆盖桌面侧栏、窄屏设置及打印入口。更新现行[使用指南](../../../../user-guide.md)。
