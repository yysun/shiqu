# 桌面复用书库服务

CLI 已经能查找同一书库的服务并连接。桌面点击「启动服务」也需要先查找。已有服务时，桌面在原地址打开阅读器并管理同一个 Node 服务。已有服务之外启动第二套制作调度会争用书库，并可能重复提交模型请求。

- [ ] 桌面按已保存的书库发现并验证已有服务。浏览器 CLI 已在线时，桌面直接连接同一个 PID 和阅读器地址，沿用其生成、绑定和端口设置；两个入口看到相同作品和任务。
- [ ] 书库命令自动启动的 Node 进程也可被接入。已接收的 CLI 命令先收尾，再由同一个进程提供常驻阅读器和制作服务。没有桌面接入时，原有的空闲退出和独立 CLI 授权边界继续有效。
- [ ] 通过桌面可以停止、立即停止、重启和退出已接入的服务。常规停止保留已领取步骤和原授权，立即停止取消模型请求；书库仍只有一个持锁进程。桌面启动无现有服务的书库时沿用已保存设置。
- [ ] 旧版本、不兼容、错误端口和另一书库的服务不接收控制指令。接入失败不关闭既有服务或改写书库配置。已有进程消失后可重试启动。管理端口仅在本机可用。
- [ ] 停服前尚未获准派发的 CLI 请求恢复故事原状态，包括原有等待或已经批准的后台制作。桌面退出和强停保留已有等待、错误汇报和取消保证。
