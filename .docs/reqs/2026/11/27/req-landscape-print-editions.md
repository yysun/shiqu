# 横图画风、套图选择与试印

删除范围及套图列表展示已由[横图套图操作与删除](req-landscape-set-management.md)更新。

读者已有能打印的横图，想另试一种画风，或先校对尚未画齐的一套。现在可重画整套，但沿用竖版画风，打印也只能自动挑选完整套图。

- [x] 首次生成和另绘整套均可选择横图画风，默认沿用当时的竖版画风。确认才开始，每幅一次绘图。横图重试沿用已保存的画风，竖版设置和产物保持原样。
- [x] 仅替换或重绘竖图时，现有完整横图仍可用于当前分镜，横图调用为零。竖版换风后原套继续可选；若画面描述已经改写且无法确认是同一场景，按原分镜标记和输出。只有页序变化时，使用当前页序。
- [x] 横图制作步骤和打印入口可查看当前及前序可见版本的各套横图，包括零幅、进行中、暂停、部分失败和完整套图。显示来源画风、生成时间、进度及历史分镜标记。打印默认选最近完成的套图，读者可明确切换。
- [x] 横版和 Letter 双面 PDF 严格输出所选套图。旧分镜用该套保存的画幅和配文；同一分镜用当前页序。缺图占原位，保留配文及页码，标明试印稿，双面配对保持原位置。已生成的幅可选为封面，零幅使用文字封面。
- [x] 选套图、导出和失败时的文件核对不派发绘图。其他故事的套图不可取得；损坏的图也按缺图处理。旧书库已保存的横图无需迁移即可列出和导出。
- [x] 在同一个故事里已有完整套图，再绘并暂停第二套时，能同时看到完整、暂停两套。可以确认删除已暂停且已收尾的未完成套图，或删除以失败结束的未完成套图。删除只影响所选套图，随后可立即选另一画风重画。已完成套图仍可导出，竖版内容不受影响。

现有尝试记录已包含实际横图画风和派发时间。复用这些记录。首期继续使用现有横版 PDF 和 Letter 格式。
