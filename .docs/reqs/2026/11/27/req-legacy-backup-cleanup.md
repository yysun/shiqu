# 清理无法使用的旧书库备份

旧升级快照缺少归属记录时，桌面控制台禁用删除。用户需要在应用内清理不用的快照，释放磁盘，同时保留正在使用的回退点。

- [x] 默认备份目录中可识别的升级快照缺少归属记录或无法校验时，可以显示实际路径和风险，经明确确认后清理。已知归属的损坏快照沿用现有能力。
- [x] 取消不删除。快照目录或清单身份变化、归属状态变化、备份正在读取或恢复、书库仍有升级依赖、来源明确不符、目录无法识别时拒绝删除。
- [x] 对缺归属的快照，保护当前书库的升级日志、迁移依赖和正式回退报告。遇到同目录共享备份根的旧别名时保持禁用。缺失的历史路径记录无法借本地扫描重建，界面要求操作者确认其他书库也不依赖它。
- [x] 在隔离书库验证删除和保护。0.18.0 签核证据和发布状态保持暂停。
