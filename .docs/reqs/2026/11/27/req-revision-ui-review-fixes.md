# 修订流程界面与评审截图修正

## 问题与目标

修改故事的读者需要看清保存后停在哪一步、接下来会重做什么，以及怎样恢复或继续。评审者应能直接打开每一步的应用截图。当前指南的 PDF 在五页保留了旧文字，部分新旧截图的比例与裁切不一致。手动核对又发现，一些制作操作链接在截图里被方框包围，读起来像描边按钮。实际界面还复用了暂停图标，并在整篇换画风时重复逐幅列出重绘范围。 [11 月 27 日评审与修正前截图](../../../../reviews/2026/11/27/revision-pdf-ui-audit.md#screenshot-evidence)

本次以评审目录内的独立应用截图验收。先完成界面和截图修正，再以验收通过的截图更新现有 PDF 指南。评审原来提出统一加框的做法由本需求取代。

## 共用视觉层级

编辑窗口用实色主按钮提交「保存修改」，用描边次按钮退出「取消」。禁用的保存沿用同一按钮尺寸并降低视觉强调。制作时间线由当前步骤的底色、状态和图标提供层级，步骤内操作沿用 `StoryFlowAction` 的下划线文字链接。使用现有按钮、链接和 `ProductionTimelineRow` 样式。 [项目布局约定](../../../../development.md#制作流程界面约定)

## 验收标准

- [x] **同倍率比较「保存修改」的可用和禁用状态。** 在同一编辑窗口、同一视口和设备像素比下，分别截图记录尚未修改和有可保存修改。截取同一操作区域，按相同倍率并排展示，核对两图中按钮的宽、高和字级一致。「保存修改」可用时以实色主按钮领先于描边的「取消」，禁用时视觉强调降低，「取消」保持可用。对应 F2，依据 Playbook 的 VH01（第 6–7 页）与 CS03（第 41–42 页）。 [原对照截图](../../../../reviews/2026/11/27/revision-pdf-ui-audit.md#screenshot-evidence)
- [x] **先实测制作链接，再核对新截图。** 旧图里的方框已出现在图片像素中，来源待查。通过正式制作入口核对待继续、进行中和已暂停三个状态。先查看未聚焦和悬停的「继续制作」「暂停生成」「恢复生成」，再用 Tab 验证清晰可见的键盘焦点。采集默认态前，点击当前面板内的非交互空白区域移开焦点，将指针移出操作区，确认链接已失焦且状态未变化。默认态已符合样式时，直接重新截图。若在未聚焦的界面复现方框，定位来源并修正相应样式。新截图并排显示未聚焦默认态，三项都是所属步骤内靠右对齐的下划线文字链接，四周无静态描边、按钮底色或后加标注框。当前步骤仍由底色、状态和图标突出。对应 F3，依据 Playbook 的 VH01（第 6–7 页）、VH05（第 11 页）与 CS02（第 39–40 页）。 [现有方框证据](../../../../reviews/2026/11/27/screenshots/05-02-style-conversion-awaiting-continue.png)
- [x] **等待读者继续与主动暂停一眼可分。** 在同一桌面宽度查看已保存的修订与同类已暂停任务。「待继续」和「已暂停」的图标不同，暂停符号只用于已暂停状态。两行分别保留「继续制作」与「恢复生成」。保存修订后等待授权，继续与恢复各自执行原有动作。对应 F4。
- [x] **影响说明准确且简短。** 全部重绘时准确给出总数一次。只重绘部分画幅时仍可核对具体编号。自动幅数重新编排时，读者仍能区分已保存旧图失效与新版幅数待定。评审所用的桌面宽度下，详略说明结尾没有单独成行的「准。」。对应 F8。
- [x] **评审目录提供修正后的截图。** 在隔离书库运行正式流程并用应用内浏览器实测。以可单独打开的图片记录制作要求、验收要求、叙事详略、画风、删幅、定向修订／复核／绘图、暂停与修改审核意见，以及保存按钮的可用和禁用状态。索引标明截图对应的构建或提交、浏览器和视口，并明确修正前后的证据。等价状态可以直接比较字号、位置和操作样式。对应 F2、F3。
- [x] **每张图片能说明对应步骤。** 画风示例能同时核对选中的水彩绘本与影响说明。示例裁切保留完整的相关控件和行，等价截图使用一致的缩放、对齐和边缘处理。制作要求、验收要求和审核意见与截图里的样本故事一致。删幅示例的标题和图注沿用流程中的「拟定标题与结语」。对应 F2、F3、F5、F6。
- [x] **应用排版与间距经过实测。** 在常用桌面宽度及操作组需要换行的窄宽度，核对编辑器和制作时间线。字段与说明就近成组，各组之间留出可辨认的间隔。影响说明紧邻靠右的保存操作。各步骤图标、标题和说明沿共用轴对齐，操作与错误反馈留在所属步骤内。空间不足时，操作组整体靠右换行，内容无重叠或裁切。记录视口、对应截图和逐项结果。依据 Playbook 的 PX01、AL01、AL03、WS01–WS03、IC09 与[项目布局约定](../../../../development.md#制作流程界面约定)。
- [x] **截图验收通过后更新 PDF。** 更新评审目录内的 [修订流程指南](../../../../reviews/2026/11/27/拾趣修订流程-按钮与实测截图.pdf)。保留按修改项分组的步骤和结果摘要，页脚如实注明采集环境。逐页渲染并核对标题、截图、图注和结果区的阅读顺序。首页两处小标题与各自内容的间距小于与上一组的间距，表格与注记清晰分组。同排截图顶边沿共同基线对齐，图注紧跟所属截图，同类截图等比且可直接比较。对照原版记录间距与对齐结果。提取文字确认当前图注各出现一次，关闭与取消的说明符合现行行为，且已替换的图文从文档内容中移除。对应 F1、F2、F7，依据 PX01、AL03、WS01、WS03、LY02、CS03。
