# 制作流程续作与确认

用户在书架打开制作任务时，应能接着选已有候选、明确解决另一设备的草稿修改，并看到与真实阶段一致的进度。

- [ ] 本地书籍与自选书籍的已保存候选可重新查看和继续选择，切换选材条件后只显示对应候选。
- [ ] 已变化的草稿需要明确解决。服务端拒绝用旧草稿确认或保存，现有草稿、重试和历史作品可继续使用。
- [ ] 制作确认前后保留真实来源以及「准备故事」和「制作确认」。原文入口归属原文步骤。
- [ ] 多选在提交前说明会合为一篇。修订草稿显示预计复用和重绘，保存后显示实际绘图进度。
- [ ] 书架说明、暂停进度、分镜入口、加载标题和流程文档符合当前行为。

交付版本为 0.13.2，桌面与 npm 由标签工作流发布。

范围为恢复任务中已有的候选，不新增未创建任务时的持久化查询。书库格式不新增迁移。
