# 按主题核对故事候选

- [x] 按主题提取时，从同版索引召回最多 50 个不重复的可用原文范围。沿用故事提取的文字模型分批读原文，每条分别判定明确符合、情节暗示或不符合。
- [x] 核对正向判断引用的原文证据，完成所有批次后优先展示明确命中。缺失、无效或超出预算的判断须可重试或明确标记。继续查看时复用已核对的结论。
- [x] 手动原文目录按关键词过滤整章并支持多选，主题提取只在所选范围内运行。按指定标题和离线 CLI 候选查询保留原有流程。
- [x] 以《搜神记》复仇查询和受控原文用例验证候选数、排序、偏题过滤和原文引用。用现有《搜神记》索引核对实际结果。
- [x] 每本书可独立制备和导入索引。按书名及原文版次加载，更新一本书时保留其他书的索引。书库备份及恢复包含已安装索引。
- [x] 有文字索引时可在缺向量的情况下召回。缺索引或缺可用候选时，按已选范围读原文。
