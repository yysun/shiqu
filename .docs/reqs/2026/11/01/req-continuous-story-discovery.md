# 连续寻找故事

过去首篇显示后就停，读者必须反复点击继续。改成选择界面打开时逐篇寻找、逐篇显示，让读者随时选中并进入制作。

- [ ] 本地原文及自选书籍的连续查找每次请求最多一篇；已找到结果立即保留并显示，自动继续寻找下一篇。
- [x] 选中故事停止查找，迟到结果不改变选择、不追加候选；制作准备及确认流程保持有效。
- [x] 关闭选择界面、切换故事或离开后释放查找需求；书架浏览及后台模式不单独驱动查找。断连以已有 30 秒租约兜底。
- [x] 重开未选中的故事保留候选和原文进度并继续；多个查看者独立离开，最后一个离开才停止共享需求。
- [x] 空结果、失败、手动暂停及已有 40 批候选上限停止自动继续；失败需要明确重试，界面说明停止原因。
- [x] 缓存、去重、跨章线索、选择并发保护及生成确认门槛不退化。

范围：选题阶段与需求管理。保留旧批次格式和最多 40 批的现有限制；不构建 Docker 或桌面安装包，不变更推理凭证。

验证：Node 24.22.1 / pnpm 11.25.0；完整 826 项测试、typecheck、lint 通过。首项的单篇请求、缓存响应、前端观察循环及静态界面渲染已验证；浏览器中的实际逐篇显示未验证，因此首项保持未完成。`cua.getState()` 返回 `Local browser use is disabled in Work settings`，无可用 in-app browser。
