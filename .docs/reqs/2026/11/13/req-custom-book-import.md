# 自备书籍导入为本地书

内置古典书有本地原文、故事卡和可选的本地向量索引，新建故事页可按章节、按故事、按主题查找，选中的故事有可核对的原文出处。「其他」书现在只接受书名或公开网页 URL：没有本地原文、章节和故事卡，选题只能靠模型凭记忆推荐，候选和原文都未经核对。

用户应能把自己的一本书（本地文件或公开网页）准备成本地书。准备完成后，它与内置书一样出现在书目中，支持三种查找方式，制作的故事带可核对的原文出处。

## 导入原文

- [ ] 用户可从本地 TXT、HTML 或无 DRM 的 EPUB 文件（每个文件最大 12 MB，可分多个文件），或一个或多个按顺序给出的公开网页 URL 导入一本书。导入时填写书名，可选填作者、朝代或年代、来源说明和授权说明。URL 只抓取用户给出的页面，不跟随页内链接。
- [ ] 导入保存原始字节的不可变快照，并为每个文件或页面记录 SHA-256、大小、文件名或 URL、抓取时间和内容类型。快照存放在当前书库数据目录，成为本书原文版次的依据。之后修改或删除原始文件，或网页内容变化，都不影响已导入的书。
- [ ] 能识别 UTF-8、GB18030（含 GBK）和 Big5 编码；无法可靠判断时，由用户指定编码。文件超过大小上限、EPUB 受 DRM 保护或解压后过大、包内路径异常、缺少可读正文时，导入明确失败并说明原因，书库中不留半成品。
- [ ] URL 只允许 `http`/`https` 公网地址。拒绝本机、局域网和链路本地地址，以及重定向到这些地址的请求。单页大小和总时长都有上限，失败时说明是哪个 URL 出了问题。

## 章节与段落

- [ ] 导入后系统先自动切分章节和段落（引用单元），用户确认结构后才能进入下一步。确认前可查看每章标题、字数和开头文字，可以合并、拆分、改名、删除非正文章节（如版权页、目录），也可放弃本次导入。
- [ ] 段落编号确定且可复现：同一快照加同一组结构决定，总是得到相同的章节、段落编号和原文版次。原文版次由快照和结构决定共同确定，结构调整后版次随之改变。
- [ ] 系统标出含无法显示字形、未解析实体、拆字描述或缺文标记的段落，以及空章节和疑似缺页。标记只用于提示，原文不做修补、替换或繁简转换。确认页显示受影响章节和段落数量，可逐处查看。
- [ ] 导入面向中文古典文本。无标点、夹杂非中文文字的文本可能无法按章节提取或生成故事卡，确认页事先说明，失败时说明是哪一章、什么原因。
- [ ] 结构确认后，「按章节」即可浏览目录、阅读原文，并从所选章节调用文本模型提取故事，不必等待故事卡生成。

## 故事卡

- [ ] 用户可逐章为整本书生成故事卡。每张卡包含标题、白话梗概、可选别名，以及能回到原文的出处范围。故事卡与内置书的故事卡作用相同，「按故事」和「按主题」都能使用。
- [ ] 开始前显示预计的模型调用次数、输入字数或令牌数和大致耗时；所选提供方能计算费用时同时显示费用。用户确认后才开始调用模型。
- [ ] 生成过程可查看进度（已完成章节、故事卡数、当前章节），可随时取消。已完成的章节结果保留，之后可继续，不重复调用已完成的章节。应用退出或重启后显示为已暂停，由用户决定是否继续，不自动续跑。
- [ ] 某章失败时记录原因并继续其他章节，可以单独重试失败章节。只有出处能在本书当前版次中定位的卡才会保存。
- [ ] 故事卡生成使用制作流程同一套模型提供方设置和实现，测试与评估工具也调用这套实现，不另建只用于评估的管线。
- [ ] 结构调整导致版次变化后，旧故事卡和旧向量不再参与检索。界面提示需要重新生成，未变化的部分不强制重做。

## 向量索引（可选）

- [ ] 已有故事卡的导入书可在「我的 → 嵌入模型」中与内置书一样选择建库、查看进度、取消和重试，使用同一个故事卡向量库。
- [ ] 不建向量索引时，「按主题」走现有的模型逐批核对故事卡路径，「按故事」走标题、别名和梗概的文字匹配。

## 书目与生命周期

- [ ] 准备完成的书出现在发现页书目和新建故事的选书中，标明是用户导入，并显示准备状态（待确认结构、可浏览、故事卡生成中、可用）。只有结构已确认的书可以选用。
- [ ] 用导入书制作故事时，原文、出处、来源说明和 AI 改编说明的保存与展示方式和内置书一致；出处标注为用户导入及其原始来源。
- [ ] 用户可删除导入书。删除前说明会一并删除快照、故事卡、向量和生成故事卡的中间结果。已制作的故事保留已保存的原文，但不能再从该书重选或续找故事，系统明确提示「书已删除」，不改用模型或网页上的未核对原文。删除后书库中不留该书的原文快照、故事卡、向量和故事卡中间结果。交互查找留下的候选缓存（标题、梗概、出处，不含原文）随版次失效。正在生成故事卡的任务先取消。
- [ ] 用户可重新导入，以新快照替换同一本书。内容和结构都未变时，原有故事卡和向量继续有效；否则按版次变化处理，并在替换前说明影响。
- [ ] 导入书随书库备份、恢复和升级保留，恢复后无需重新导入即可使用。快照或清单损坏、校验失败时，该书显示为不可用并说明原因。书目、嵌入设置等列表中的其他书照常显示和使用，用户数据也不会被自动删除。

## 版权与隐私

- [ ] 导入前提示：只导入用户有权使用的内容，导入内容仅供本机个人使用。用户须确认后才能导入。
- [ ] 导入的原文、故事卡和向量只保存在本地书库，不随应用发布，不上传到拾趣的任何服务，也不进入官方故事卡或向量包。调用文本模型时只发送完成当前任务所需的章节。
- [ ] 制作的故事导出时保留用户填写的来源与授权说明，并标明原文为用户导入。用于公开发布的导出要求已填写授权说明。

## 「其他」书的旧路径

- [ ] 已保存的「其他」任务（书名或 URL、模型推荐的未核对候选）继续可以打开、查看、暂停、继续和选择，行为不变。
- [ ] 新建故事时，「其他」书引导用户导入；不导入的书名仍可用现有的未核对推荐路径，界面明确标为「未核对原文」。

## CLI 与技能

- [ ] CLI 支持导入、查看和调整结构、确认、预估并生成或取消故事卡、建向量索引、列出和删除导入书，使用与应用相同的生产实现。内置 `skills/shiqu/SKILL.md` 和使用示例同步更新。

## 约束

- 遵循仓库规则：生产工作流唯一，测试和评估复用；书库访问先经 `ensureLibraryReady()`；不在用户真实书库上做迁移或破坏性测试。
- 原文只读，不修复字形，不繁简转换；故事卡和向量只提供候选，出处始终由本地原文核对。
- 现有内置书、内置故事卡、向量库、已保存故事及 `bookId:'other'` 任务保持兼容。

## 非目标

- 不支持 PDF、扫描件或 OCR，不支持有 DRM 的电子书。
- 不爬取整站或自动跟随目录链接，不定期同步网页更新。
- 不在多台设备或多个书库之间共享导入书，不提供公开分享或上传。
- 不修改内置书及其故事卡制备流程，不为导入书发布官方向量包。
- 不制作桌面安装包或发布应用。

## 已定决策（2026-11-13 用户批准推荐方案）

1. 「其他」免导入路径保留，界面标为「未核对原文」，并以「导入这本书」为主操作。已保存的「其他」任务不受影响。
2. 导入书在整个书库内可见。应用只有一个使用者，与故事卡向量库的范围一致。
3. 应用内导出（个人 ZIP）始终附上来源与授权说明，并标明原文为用户导入。用于公开发布的导出（`pnpm export:story`）要求导入书填写了授权说明，否则拒绝导出。
4. 大小上限：单个文件或单个网页不超过 12 MB，整书不超过 300 万字，最多 2,000 章。
