# 故事生成状态机落地

> 已被取代：见[制作 DAG 需求](../21/req-data-driven-production-dag.md)。涉及原约定「确认后的修订提交即恢复、原有引擎继续编排」。普通修订有待做工作时等待读者继续。确认后的编排、审片和绘图由制作 DAG 调度。 [保存、暂停与继续](../../../../story-production-dag.md#保存暂停与继续)

> 本需求调整的先前决定：[暂停编辑与重选](../../10/31/req-paused-editing-latest-version.md)曾把确认后重选作为独立故事，本文改为同一家族内替换。

变更前，重选会多一本书，显示名改动可能重复绘图，完成后的丢图没有可用恢复路径；普通失败、审核阻断和用户暂停混在会话状态中，恢复请求也没有持久的故障实例与授权身份。

以[已审状态机](../../../../story-generation-state-machine.md)为完整行为规格，更新生产流程。设计审查通过不等于这些行为已实现。

## 验收

- [x] AC1：制作确认后的替换选题使用同一家族、同一书架卡片；只打开或取消重选不提交版本。旧原文、分镜、图片、审核与失败记录保留历史，旧版不再领取新付费工作，在途成果只保存旧版。
- [x] AC2：替换继承原子提交时的控制状态与生成方式；paused/stopped 不偷偷准备，点击“恢复准备”后只准备，仍需确认制作。新版不继承旧选题故障；取消只读刷新家族当前版，不回滚快照或恢复删除。
- [x] AC3：普通修订与替换共用原子基版校验；同一基版并发提交最多一个成功，过期编辑拒绝并保留草稿。重放不另建版、不重新激活或复活历史。收藏/阅读位置与图片保存不制造编辑冲突。
- [x] AC4：显示名、署名、收藏和阅读位置不改变生成任务身份；绘图中改名不重复调用，普通失败后改名/刷新/暂停恢复不重试。
- [x] AC5：图片加载失败后服务端按版本、幅号及图片身份核对；暂时不可读不当作丢失。确认失效后撤销完成声明、保留正常图片；文件恢复只核对复用，明确授权才重绘。
- [x] AC6：恢复按故障范围和真实依赖放行，多幅失效可逐幅恢复；已生成但发布失败只重试保存。首幅失效阻止新的依赖绘图，不清空正常图片或丢弃在途成果。
- [x] AC7：故障有不可复用实例身份；所有启动/恢复/控制命令持久幂等。请求绑定用户、版本、输入、动作与故障；并发领取同一故障最多一次。响应丢失重放不再排队或重置额度，普通再次失败产生新实例、旧实例退出待处理并保留历史。
- [x] AC8：受理与登记恢复工作原子或可幂等接续；重启不漏排或增权。中断重放共享最多3次尝试，人工续修20轮额度也只建立一次。旧版、暂停、制作确认和审核门槛不能被恢复绕过。
- [ ] AC9：会话执行、用户控制和故障集合独立投影；恢复运行可同时显示其他故障，局部成功不清其他原因、不提前完成。暂停和失败原因都可见，健康completed无需恢复生成。
- [ ] AC10：按钮名称与规格第8节一致，区分选择并替换、恢复准备、开始制作、应用修改并恢复、重试准备、重试保存图片、重新检查图片、按幅重绘；只读和关闭编辑器不授予执行权限。
- [ ] AC11：生产API、正式队列及原有引擎实现上述行为；受控测试复用正式工作流，不另造功能管线。完成规格第9节场景、相关回归、类型/lint与应用内浏览器验证，含手机宽度。
- [x] AC12：更新状态机与开发/使用说明，准确区分已交付能力和历史兼容；迁移保留现有作品与成果，不重审或重绘真实书架内容。

## 边界

不扩充生成题材、模型或配音能力；不更改审核质量标准；不打包Docker/桌面、不使用真实付费调用、不推送。用户明确要求完整RPD，允许本任务本地里程碑与最终提交。仅纳入本任务变更；进入时三处状态机相关文档属于本任务已有上下文。
