# 轻量书架与按需分镜

- [x] 首次加载只返回可显示书架与最近阅读的摘要，不传完整分镜、原文、提示词或制作耗时；列表继续按最新版本和读者权限过滤，保留阅读进度、收藏、分组和待处理状态。
- [x] 打开、续读和重读时加载该篇完整分镜，保持桌面停靠与移动阅读行为；快速切换或退出时不接受过期详情。
- [x] 后台刷新只应用变化项，保留跨窗口的新稿、版本更替和删除；无变化时不重传列表或分镜，普通读取不启动制作。
- [x] 在同一个真实书库快照上比较修改前后浏览器首屏与接口耗时、体积，核对完整分镜按需加载和增量状态更新。

保持现有详情和旧列表接口，避免数据库迁移；用隔离书库进行测试，不触发付费推理。
