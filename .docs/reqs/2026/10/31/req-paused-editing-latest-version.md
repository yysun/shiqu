# 暂停后可调整，书架只留最新版

故事生成方向不对时，暂停必须给用户纠正机会。现在编辑入口受制作阶段限制，确认后到完整分镜保存前无法修改；修订又作为独立故事出现在书架，用户改一次就多一本。

目标：暂停 → 修改 → 保存（仍暂停）→ 明确继续；同一故事只有一张书架卡片，始终代表最新提交版本，旧结果在后台保留。

## 验收
- [x] 准备原文/推荐幅数阶段暂停后，可以重选故事、编辑制作要求、画风和幅数；编辑不启动任务，草稿保存不被正在收尾的工作覆盖。
- [x] 确认制作后，无论分镜尚未完成、审片中、已有部分图片或已完成，都能修改制作要求、画风和幅数；完整分镜存在时继续支持手动分镜编辑。未完成分镜须先暂停。
- [x] 保存暂停故事的修改后，新版仍暂停；明确恢复后才执行新设置。旧任务的迟到结果只保存到旧记录，不能覆盖新版；重试同一提交不重复创建或自动恢复已暂停版本。
- [x] 制作要求/幅数变化重新编排，画风变化在完整分镜已有时保留编排并重绘；图片继续按实际输入依赖安全复用。
- [x] 阅读端与桌面书架、计数、搜索、收藏和最近阅读仅展示每个故事的最新提交版本，包括尚无图片、暂停、失败的最新版；同名但独立创建的故事不合并；刷新/重启后保持一致。
- [x] 草稿编辑不生成版本；修订保留旧设置、分镜和图片及版本关联，收藏状态延续。删除最新版不会让旧版重新出现在书架，恢复后仍显示最新版；不增加历史版本列表。
- [x] 确认制作后的“重新选择故事”创建独立故事流程，沿用书籍/主题/偏好；准备阶段可在已保存候选中更换选择；原故事与后台历史保留。

## 边界
沿用现有 SQLite 会话和 rootId/parentId/number 版本关系，不引入新数据库表、版本管理页面、迁移或新依赖。保留旧版直接读取能力及原有修订 API 默认继续行为；新增显式保存暂停行为。恢复生成作为单独动作。旧版未完成任务允许当前调用收尾，不再分派新增工作。

不构建版本对比、恢复历史版本 UI、跨版本进度映射系统或自动生成摘要。不开 Docker/桌面打包，不调用真实付费生成服务。仓库进入时的书架刷新相关未提交改动保留并排除提交。


## 验收证据
1. 准备暂停/草稿/重选：`tests/paused-editing-versions.test.mjs` 真实 worker 收尾保留草稿；`tests/unified-story-setup-ui.test.mjs` 真实组件输出包含暂停时四入口。
2. 无分镜/有分镜修改：暂停分镜真实集成 + 独立浏览器修改要求/水彩/3幅返回201且paused；读完后再改剪纸，第3版保留3幅分镜、0幅新图且paused。
3. 迟到/重放/继续：受控分镜回包、重启、顺序及两个交错重复提交用例；handoff CAS；浏览器明确恢复后3/3幅完成。
4. 失效和复用：现有 reader-revisions 的两 provider 图片依赖、风格/要求/幅数、拷贝隔离、审片修订全套通过。
5. 最新版：API 与共享桌面SQL实际结果一致；真实hook覆盖历史深链、删最新版读历史、恢复旧版；浏览器历史读取后仍3张，水彩旧版搜索0/3，剪纸新设置搜索2/3（另有独立重选故事）。
6. 历史/收藏/恢复：集成验证旧图保留及收藏/位置延续；浏览器删除后2张、刷新2张、撤销后3张且仍第3版，无第2版；版本列表入口0。
7. 重选：浏览器第3版暂停时重选，新增独立无revision的intake，继承庄子/放下执念/剪纸，调用图片数不变；原故事与独立同名故事保留。
