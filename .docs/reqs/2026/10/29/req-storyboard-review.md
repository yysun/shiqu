# 系统分镜导演规则与绘图前审片

当前提示能约束单幅、字数和景别，却仍可能把逐段说理写成连续站着说话的画面。用户要求改通用系统提示词，并明确将自动审片加入现有队列。

- [x] 目录、详细分镜和图像系统提示统一要求可见动作、空间与物件状态、信息揭示及因果递进；适用于所有故事，保持原文事实、画风和静态单幅约束。
- [x] 对讲述往事，允许有明确讲述归属的原文支持画面，避免一律站桩；不把指控、预测和未经确认的说法画成客观事实。
- [x] 新生成的完整分镜在绘图前进入独立全篇审片队列任务，两提供方均支持；检查动作、构图、重复、递进、连续性、画风与事实，只返回有实质影响的具体幅号及修订要求。
- [x] 仅修订审核指出的幅号，每次最多 20 幅，保存后重新全篇审核；固定元数据、目录事件、总幅数与未指明页保持不变。
- [x] 每次生成/手动继续最多自动修订一轮；复核仍不通过则停止并保存问题，不绘图、不自动重复扣费；用户可明确点击继续修订。
- [x] 审片、定向修订和复核可暂停、重启和失败恢复，不重复已保存的付费结果；旧会话已有完整分镜保持兼容，不自动追补审片。
- [x] 进度与手动继续入口能说明正在审片/修订、已通过或待继续修订；程序格式检查不宣称为视觉质量保证。

本次不重做东郭故事，不发起真实图片或真实故事改写；使用受控模型输出验证队列和恢复。没有模型切换、数据库结构迁移、图片审核或新队列池。
