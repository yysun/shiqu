# Story frame count

固定 8/10/12 幅会在拆故事前强行压缩叙事。默认让模型按事件、因果与转折编排；需要控制篇幅时，读者可以指定目标幅数。

## Acceptance

- [ ] 新故事默认自动决定幅数；模型以 30–60 幅为常见故事的参考，允许短故事少于 30 幅，不为凑数重复画面；输出安全范围为 1–60 幅。
- [ ] 生成前可切换自动/指定；指定提供同步的滑块与数字输入，支持整数 1–60，1 幅显示“单幅”；切回自动不丢失手动选择。生成中禁止修改。
- [ ] Gemini 与 Codex 都接收相同模式约束；指定模式严格校验幅数，自动模式保存模型实际分镜数。失败、重试及重启复用已保存分镜，不重新决定篇幅。
- [ ] 1 幅与 60 幅可按需生成、读至最后一幅、保存/恢复进度、记录阅读事件及读取图片；保持首图参考与后续三幅批次机制。
- [ ] 现有 8/10/12 幅故事保持可读可恢复；不修改已开启故事的分镜；无需数据库迁移。

## Boundaries

仅改读者端新故事的篇幅配置与相关生成/阅读边界。不增加生成前分镜审批、不重排现有故事、不改管理端故事编辑规则、不扩展音频、不调用真实付费生成、不构建 Docker。保留现有工作区的桌面、图标等改动。
