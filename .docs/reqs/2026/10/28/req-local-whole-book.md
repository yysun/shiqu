# 本地整书选题与原文约束

用户已确认 24 本目录。先整理并将可复现的书籍资料纳入 Git，再为《庄子》《世说新语》接通整书输入、按主题选题、本地核对出处、最后生成分镜的流程。

- [x] 24 本仅将首选原始下载件、出处、版本范围、哈希与已知问题纳入 Git；按用户最新决定，模型直接读取原文字形并输出简体，不转换输入或重复提交 TXT。重复对照和中间文件移到忽略目录保留，运行数据库、媒体、凭证不进入 Git。
- [x] 两本书的每次选题请求包含完整本地正文及可引用的稳定篇章/段落编号，不能用模型记忆或外部书籍 API 替代。
- [x] 服务端核对候选的书籍版本、篇章和连续原文范围；无效、跨篇、过长、含不可读字形的候选不能进入分镜生成。
- [x] 客户端随选题保存并提交出处编号；换书、主题、批次时清除过期选择，旧缓存不能绕过本地核对。
- [x] 核对的本地原文先保存，再发起分镜请求；分镜只接收选中原文，不重发整本；失败和重试保留已保存原文及已完成图片。
- [x] 两种现有生成提供方均支持以上流程；其他书籍、已有故事、原文回看、补全和重试合同保持可用。
- [x] Node 开发、生产构建和 Docker 运行都能加载随代码发布的只读书库，不依赖运行数据挂载目录。
- [x] 有针对性的自动化回归、全部现有检查、可执行流程验证与证据；明确区分模拟模型与真实模型验证。

非目标：RAG、向量库、语义检索、将其他 22 本接入本地生成、推送 Git、全量校勘古籍、重新设计发现页。
