# 故事修订与最少重做

已完成故事无法修改；直接清空结果重跑会丢失原版并重复支付无关任务。读者应在现有制作流程上编辑、预览影响，一次提交为独立修订版本，旧版始终可读。

- [x] 原文固定；通过现有弹窗编辑制作要求、画风、画幅数、分镜配文/提示词/人物设定/余味，修改先留在草稿，统一提交。
- [x] 提交前显示重新编排、审片、需重绘与复用幅数；无变化不提交；画幅数与全篇手改分镜冲突必须明确处理。
- [x] 制作要求/幅数变化重编排；仅画风或分镜变化复用编排并重新审片；配文/余味单独变化保留图片。
- [x] 依绘图实际输入（画风、全局制作要求、人物、该幅提示词、第一幅参考）复用原图；审片修订也重新计算失效范围；不以整个 Plan 的哈希强制重绘所有图片。
- [x] 保存为独立 session 修订版，记录父版/根版本及版本号，原版不被覆写；相同请求幂等、并发过期草稿冲突、所有权和来源权限均受控。
- [x] 队列仅执行缺失任务；修订仍先审后画，失败重试沿用当前机制，已保存结果不重复调用。
- [x] 原图复制进新版自身媒体空间，删除父版仍能阅读/导出新版；旧版晚返回只写旧版。
- [x] 阅读设置和生成状态可以返回原版；书架保留新旧版本；运行中父版在提交修订后暂停新增任务，已开始任务可完成保存。

不更换原典、不新增推理档位、不修改发布版本号，不实际触发未获明确操作的付费整篇重绘。真实 UI 验证使用本地受控 fixture，真实《大葫芦》仅检查编辑和取消。
