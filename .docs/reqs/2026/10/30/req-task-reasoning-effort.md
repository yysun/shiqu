# 按任务分配推理预算，并用旧《大葫芦》验证审核效果

统一推理档位把选题、编剧与质量审核混为一谈。审核漏检还会把坏配文带入昂贵的绘图阶段。用户已授权拆分配置及真实 medium/high/xhigh 审核对比。

- [ ] 画风默认 low；选题、画幅建议 medium；全篇提纲、详细分镜、审核/复核及修订 high。任务标识显式传递，不能靠提示词猜任务。
- [ ] Node/Docker 环境及桌面设置可以分别覆盖任务档位；旧设置可读取，无关配置与密钥不变。Codex 原全局档位保留给未分类/绘图调用，文本任务以新配置优先。
- [ ] Codex 每个任务使用独立请求配置且校验生效，不共享可变档位；Gemini 传入对应 thinkingLevel，不把 xhigh/max 静默降级。连接检查不产生推理调用。
- [ ] 生成记录保留任务实际采用/请求的档位及原用量；会受推理配置影响的选题/画风缓存不混用。
- [ ] 使用备份中的《大葫芦》原版 20 幅分镜，固定原文、制作要求、新审核提示、模型，medium/high/xhigh 各真实审核一次；不提供已知问题答案，不生成图片或修改书库。
- [ ] 保存输入/提示哈希、实际模型及档位、报告、用量、耗时、失败，并比较机械转述、含混表达、信息不足与误报；明确单故事单次试验的证据边界。
- [ ] 受控测试、类型/lint、原生配置测试与应用内桌面预览通过；无打包、Docker 构建、推送。

不扩展为多模型评测平台，不自动重做旧故事，不自动升档，不修改已修好的配文和原图。真实对比使用现有 ChatGPT 订阅，无 OpenAI API 密钥。
