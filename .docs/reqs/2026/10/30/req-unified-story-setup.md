# 选好故事后统一使用流程与编辑窗口

选好故事后的确认页重复铺开候选、画风、要求和幅数，用户很难看清当前步骤。改用现有流程展示与编辑窗口，取消额外的“叙事详略”选择。

- [ ] 新建故事选定后，以同一制作流程展示状态；原文、制作要求、画风、幅数从流程进入对应窗口，分镜与绘图仍显示未开始。
- [ ] 制作要求、画风和幅数复用故事修订的编辑内容和标签页；不是另一套重复表单。保留最近完成的紧凑画风选择。
- [ ] 候选收进“重新选择”，后台继续保存批次，界面累计列出全部候选并可继续查找。切换候选携带当前手改设置，继续遵循原文/建议世代隔离。
- [ ] 不再显示叙事详略；旧记录已有值不被清空，也不改变服务器契约和队列语义。
- [ ] 本地编辑和关闭窗口不开始生成；重新推荐幅数显式保存并排队。只有最终“确认制作”提交最终设置并释放生成门槛。
- [ ] 原文窗口复用现有内容组件，在plan尚未产生时只读取已保存原文，不偷偷补全或触发付费。
- [ ] 已有故事修订、旧幅数确认和叠加弹窗关闭/滚动/焦点保持可用；IAB使用隔离受控库验证，无真实付费或打包。

用户继续明确三段界面：
- [ ] 书籍、主题选择页不出现制作要求；加入队列后独立“选择故事”窗口只呈现全部候选与继续查找，不与制作确认混排。
- [ ] 首次选题与“重新选择”复用候选界面；选定后进入制作流程，编辑入口与最后确认门槛保持。

用户进一步决定统一入口：未确认制作的任务在当前任务内重新选择；已有生成故事也提供“重新选择”，沿用已保存书籍、主题与制作偏好建立独立新选题任务，原故事保留。两者共用候选窗口与制作流程。

- [ ] 已有故事重新选择先成功持久化新任务，再切换界面；失败时原故事页面、收藏、进度及当前阅读会话不被清空。重复点击/丢失响应沿用既有创建幂等，不提交原故事修订或改写原图。

- [ ] 未完成故事卡片去掉重复的行动文字/箭头行，卡片主体仍可点击打开对应窗口，收藏/删除/暂停独立；不额外保留空行高度。

- [ ] 查找更多候选不会丢失已选故事的制作准备状态：已有合法选择、原文和幅数建议时，提取结束返回待制作确认。旧记录出现choosing+已准备组合时，阅读/书架/桌面显示及后续操作一致恢复，不额外读取原文或付费推荐/编排/绘图。

- [ ] 选择故事不再显示“第几批”下拉；全部已找到候选按发现顺序累计显示，继续查找只追加，选择任一项仍使用保存的准确batch/index及出处，不把同名不同出处合并。

- [ ] 待确认的故事标题与流程之间使用紧凑间距，不沿用生成状态页的大块顶部留白。

- [ ] 删除制作确认页两条重复的确认前说明，最终确认按钮仍保留；“继续找故事”请求和后台查找期间都有旋转加载指示及文字，禁止重复点击，完成后恢复。
