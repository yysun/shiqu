# 新建故事先入队，创作意图不能丢

当前选题依赖页面状态，提取未完成离开后，书籍和主题对应的创作任务没有进入书架。应在开始提取前持久化任务，再逐步让读者确认制作内容。

- [x] 指定书籍、主题后点击开始：先保存 durable session（书籍、主题、已有制作要求），再由文本队列提取候选；离开、刷新、重启保留任务，可从书架继续。
- [x] 候选批次/已选故事及核对出处回执持久化。支持选择、回看、再找一批，等待选择释放工作位，不进行分镜或绘图。
- [x] 选择故事后保存原文、推荐幅数。制作确认页统一选择故事、画风、幅数和制作要求；不显示叙事详略，保留已存值；原文可查看，确认前不编排/审片/绘图。
- [x] 换故事清除该故事的原文/幅数建议后重新准备；改画风不重搜候选；修改制作要求可手动重新推荐幅数，或者明确确认自定数量。不能静默丢手改配置。
- [x] 所有动作 owner-scoped、输入有效、并发/CAS、请求丢响应与重复确认不会重复付费。旧直接生成和幅数确认 session 可继续使用。
- [x] 失败/暂停/恢复沿用已有队列；生成状态准确区分提取中、待选故事、准备中、待制作确认，候选少于5/空结果不假装已完成。
- [x] 不更改真实书库内容或发起真实付费验证；通过真实SQLite/FileMedia+受控provider和IAB完成创建、离开/刷新/恢复、选择、确认和绘图。

执行顺序（用户 !! 明确调整）：先完成队列流程，再更新流程显示与确认界面，最后将故事修改接到新流程并完成统一回归。不回退已保存的修订里程碑，修订收尾延期到第三阶段。

- [x] 审核/修复是循环：全篇审核 → 定向修复 → 全篇复核，未通过继续循环；默认最多自动修复3轮，无实际修改或到上限未通过时阻止绘图并待处理，手动继续开启新一段有界循环。保留每轮问题/修订历史与精确轮数，配文与原图复用规则不变。
