# 故事制作流程：内容不丢、流程不卡、信息真实

本应用只有一位所有者，也没有计费系统；模型调用仍占用所有者自己的 Codex 订阅或 Gemini 配额。队列核心已能隔离旧任务、保留结果，但围绕它的创建和修改流程仍有缺口：正在绘制的故事上写好的草稿提交不了，审片受阻的故事走投无路，查找更多候选会打断已选故事，正在查找的任务停不下来并占住唯一的文本工作位，预览的重绘数量可能与实际不符。

## 修改故事

- [x] 正在绘制的故事上，图片完成和其他进度保存不使草稿失效。只有制作要求、画风、分镜、人物设定、余味或版本家族发生变化才算冲突；提交时按当时已保存的原图计算复用。
- [x] 发生真实冲突时，草稿内容仍留在编辑窗口，只有读者明确选择才丢弃。重新打开编辑窗口时刷新基准：相关内容未变则保留草稿，已变则显示冲突并保留草稿，不把草稿自动合并到新内容上。故事的首图到达不清除草稿。
- [x] 已有完整分镜和原文、但尚无首图的故事（含审片受阻）可从制作流程查看全部分镜，并通过现有编辑窗口提交新版。查看和编辑不产生模型调用，原故事保留。
- [x] 审片受阻的故事显示全部未解决问题，并提供“仍然绘制”：读者明确选择后不再审片、直接进入绘图，流程显示这些问题由读者确认放行。重复点击和丢失响应不产生重复效果；已暂停时会被记录，恢复后才绘制。
- [x] 原图丢失或损坏不阻止修改：丢失的图片按不可复用处理，新版照常创建并重绘，其他可复用的图片不受影响；首幅是全篇参考，首幅丢失时全部重绘。原图暂时读不到（非丢失）仍不创建新版，提示稍后重试。
- [x] 重绘预览如实：预览文字说明审片修改画面指令会增加重绘，首幅变化时全部重绘。实际需重绘幅数超过提交时预览的数量时，新版的制作流程显示实际数量、预览数量和原因；不增加确认步骤，读者可用现有暂停。预览未作出数量承诺的修订不显示此提示。

## 选择故事与制作确认

- [x] “继续找故事”不改变已选故事的准备和确认状态：查找排队、进行中或失败时，已准备好的故事仍可确认，排队中或进行中的准备不被取消。查找不因换故事或重新推荐而中断，结果继续累加到候选。
- [x] 查找进行中可以选择已找到的候选；查找不占用故事的工作锁。
- [x] 确认制作结束本轮查找：排队中的查找取消；进行中的查找在当前调用结束后停止并保留进度，此后不再追加候选。
- [x] 查找失败只影响查找：显示失败原因和“重试查找”，候选和已选内容保留，故事不进入整体失败。读者可不重试直接继续；重试查找不重新执行其他失败的任务。
- [x] 点击已准备好或正在准备的已选故事只关闭选择窗口：不清除原文或幅数建议，不产生模型调用，不丢失未保存的编辑。已选但没有幅数建议、也没有排队或进行中的准备时，页面提供明确的“准备这篇”操作。准备失败时只显示一个操作（重试），不同时显示“准备这篇”。
- [x] 手动设置的幅数、画风和制作要求在“继续找故事”、离开和刷新后保留，并在确认时显示；保存这些设置不打断进行中的准备。幅数只有换故事或明确重新推荐才重置。
- [x] 换故事时，读者未手动改过画风则采用新候选的画风推荐，手动改过则保留。沿用推荐不算手动修改。旧记录已有的手动标记无法区分来源，继续保留当前画风。
- [x] 手机和电脑共用书架：等待选择或确认时能看到另一设备的最新内容，这种同步不产生模型调用，也不丢弃未保存的编辑，由读者决定保留还是采用最新内容。操作因内容过期被拒后，依据最新内容重新操作可以成功，不需刷新整个页面；响应丢失后的重复提交仍然幂等。

## 队列

- [x] 查找进行中暂停、删除故事或服务停止后，不再发起新的模型调用，Codex 与 Gemini 一致；已开始的单次调用结束后保存进度，释放文本工作位。恢复或重启时从已存进度继续，不重读已完成部分。其他请求共用同一提取时不受影响；队列发起的调用，重叠不超过文本工作位。被服务停止杀掉的调用按中断处理，受现有自动重放上限约束。
- [x] 手动重试只恢复当前选题世代的任务；旧世代任务不重新排队，也不再每轮占用调度和恢复检查。查找不受选题世代限制，换故事后仍有效。没有选题世代的故事行为不变。
- [x] 已暂停故事的服务异常退出后，过期的工作锁不阻止选题操作，也不把暂停改成运行；明确确认制作仍会启动生成。暂停时发起的查找显示为等待恢复，不显示为进行中。

## 约束

- 所有动作保持输入校验和幂等；旧的直接生成、幅数确认、修订记录和已保存候选继续可用。
- 升级不增加模型调用：旧记录已排队或中断的查找按新流程继续，同一查找不因新旧任务并存而执行两次；旧记录已保存的查找失败转为只影响查找，已准备好的故事无需等待即可确认。
- 原版和已生成图片不被覆写。
- 阅读页、书架和桌面摘要对查找失败、查找进行中的显示一致；查找失败不显示为故事失败。桌面摘要在服务启动前也能读取升级前的书库。
- 复用现有流程展示和编辑窗口，不新增一套表单。
- 通过真实 SQLite/FileMedia 和受控 provider 验证调用次数；界面在隔离书库的 in-app browser 验证。不发起真实模型调用，不构建 Docker 或打包桌面应用。

## 非目标

- 不增加重绘或丢图的确认步骤，也不增加用量或费用展示。
- 同一父版上的多个修订继续并行运行；从父版再次修订不暂停已在运行的另一版。
- 新版审片通过前已复用的图片仍可阅读和导出。
- 不改变审片和修复的提示词、三轮上限、画风选项、文本工作位数量及优先级。
- 不在原故事内修复丢失的图片，也不提供无修改的修复提交。
- 不清理历史归属字段；所有者仍是固定值。

## 已定决策

- 无计费系统，确认步骤不再有保护费用的理由：超出预览的重绘和丢图重绘都如实显示后直接继续。
- 所有者可以覆盖审片结论：只影响自己的故事，避免模型反复不通过时无路可走。
- 确认制作结束查找：结果已无法选择，并释放文本工作位。
