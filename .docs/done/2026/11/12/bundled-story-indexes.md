# 内置书籍索引随版本发布

18 本书的 12,661 张故事卡随内置原文进入 npm 与桌面资源。卡片保存标题、梗概和原文范围，源文件共约 4.8 MiB，gzip 压缩约 1.8 MiB。完整向量按书制备，共约 187 MiB，gzip 压缩约 163 MiB，其中《太平广记》约 74 MiB。用户可用 `books index-install` 安装指定向量包，桌面与 CLI 共用按原文版次分隔的系统缓存。

匹配版次的手动导入及旧索引继续优先。官方向量按原文范围补充内置故事卡。缺失、损坏或错版时继续用内置卡和原文。新备份排除官方资源，手动索引仍随书库保存。18 个可选资产已两次制备出一致的字节，并校验 SHA-256，待维护者附到对应版本的发布页。
