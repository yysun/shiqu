# 制作流程续作与确认

从书架重开任务可续选持久化候选。确认前校验草稿指纹，沿用已有动作回执和数据库原子检查；无需迁移书库。确认前后共用原文、准备和确认步骤。修订预览报告预计复用，暂停书架卡显示所在阶段。

## 验证

VR passed: all acceptance criteria complete

- Chrome 中从书架打开已有任务，显示 50 条候选。选中后可进入准备，换检索方式后隐藏原候选，切回可恢复。勾选两章时显示合并提示。
- 隔离书库验证旧草稿不能覆盖、旧格式兼容、显式清空验收要求、动作重放及 CLI 确认重放。
- 共享步骤测试覆盖直接选材、合并原文和候选三种入口。书架测试核对暂停阶段和实际绘图计数。
- 通过 `pnpm test:changed`（435 项）、专项检查（73 项）、类型检查、lint 和 13 项本机原生源码测试。版本交付由标签工作流执行。
