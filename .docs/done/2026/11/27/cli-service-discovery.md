# CLI 启动并接入书库服务

## 摘要

CLI 查找同库的持锁服务。书库空闲时，CLI 自动启动仅监听本机的短时服务。桌面、浏览器和 CLI 共用书库操作与制作调度，保存命令和审片停点保留明确的继续授权。
