# 横图制作、套图管理与打印交付

## 变更

- 首次制作和另绘横图都从画风弹窗确认。每套保存自己的画风和进度，横图与竖图独立。打印缺图时可直接进入制作。
- 制作步骤直接列出套图，画风、进度和操作同行。已完成及已收尾的未完成套图可按套确认删除，正在运行的任务受到保护。
- 横版与 Letter 双面 PDF 可指定套图，包括历史套图和未完成试印稿。制作和打印选择均省去时间戳，同画风多套按现存顺序编号。
