# 主题核对与逐书索引

手动选原文时，拾趣列出章节，按章名和原文中的关键词过滤，支持勾选整章。主题提取最多召回 50 条原文范围，再用故事提取所配置的文字模型核对。明确命中排在情节暗示之前。长原文按输入预算拆批，已核对的判断写入磁盘缓存。

离线脚本可按书制备索引。`books index-import` 校验书名、版次和出处，再替换数据目录内对应书的索引。索引随书库备份与恢复，保存故事及制作记录的 `shiqu.sqlite` 采用原有格式。缺向量时使用文字匹配，缺索引或候选时读取已选范围的原文。
