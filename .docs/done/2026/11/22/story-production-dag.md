# 制作 DAG 切换

## 变更

故事制作改由数据驱动的 DAG 执行，涵盖选题后的准备（原文核对、候选画风、梗概核对、制作建议）、提纲、分镜、审核、修订、绘图与横图。修改后只重做依赖它的部分，故障只阻断依赖它的工作，流程图由登记表生成。

- 保存需要重做工作的修订后显示「已保存，等待继续」，用一个「继续制作」文字链接开始；影响说明来自服务端预估（复用/重绘幅数），与保存共用同一计算。
- 手改默认保护；制作要求变化会丢弃手改时，编辑器内联拒绝并保留草稿，提示指明幅数（例如「第 3 幅的配文」），不再显示内部编号。
- 旧版准备任务、数字幅数故事和升级前的中断、故障由运行时接管。升级经整库备份，可由配套的 v0.14.0 恢复并打开。
- 「生成横版插图」改为任务清单内的文字链接，与重试一致。
- 已同步状态机文档、DAG 调用契约和内置 CLI 技能。
