# 本篇画风提示词

## 变更

- 在制作确认和故事设置的画风页显示所选预设的提示词原文。可直接编辑、查看系统默认和恢复默认。切换画风使用新预设的默认文本。
- 本篇提示词随制作草稿和故事版本保存，进入分镜编排、审片和竖图、横图的绘图请求。CLI 的确认和修订支持 `artStylePrompt`，显式传 `null` 恢复默认。
- 已完成故事只改画风提示词时，沿用分镜编排和审片记录，制作新版时重新绘制全篇。原版可供对照。
