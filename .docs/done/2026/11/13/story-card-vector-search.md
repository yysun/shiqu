# 简化新建故事选题

## Summary

书架、发现和「修改提取条件」共用原选题页。选书后，可在同一行切换按章节、按故事和按主题。主题列表的「其它」接受自定义主题或情节。点击「开始找故事」后，有向量时把主题或情节转成 Embedding，按相似度召回前 50 张故事卡并直接展示候选。无向量时，模型每批读取 10 张卡的标题和梗概，对每张卡返回是否符合。新故事自动拟题，已有名称可在故事设置中修改。

## Verification

- 类型检查、Lint、手机与桌面选题端到端场景通过。覆盖关键词筛选、无向量时按故事卡检索、跨布局草稿保留、返回行为和修改提取条件时保留已改过的名称。手机可读性复跑通过。
- `pnpm test:changed` 通过，书库完整性检查 5 项、变更检查 1506 项。
- 桌面原生测试首次并行运行有一项目录锁测试失败。串行重跑 26 项全部通过。

## Notes
