# 故事关键词筛选与分页

## Summary

故事制作页的关键词继续由目录接口在服务端筛选。目录接口新增 `limit`、`offset` 分页参数和匹配总数；故事选择器每次请求 20 条，滚动到底自动读取下一页，并显示“共 X 则，已加载 Y 则”。三种检索方式按钮保持紧凑排列。

- 故事关键词由服务端筛选。制作页请求目录接口的 `q` 参数；接口先完成筛选，再根据 `limit` 和 `offset` 返回页面，并提供匹配总数。API 测试验证筛选结果与完整查询一致。

- 三种检索方式按钮紧凑排列。样式改为左对齐按钮组，缩小按钮之间的留白。
