# 分镜核心表达、原文对白与事实边界审核

## Summary

生成目录与详细分镜先按原文中的关键言行、回应和关系变化分配画幅。合并或删幅前检查会损失什么，允许有价值的沉默、端详与反应独立承载叙事；不靠加长旁白补救关键戏被压缩。

审核按“核心含义 → 分镜轻重 → 事实与连续性 → 语言”检查。修订指令必须指明改哪句、保留哪句对白，或画谁在什么动作之后作出什么回应；允许在明确列出的相邻幅范围内重分配原有事件，不改范围外的幅。人物对白可直接采用已核原文，现代旁白要求不再强制改写人物口气。事实检查与修订共用条件范围、判断归属规则，避免把假设写成现实、把人物的感受或指控写成客观事实，同时允许合理省略和已证实事实的直接叙述。

## Notes

提示词只规定通用的条件、适用范围与判断来源检查，不写故事名、人物、物件或目标幅号。已经明确的叙述语境可以自然承接；原文明示或独立事件证实的事实无需降成猜测。

本篇验证证明新增规则能够检出已观察到的两类漏检，不能据此宣称跨故事稳定检出或低误报率。其他故事的新旧审核对照尚未执行，作为后续验证继续。不同提示词版本的生成样本和复用回执均在证据中区分，不将一次审核通过当作分镜质量保证。
