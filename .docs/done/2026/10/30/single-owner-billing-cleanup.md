# 单机书架计费残留清理与旧缓存哈希修复

## Summary

应用已使用固定本地书架，没有按用户扣费、扣 Token 或限制生成次数的业务逻辑。本次移除旧后台的制作费用录入、成本统计、广告收益试算和故事接口中的费用、币种字段，清除无效登录判断，取消生成书架只返回最近 80 篇的截断。

重试操作改由原文检索、图片展开、审片和重绘阶段决定，不再使用 `retryMayCharge`。旧版已保存的重绘错误仍可识别并正确恢复；生成记录、模型用量、任务锁、并发及自动重试保护继续保留。

新增白描画风曾使旧缓存引用的当前画风定义发生变化，导致历史缓存键漂移。现已固定 v2 缓存的历史画风结构和提示词，恢复原有哈希断言，当前推荐继续支持白描画风。
