# 桌面复用书库服务计划

Git base: `66aef878`

桌面和 CLI 共用每库已有的回环发现、实例校验和 HTTP 控制连接。保留桌面的 Node stdin 控制帧；它先向已有端点请求接入，无可用持锁服务时启动本地服务，接入时只转发状态与控制指令。桌面控制通道不持有书库数据库。浏览器服务保持当前地址和设置。自动进程先结束已接收的命令，然后以桌面设置在原持锁进程中打开阅读器并停用空闲退出；遇到端口或启动错误，恢复原状态。浏览器进程退出仍由原进程清理。桌面重启先等持锁进程释放，再按已保存设置启动。控制协议仅新增可选能力，无数据库迁移和公开参数改动。

桌面正常退出及显式强停通过已经认证的实例发指令；接入通道异常断开只解除连接，保留已有服务。已确认的停服继续执行。自动进程收到接入请求后同步保留现有实例，暂停空闲计时和新命令接收，等已接收命令收尾。接入连接断开或初始化失败时还原原有空闲与派发策略；书库所有者和命令地址不变。桌面控制只对支持当前控制协议且版本一致的进程启用。

浏览器接入先请求能力和状态，不提交配置。仅经校验的自动进程返回可启用阅读器时才提交桌面设置；进程身份在提交前再次核对。浏览器地址取实际绑定的本机 IP 与端口，默认通配绑定使用回环地址；原生只打开认证控制进程给出的本机 IP 根路径。自动进程处理已有命令期间，桌面按原启动协议持续发启动进度；EOF 取消待接入操作，不让迟到的接入把独立自动服务变为常驻。原生 `.desktop.lock` 仍限制桌面控制台数量。构建 npm 分发包运行冒烟，桌面沿用源码入口和已提交资源覆盖做原生检查，不构建安装包。

- [x] 首个探针：现有浏览器服务遇到桌面启动时返回占用；冷 CLI 并发按原规则复用临时进程。单个持锁者是两条路径共同的边界。
- [x] 扩展现有 CLI 发现/身份校验机制，支持可选的本机桌面控制。只向已验证的实例发送接入和控制，不转发到失效进程或陌生端口。停止之前先交付回复。
- [x] 复用 `startDesktop` 的应用、阅读器和调度，在自动工作进程中启用桌面服务。原进程、锁和 CLI 控制地址保持；在途 CLI 命令先收尾；取消或失败释放临时接入意图。更新旧服务发现的兼容处理。
- [x] 桌面 stdin 入口发现、接入和管理现有服务；本地服务和接入服务沿用相同状态帧。处理退出等候、子进程异常及强停取消顺序。停服中断发生在 CLI 派发前时恢复原授权。
- [ ] 同步使用指南、开发指南、内置技能和相关示例；用临时书库和受控提供方从正式入口验证 PID、地址、停服、重启、在途命令和失败恢复。

AR 第 2 轮独立复核通过。直接运行浏览器 CLI 的用户仍可从该 CLI 终端停止服务；接入桌面只是另一个通过同一控制端点管理服务的入口。
