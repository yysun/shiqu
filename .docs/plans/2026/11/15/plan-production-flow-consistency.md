# 制作流程续作与确认实施

基线为 `d2d4607`（v0.13.1）。

- [ ] 给准备阶段的草稿读回稳定指纹，在保存、重新推荐与确认时和数据库当前草稿比较。用同一次比较并写入保留准备中的工作锁；使用现有触发器持久化动作回执，重放返回现状，另一次编辑后的旧请求不得覆盖。旧请求可编辑未修改的系统建议，或继续提交一致的已保存草稿。同步 CLI 和内置技能。
- [ ] 保留候选批次与批次内索引，通过现有选择动作继续；仅在原书、主题或章节范围仍匹配时展示，分开显示本次即时查询的结果。
- [ ] 共享准备前后的来源、准备、确认步骤。预览单独显示预计复用，不改变实际绘图计数；修正多选、书架、原文与分镜等关联文案。
- [ ] 复核与更新用户可见流程说明。跑隔离的跨客户端草稿回归、候选与时间线测试以及变更检查。同步 0.13.2 版本文件，通过标签门禁后核验桌面和 npm 发布。
