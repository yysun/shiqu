# 连环画场景叙事改进方案

实施基点 `5b5f9e4`。制作 DAG 已切换到正式入口，见[切换记录](../../../../done/2026/11/22/story-production-dag.md)。本次只调整共享提示词，复用提纲节点、逐幅画面描述、审校结论和绘图调用。同期改动按文件隔离验证和提交。

## 要解决的问题

连环画每幅是一张完整的画。人物、环境、光色与画材共同表现一个可见瞬间。读者需要看懂地点、身份、距离、阻隔或行动方向时，环境要承担相应的叙事工作。近景可以借一个局部交代处境，也可以把画面集中在决定性的动作或表情上。

《管鲍之交》第 4 版 14 幅的实际生图提示词都已包含绘画质量要求。第 6 幅会盟用两侧席位和中央通道表现规模和秩序，第 10 幅虽然画出了管仲在退走，战场和退路之间的关系仍很弱。第 1、7、8 幅的室内双人构图相近。《李宽量谷》的静室问答也有连续构图雷同的现象，《鸣镝指射》开场则用河岸、牧群和驮马讲清逐水草迁徙。这组样本表明，单幅绘画质量与场景能否讲清故事都需要验收。前者已有共用要求，后者需要从提纲安排到画面落地逐步落实。

## 提纲

- [x] 在 `outlineDirection` 中要求作者找出需要读者建立或更新空间认识的节点。重点检查开场、地点或处境变化，以及距离、地形、门槛、席次等直接决定行动或人物关系的时刻。沿用该节点原有的动作、反应或结果，在 `beats` 同一句内说明环境承担的任务。
- [x] 同一地点的连续画幅先在合适的节点交代布局，再让后续节点沿用必要的空间关系。必要的交代可以与动作合在一幅。按现有幅数策略取舍，固定幅数时在既有节点内完成，自动幅数仍按有据的叙事任务分配。全篇只有一幅时，核心动作与理解它所需的环境同幅交代。 [现有提纲规则](../../../../../lib/reader-storyboard.ts)

## 分镜

- [x] 在共用的 `storyVisualDirection` 中明确画面描述的写法。情节依赖场景时，先写核心瞬间和环境承担的信息，再用可见的地标、物件或空间边界，写清人物和它们的相对位置，最后写景别与焦点。把这些信息写进该幅 `prompt`，使每幅可以独立出图。配文继续负责自然讲述。
- [x] 远景交代有用的尺度、路径和群体位置。中景留足支撑互动的站位、间距和场所线索。近景按需要借局部物件、边界或光线说明处境。人物可以很小、局部入画或处于次要位置；入画名单仍只登记实际画到的人。前后幅写清同一场所的关键方位，允许为本幅动作调整视点。环境补足以时代和原文为边界，保留原文的未知、遮挡与揭示顺序。
- [x] 把同一标准用于正式画面描述和定向画面修订。确认负责配文的调用继续接收原有契约；跨批次依靠全篇提纲中的空间安排和逐幅自足的描述，相邻幅衔接由现有审校检查。换画风时核对原有构图、环境线索和人物位置得到继承。 [共用画面规则](../../../../../lib/reader-generation-contract.ts) · [制作调用](../../../../../lib/production-dag/calls.ts)

## 审校

- [x] 给现有全面文字审校增加一个可举证的问题。按提纲、配文、原文及相邻画面描述判断，画面缺少哪项具体环境或空间关系会改变读者对地点、行动、身份、处境或后果的理解。发现问题时写出幅号、叙事损失和最小修法，沿用现有画面问题和定向修订流程。
- [x] 连续对白用各幅的叙事任务判断是否需要调整构图。同一布局有助于连续阅读时可以保留；读者需要辨认场景变化而从前后幅看不出来时，只修承担变化的画幅。允许有明确作用的近景、单人画面和留白。全面审校继续判断文字分镜是否可执行。 [审校与修订规则](../../../../../lib/reader-review.ts) · [制作 DAG 审校范围](../../../../story-production-dag.md)

## 生图

- [x] 在 `imagePromptFor` 的共用绘画要求里明确保留本幅已规划的环境线索和空间关系。根据场景的叙事焦点分配画面面积，用明暗、色块、线条或笔触区分路径、边界和人物位置。为手机配文保留安静区域时，仍要保留关键地面、路径和远近关系。
- [x] 普通竖图与重绘按当幅分镜保留空间和取景，角色参考图继续用于身份与外貌一致性。印刷横图可按画幅比例重组空间，须保存同一事件、遮挡和关键方位。使用预设或自定义画风时都传递这条要求，表现手法遵循选定画材。 [正式生图模板](../../../../../lib/reader-generation-contract.ts) · [绘画质量要求](../../../../../lib/reader-prompts.ts)

首批改动应用于新制作。历史作品按原有修订入口处理。

## 验证顺序

- [x] 先检查正式 Codex 订阅运行器能否在隔离目录发起调用，记录就绪状态。正式调用受环境阻断时，继续完成本地证据，真实成图验收保留待验证状态。
- [x] 使用现有调用契约测试核对提纲、逐幅描述与修订、文字审校、换画风和竖横图实际收到了适用规则。按仓库规则运行登记的直接消费者与完整性冒烟，使用本次文件范围排除并行改动。
