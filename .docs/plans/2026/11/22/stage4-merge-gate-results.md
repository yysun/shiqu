- 已付费未发布的图片按输入版本和文件结构采用，合法横图同时核对比例。迁移对已发布的本地图片记录结构检查发现的损坏，保留原始路径和字节。若参考图能通过结构检查但无法解码，实际付费绘图前沿用生产解码器核对，故障记在参考画幅，待读者明确恢复。同步迁移未对整个书库逐个解码，未作为绘图参考的图片仍可由读取时的图片检查发现像素损坏。
- 故障按节点归属，恢复中的故障回到待处理，旧任务和回执按迁移规则收束。部分绘制、等待继续、已付费结果与损坏参考图的恢复均核对实际调用次数，已保存的有效图片没有重复绘制。

- 书籍星标用于之后派发的各幅，换画风或指定首幅原图的版本继续使用本篇首幅。替换星标保留在途调用、已保存图片和仍适用的已付费回执。
- 旧版原已获直接绘图许可的未完成成稿可补完缺幅，原版成稿的明确恢复可补绘损坏图。旧许可单独标记，保存修订、换图、指定首幅和复制仍遵守各自原有审核门槛。两阶段审核和摘要回归现均通过生产队列执行，断言持久检查点、画幅身份和实际调用次数。

## 完整故事的 DAG 验收清单

1. 通过书架或 CLI 选定原文与故事，保存准备结果，确认制作要求、验收要求、画风、幅数策略和模型快照。现行选题及确认前准备仍由 discover / prepare 协调器处理；有适用的已核原文、梗概和建议时，确认后的 DAG 直接采用。
2. 用 DAG 保存原文、范围匹配的事实梗概、提纲、人物、逐幅配文、画面描述、标题与结语。缺梗概时分镜等待；失败后重启只恢复缺失的节点，不重付已保存的结果。初次编排按确认的幅数策略进行。定长故事跳过幅数核对；自动幅数故事结构修订后重新核对。
3. 保存有效的逐幅和全篇结论。先局部修订，再只复核受影响的结论。需要读者放行时持久记录授权及其绑定输入。保存有后续工作的修订后，通过「继续制作」再次授权运行。
4. 绘图使用适用的书籍星标或本篇首幅，逐幅入库。所有必需节点和图片有效、必需故障已处理后，状态成为 completed。用阅读和公开导出回读确认。横图为可选产物。
5. 完成发布验收与用户确认。补齐 U2、U4–U6 的隔离浏览器核对，以及真实打包资源上的原生验证。格式 2 的发行版需为 0.15.0 或更新版本。用户确认后再合并。未运行实际提供方成本或真实书库验证的决定沿用此前范围。
6. 若要把确认前流程也纳入 DAG，另完成准备建议调度和确认草稿切换，保留旧版幅数确认和历史数据恢复边界。之后清理已证明无人使用的旧写入路径，并同步状态机、用户手册与由登记表生成的图。新增人物、验收条目和标题结语编辑控件仍属于已暂缓的范围。
