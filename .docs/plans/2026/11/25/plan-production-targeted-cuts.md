# 制作定向精简计划

Git 基线 `3d382bcd`。0.17.0 对照使用已完成版本准备的 `ee74292a`，测试使用隔离目录和相同输入。

## 实施边界

- 分镜合批保留原有提纲、人物、配文、画面描述的产物身份、内容结构和硬输入指纹。首批同时返回全篇提纲、人物和最多 20 幅。后续批次用已采用的提纲、人物与前文续写，分别记录配文和画面描述。合批使用独立调用名和完整请求指纹来核对回执身份与迟到结果；已有待续 0.17 稿件沿用原任务及回执，重新编排进入合批。合批执行期间排除同一产物的单独派发。单字段恢复、结构修订补齐画面、换画风沿用局部生成。定长仍做数量校验，不增加模型调用；自动幅数保留既有结构核对。绘图、审片、付费派发和接收仍走正式队列。
- 手改产物保留标记和内容，换画风只重做手改画面描述的画风部分并保留标记。清空手改字段解除保护并生成该字段，区别于采用家族中清空前的自动产物。预览与保存共享画幅身份判断，按旧幅号提供会丢失的配文和画面描述。保存使用与修订 token 绑定的一次确认。自动修订不得删改手改画幅，阻断说明列出实际受影响的原幅号。
- 新建库使用 0.17.0 初始化结果导出的 SQL 基线，保留同一组迁移回执和种子。既有格式 4 保留普通迁移、日志恢复和开发预览版的 0029/0030 修复，删去只为 1–3 使用的转换代码。版本为 1–3 的库须先用 0.17.x 打开，合并前导入也经该版本。验证拒绝时已有 WAL、SHM 和日志也保持原样。发布版后的普通迁移继续用原来的整库备份。Node 和原生读取共用格式声明与 0.17 升级说明。
