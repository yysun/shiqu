# 故事制作生命周期

生命周期说明当前版本处于哪个阶段、读者能做什么、一次授权覆盖哪些工作。制作 DAG 负责产物的有效性、就绪、依赖和免费复用。升级时一次性采用可用结论与产物，失败记录留在原版本。 [制作 DAG](story-production-dag.md)

## 状态和输入

| 维度 | 值 | 推导依据 |
| --- | --- | --- |
| 阶段 | 选题、准备、待制作确认、制作中、完成 | 选题与准备检查点、确认世代和 DAG 产物有效性。必需图片确认丢失时由完成回到制作中。 |
| 版本归属 | 当前、历史、已删除 | 故事家族序号及删除记录。已删除的最新版仍压住家族中的历史版。 |
| 替换草稿 | 无、打开 | 归属于当前版的未提交替换草稿。 |
| 控制 | 进行、读者暂停、停止 | `stories.generation_control`。 |
| 修订继续 | 无、等待继续 | `dag.continuation`。 |
| 在途收尾 | 无、有 | 暂停、停止、删除或版本取代时仍持有有效租约的任务。 |
| 读者决策 | 审片阻断、额度用尽、修订无变化、涉及手改、要求冲突或无法判断、重新编排 | 当前有效的审核结论及其目标、问题、修订记录。可同时命中多项。 |
| 故障 | 种类为步骤失败、内容拦截、中断、确认丢图。状态为待处理、恢复中 | 执行尝试日志、任务错误码与恢复回执。附节点、画幅、指纹和可选性。 |
| 图片可用性 | 正常、某幅待核对、暂不可核对 | 图片核对、媒体可读性和任务等待原因。确认丢失登记故障。 |
| 服务可用性 | 可用、未配置或只读、快照服务不可用、正在停止 | 当前运行配置、实时快照构造、进程状态。文字服务的登录、密钥、额度及限流错误按当前服务统一展示，保持文字任务排队。 |
| 活动 | 在途任务集合、排队、无可运行工作 | 当前世代的任务记录、尝试租约和读者授权。候选查找另需打开的选择界面。 |

推导使用当前故事的设置和产物、执行尝试、授权、控制、删除记录、候选界面的阅读需求、服务可用性与同一当前时间。计时、幅号和主要文案取最早领取的有效在途任务，同毫秒按任务标识排序。其他在途任务和故障各自保留。无在途时显示有效的修订继续、服务或控制门槛、当前阻断和排队状态。

具名约束：

- **阶段由产物推导**。暂停、服务不足和失败本身没有阶段转换。只有确认且必需产物齐备、可绘图、没有未解除必需故障时才算完成。故障保留在核对或尝试发生的版本。新修订按当前稿件推导待做工作。
- **当前版才有新工作**。历史或已删除的任务只可收尾。恢复删除后保持停止。替换草稿是独立选题，其取消不影响已提交版本。
- **修订等待与暂停独立**。有重做工作的新版等待继续。无需重做的新版沿用读者控制。完整作品确认重绘时授权所选竖图。选择按新首幅重绘其余画幅时，等首幅可用后再派发。横图独立运行。
- **一期许可绑定具体目标**。前置条件变化时须重新判定。相同回执按原请求重放。历史回执没有当前工作许可。

详情和书架的 `lifecycle.replacementDraft` 反映当前版是否有未提交的替换草稿。草稿打开、取消或提交时，书架增量版本也更新。写回与轮询使用同一投影。

`lifecycle.faults` 为故障区分 `kind`、`state`、`scope` 和 `targets`。目标列出节点、产物键和有对应画幅时从零开始的页号。横图帧保存的失败也属于可选故障，使用横图入口重试。审片已有结论但等待处理时见 `lifecycle.reviewAttention`。

详情、回包和书架通过同一读事务取故事、版本、任务、故障、替换草稿及阅读需求。图片核对和服务运行状态同时取自当前进程。`lifecycle.imageChecks` 用从 1 开始的幅号列出正在核对的原图、横图及因图片暂时不可读而等待的任务。等待任务的幅号指任务目标。确认丢图仍记录在 `faults`。

`lifecycle.actions` 列出按当前快照可用的选题、准备、修订、控制、故障恢复、审片和图片操作。选题操作带 `generation`，替换草稿的提交与取消另带 `parentId`。设置草稿的指纹包含两项要求各自的编辑标志。针对故障或审片结论的操作带 `faultId`，原图核对带从 1 开始的 `page`。删除清单独立提供 `canRestore`。操作提交时重新核对目标、编辑依据、令牌和授权。

已删除的自有作品在删除清单中给出 `lifecycle.version='deleted'`，照常报告原有阶段和在途收尾。确认后刷新建议单独用 `lifecycle.preparationRefresh` 表示，保留原有制作阶段。书架可以同时显示这类仍在执行的工作。

横图入口核对实际文件并发放操作令牌。书架和详情使用同一规则处理已保存的横图工作及已核对的文件，轮询时无需重新解码每幅图。

读者命令发生 409 冲突时，响应保留原有 `error`，能读取当前版时附带 `session`，供客户端刷新依据。`generationControl`、`awaitingContinue`、`productionState`、`superseded`、`snapshotUnavailable`、`faults` 和 `reviewIssues` 保留兼容值。新客户端优先读 `lifecycle` 对应的维度、故障及动作。
等待审片的命令行与界面使用同一份 `lifecycle.review`。候选查找的超时和拦截保留在当前轮次，超时共用中断额度。已保存的候选可继续选用。

需要读者处理的状态（修订等待继续、暂停或停止的未完成工作、待处理的必需故障）必须给出可点击的操作，或说明暂不可用的原因。状态文案提示点击某项操作时标明所需动作（`expects`），`lifecycle.actions` 没有该动作时改为显示原因（服务不可用、旧版本等）。操作位不得留空。`tests/production-reader-exits.test.mjs` 枚举各维度组合并渲染正式组件核对这条规则；新增需要读者处理的状态或维度时，同步扩展这份枚举。

## 事件规则

所有读者请求先通过格式与归属检查。可重放的请求按命令编号和原始输入命中既有回执，编号占用冲突返回 409。表中的守卫针对其余新请求，守卫不满足的剩余组合返回 409 与该行提示。服务阻断新付费工作时返回 503，队列保留原许可。无变化覆盖该维度的全部旧值。表中的“推导”按上一节重新计算阶段和活动。

| 事件 | 守卫 | 状态变化和授权 | 拒绝提示 |
| --- | --- | --- | --- |
| 查找或继续查找 | 尚未确认的当前选题与有效轮次 | 建立或继续本轮候选查找，只在阅读租约内付费 | 选题或查找已更新 |
| 打开替换草稿 | 当前版，替换依据有效 | 打开或返回同一草稿，只授权该草稿的选题操作 | 版本已更新 |
| 取消替换草稿 | 草稿归属当前操作的原版 | 删除该草稿；若已提交，返回家族当前版 | 草稿不属于这篇故事 |
| 选择选题 | 当前选题、有效世代及候选 | 进入准备，授权当前候选的准备节点 | 选题或候选已更新 |
| 提交替换选题 | 草稿归属、候选与提交依据有效 | 原版降为历史，新版进入准备 | 版本或选题已更新 |
| 恢复准备 | 当前准备中且已暂停或停止 | 解除控制门槛，沿用当前准备世代 | 当前没有已暂停的准备 |
| 重试准备 | 当前准备故障待处理且处于进行 | 仅恢复该故障对应步骤 | 准备问题已更新 |
| 重新准备 | 当前已确认版，原文已保存，无等待继续或进行中的重新准备 | 刷新建议并隔离旧准备世代。期间暂停发送生成任务，已付费结果仍可按原输入保存。保留已确认设置、分镜、成图和读者控制 | 等待或重试现有准备任务，或打开当前版本 |
| 开始制作 | 准备齐备、确认令牌有效 | 确认当前世代，授权制作 | 请先保存完整准备内容 |
| 确认前保存 | 当前、未确认、草稿令牌有效 | 更新当前草稿及受影响的准备内容 | 请刷新制作设置 |
| 确认后保存 | 当前、有效编辑依据及手改损失确认 | 等价提交记回执；有效修改建立新版并推导等待；展示改动留在原版 | 故事已更新或需要确认移除手改画幅 |
| 修改审核意见 | 当前、完整稿件与编辑依据有效 | 保存审核意见并按修订规则推导。打开阻断问题时同时提供当前问题 | 请刷新稿件与审核结果 |
| 继续制作 | 当前且等待继续 | 同时解除等待与暂停，授权新版工作 | 当前没有等待继续的修改 |
| 复制或复制为草稿 | 原文、完整分镜及该模式要求的审核依据齐备 | 独立副本；草稿保持暂停，本版放行的结论须在副本独立审核 | 原文、分镜或审核依据不完整 |
| 指定首幅原图 | 当前已完成、审核通过，换画风且上传有效图片 | 新版采用指定图，其他工作等待继续 | 请选已完成且审核通过的作品 |
| 暂停、恢复生成、停止 | 当前版本有制作或已请求的可选工作。恢复用于暂停或停止，旧客户端对等待继续的进行版重复恢复时接受幂等提交 | 控制改为暂停、进行、停止；保持修订等待 | 无可控制的制作，或版本已更新 |
| 删除 | 属于读者 | 标记删除且停止，已发送任务在原版收尾 | 故事不可用 |
| 恢复删除 | 存在该读者的删除记录 | 恢复可见且保持停止 | 故事不可用 |
| 继续自动修复 | 当前进行、无等待，对应修订额度用尽目标 | 对符合条件的当前问题追加一组额度 | 审片结果或修订额度已更新 |
| 仍然绘图 | 审片阻断或审核调用失败，稿件齐备，故障号匹配，审核未在运行 | 放行所有当前待定或阻断的结论。需要时确认标题与结语，解除审核故障，保留控制和等待 | 核对当前稿件、故障和标题结语 |
| 重试审核调用 | 当前审核故障待处理、进行且无等待 | 重试这项审核 | 当前审核问题已更新 |
| 重试故障 | 当前目标故障待处理、进行、无等待 | 只恢复被选中的实例或其批任务 | 问题已更新，请刷新后再操作 |
| 已完成作品确认重绘 | 当前、完成、已确认一个有效画幅 | 建立新版并授权所选竖图重绘。已有横图套图保存在原版；仅读者明确发起或重试横图时派发 | 当前无法只重绘这一幅 |
| 恢复确认丢失的画幅 | 当前、所选丢图故障尚未解除 | 文件可读则免费解除，否则只授权该幅 | 图片或恢复目标已更新 |
| 重新检查图片 | 当前且地址与画幅匹配 | 根据可读性更新图片状态或故障 | 图片已更新 |
| 生成或重试横图 | 当前完成版、横图操作令牌适用 | 标记或恢复相应的可选横图 | 竖版尚未完成或横图状态已更新 |
| 应用模型设置 | 当前确认版、当前设置可用 | 改写图片快照，下次绘图使用新设置 | 当前设置或版本不可用 |

### 系统事件

| 事件 | 守卫 | 结果 |
| --- | --- | --- |
| 领取 | 当前版、允许进行、无等待、有效任务世代与需求、硬输入匹配、目标可运行 | 同一事务写租约及恢复回执，否则保持排队或作废。 |
| 付费发送 | 当前有效租约，领取条件仍成立，实际服务及图片可用，快照、指纹与发送参数仍一致 | 开始付费调用。过时作废；控制、服务及暂时的图片问题退回排队。任务内没有发送许可的发送一律拒绝，任务按失败记录。 |
| 成功 | 有效租约、结果与派发输入对应 | 原版保存产物、用量及回执，解除该授权覆盖的故障。 |
| 失败或拦截 | 有效租约、工作仍属于派发世代 | 在任务事务中登记目标故障，等待相应恢复。 |
| 超时或中断 | 租约过期或本次执行中断 | 按有效意图和自动尝试上限恢复，否则保留中断故障。 |
| 服务不可用或恢复 | 实时状态改变 | 进入相应的服务维度。恢复后既有许可重新可用。 |
| 审片阻断、额度用尽、无进展或手改冲突 | 当前审核目标得出该结论 | 当前原因及目标进入读者决策维度，适用出口分别为放行、续授、修改描述或修改要求。 |
| 图片待核对或暂时无法核对 | 当前图片地址仍适用 | 核对尚未形成故障，不再次付费。 |
| 确认丢失或恢复可读 | 确认的图片与当前输入一致 | 登记或解除图片故障，重新推导完成。 |
| 迟到结果 | 已发送，之后提交暂停、停止、删除或替换 | 已付费用量和仍适用的结果只归派发时的版本。 |
| 服务重启或停止 | 进程状态或租约变化 | 停止领取，由租约、持久回执和原授权决定收尾与恢复。 |
| 并发变更 | 比较数据库提交顺序 | 先于领取不得领取；先于发送重新判定；发送后保留原版回执。编辑按版本条件提交，同编号按回执重放。 |

| 读者动作 | 公开入口 |
| --- | --- |
| 恢复历史版为当前版 | 不提供 |
| 按画幅身份重排 | 不提供 |
| 保存配文时要求同时生成画面描述 | 不提供 |
| 编辑单篇的绘图参数 | 不提供 |
| 按单个条目放行 | 不提供 |
| 请求全篇复核 | 不提供 |
| 允许自动修订覆盖手改 | 不提供 |

放行按各结论的当前硬输入分别绑定。在领取和发送时由引擎重算。审核记录保留读者选择，验收结果来自实际审核结论。 [生命周期验收用例](tests/test-production-lifecycle-state.md)
