# 故事制作生命周期

生命周期说明当前版本处于哪个阶段、读者能做什么、一次授权覆盖哪些工作。制作 DAG 负责产物的有效性、就绪、依赖和免费复用。旧文档先转换再用 DAG 判断，`visualReview` 仅供旧文档读取与转换。 [制作 DAG](story-production-dag.md)

## 状态和输入

| 维度 | 值 | 推导依据 |
| --- | --- | --- |
| 阶段 | 选题、准备、待制作确认、制作中、完成 | 选题与准备检查点、确认世代和 DAG 产物有效性。必需图片确认丢失时由完成回到制作中。 |
| 版本归属 | 当前、历史、已删除 | 故事家族序号及删除记录。已删除的最新版仍压住家族中的历史版。 |
| 替换草稿 | 无、打开 | 归属于当前版的未提交替换草稿。 |
| 控制 | 进行、读者暂停、停止 | `stories.generation_control`。 |
| 修订继续 | 无、等待继续 | `dag.continuation`。 |
| 在途收尾 | 无、有 | 暂停、停止、删除或版本取代时仍持有有效租约的任务。 |
| 读者决策 | 审片阻断、额度用尽、修订无变化、涉及手改、要求冲突或无法判断、重新编排 | 当前有效的审核结论及其目标、问题、修订记录。可同时命中多项。 |
| 故障 | 种类为步骤失败、内容拦截、中断、确认丢图。状态为待处理、恢复中、待匹配 | `reader_faults`、失败任务、任务错误码与恢复回执。附节点、画幅、指纹和可选性。 |
| 图片可用性 | 正常、某幅待核对、暂不可核对 | 图片核对、媒体可读性和任务等待原因。确认丢失登记故障。 |
| 服务可用性 | 可用、未配置或只读、快照服务不可用、正在停止 | 当前运行配置、实时快照构造、进程状态。密钥失效、额度不足及限流退避作为服务级状态保留，本期仍由步骤错误呈现。 |
| 活动 | 在途任务集合、排队、无可运行工作 | 当前世代的任务记录、尝试租约、有效的阅读需求和授权。 |

推导使用故事行与文档、任务与租约、故障、命令回执、删除记录、阅读需求租约、服务可用性和同一当前时间。计时、幅号和主要文案取最早领取的有效在途任务，同毫秒按任务标识排序。其他在途任务和故障各自保留。无在途时显示有效的修订继续、服务或控制门槛、当前阻断和排队状态。

具名约束：

- **阶段由产物推导**。暂停、服务不足和失败本身没有阶段转换。只有确认且必需产物齐备、可绘图、没有未解除必需故障时才算完成。待匹配故障阻止完成，允许其他画幅继续。
- **当前版才有新工作**。历史或已删除的任务只可收尾。恢复删除后保持停止。替换草稿是独立选题，其取消不影响已提交版本。
- **修订等待与暂停独立**。有重做工作的新版等待继续。无需重做的新版沿用读者控制。完整作品确认单幅重绘直接授权该幅及适用的横图。
- **一期许可绑定具体目标**。前置条件变化时须重新判定。相同回执按原请求重放。历史回执没有当前工作许可。

详情和书架的 `lifecycle.replacementDraft` 反映当前版是否有未提交的替换草稿。草稿打开、取消或提交时，书架增量版本也更新。写回与轮询使用同一投影。

`lifecycle.faults` 为故障区分 `kind`、`state`、`scope` 和 `targets`。目标列出节点、产物键和有对应画幅时从零开始的页号。横图帧保存的失败也属于可选故障，使用横图入口重试。审片已有结论但等待处理时见 `lifecycle.reviewAttention`。

详情、回包和书架通过同一读事务取故事、版本、任务、故障、替换草稿及阅读需求。图片核对和服务运行状态同时取自当前进程。`lifecycle.imageChecks` 用从 1 开始的幅号列出正在核对的原图、横图及因图片暂时不可读而等待的任务。等待任务的幅号指任务目标。确认丢图仍记录在 `faults`。

`lifecycle.actions` 列出快照中可执行的制作控制、恢复与审片动作。针对故障或审片结论的动作带 `faultId`，提交时重新核对目标和授权。

## 事件规则

所有读者请求先通过格式与归属检查。可重放的请求按命令编号和原始输入命中既有回执，编号占用冲突返回 409。表中的守卫针对其余新请求，守卫不满足的剩余组合返回 409 与该行提示。服务阻断新付费工作时返回 503，队列保留原许可。无变化覆盖该维度的全部旧值。表中的“推导”按上一节重新计算阶段和活动。

| 事件 | 守卫 | 状态变化和授权 | 拒绝提示 |
| --- | --- | --- | --- |
| 查找或继续查找 | 尚未确认的当前选题与有效轮次 | 建立或继续本轮候选查找，只在阅读租约内付费 | 选题或查找已更新 |
| 打开替换草稿 | 当前版，替换依据有效 | 打开或返回同一草稿，只授权该草稿的选题操作 | 版本已更新 |
| 取消替换草稿 | 草稿归属当前操作的原版 | 删除该草稿；若已提交，返回家族当前版 | 草稿不属于这篇故事 |
| 选择选题 | 当前选题、有效世代及候选 | 进入准备，授权当前候选的准备节点 | 选题或候选已更新 |
| 提交替换选题 | 草稿归属、候选与提交依据有效 | 原版降为历史，新版进入准备 | 版本或选题已更新 |
| 恢复准备 | 当前准备中且已暂停或停止 | 解除控制门槛，沿用当前准备世代 | 当前没有已暂停的准备 |
| 重试准备 | 当前准备故障待处理且处于进行 | 仅恢复该故障对应步骤 | 准备问题已更新 |
| 重新准备 | 已确认、重准备依据有效且当前 | 重开准备世代，旧世代任务失效 | 故事或版本已更新 |
| 开始制作 | 准备齐备、确认令牌有效 | 确认当前世代，授权制作 | 请先保存完整准备内容 |
| 确认前保存 | 当前、未确认、草稿令牌有效 | 更新当前草稿及受影响的准备内容 | 请刷新制作设置 |
| 确认后保存 | 当前、有效编辑依据及手改决定 | 等价提交记回执；有效修改建立新版并推导等待；展示改动留在原版 | 故事已更新或需要确认手改取舍 |
| 修改审核意见 | 当前、审核问题与编辑依据有效 | 保存审核意见并按修订规则推导 | 请刷新审核结果 |
| 继续制作 | 当前且等待继续 | 同时解除等待与暂停，授权新版工作 | 当前没有等待继续的修改 |
| 复制或复制为草稿 | 原文、完整分镜及该模式要求的审核依据齐备 | 独立副本；草稿保持暂停，跳过审核的许可不转移 | 原文、分镜或审核依据不完整 |
| 指定首幅原图 | 当前已完成、审核通过，换画风且上传有效图片 | 新版采用指定图，其他工作等待继续 | 请选已完成且审核通过的作品 |
| 暂停、恢复生成、停止 | 当前版本有制作或已请求的可选工作 | 控制改为暂停、进行、停止；保持修订等待 | 无可控制的制作，或版本已更新 |
| 切换后台 | 当前且满足后台操作条件 | 保留后台制作许可及其他维度 | 版本已更新 |
| 删除 | 属于读者 | 标记删除且停止，已发送任务在原版收尾 | 故事不可用 |
| 恢复删除 | 存在该读者的删除记录 | 恢复可见且保持停止 | 故事不可用 |
| 继续自动修复 | 当前进行、无等待，对应修订额度用尽目标 | 对符合条件的当前问题追加一组额度 | 审片结果或修订额度已更新 |
| 放行审片阻断 | 当前审片目标和结论指纹仍匹配 | 放行当前结果，控制状态原样保留 | 审片结果已更新 |
| 重试审核调用 | 当前审核故障待处理、进行且无等待 | 重试这项审核 | 当前审核问题已更新 |
| 跳过本次审核 | 当前审核调用失败、稿件齐备、故障号匹配，且暂停、停止或等待继续 | 保存读者选择的标题结语，记录覆盖的全部待定结论及绑定，解除该故障。保持控制和等待 | 请先暂停并保存完整稿件，确认当前标题与结语 |
| 重试故障 | 当前目标故障待处理、进行、无等待 | 只恢复被选中的实例或其批任务 | 问题已更新，请刷新后再操作 |
| 已完成作品确认重绘 | 当前、完成、已确认一个有效画幅 | 建立新版并授权所选画幅及其已有横图的更新 | 当前无法只重绘这一幅 |
| 恢复确认丢失的画幅 | 当前、所选丢图故障尚未解除 | 文件可读则免费解除，否则只授权该幅 | 图片或恢复目标已更新 |
| 重新检查图片 | 当前且地址与画幅匹配 | 根据可读性更新图片状态或故障 | 图片已更新 |
| 生成或重试横图 | 当前完成版、横图操作令牌适用 | 标记或恢复相应的可选横图 | 竖版尚未完成或横图状态已更新 |
| 应用模型设置 | 当前确认版、当前设置可用 | 改写模型快照，下次发送使用新设置 | 当前设置或版本不可用 |

### 系统事件

| 事件 | 守卫 | 结果 |
| --- | --- | --- |
| 领取 | 当前版、允许进行、无等待、有效任务世代与需求、硬输入匹配、目标可运行 | 同一事务写租约及恢复回执，否则保持排队或作废。 |
| 付费发送 | 当前有效租约，领取条件仍成立，实际服务及图片可用，快照、指纹与发送参数仍一致 | 开始付费调用。过时作废；控制、服务及暂时的图片问题退回排队。 |
| 成功 | 有效租约、结果与派发输入对应 | 原版保存产物、用量及回执，解除该授权覆盖的故障。 |
| 失败或拦截 | 有效租约、工作仍属于派发世代 | 在任务事务中登记目标故障，等待相应恢复。 |
| 超时或中断 | 租约过期或本次执行中断 | 按有效意图和自动尝试上限恢复，否则保留中断故障。 |
| 服务不可用或恢复 | 实时状态改变 | 进入相应的服务维度。恢复后既有许可重新可用。 |
| 审片阻断、额度用尽、无进展或手改冲突 | 当前审核目标得出该结论 | 当前原因及目标进入读者决策维度，适用出口分别为放行、续授、修改描述或修改要求。 |
| 图片待核对或暂时无法核对 | 当前图片地址仍适用 | 核对尚未形成故障，不再次付费。 |
| 确认丢失或恢复可读 | 确认的图片与当前输入一致 | 登记或解除图片故障，重新推导完成。 |
| 迟到结果 | 已发送，之后提交暂停、停止、删除或替换 | 已付费用量和仍适用的结果只归派发时的版本。 |
| 服务重启或停止 | 进程状态或租约变化 | 停止领取，由租约、持久回执和原授权决定收尾与恢复。 |
| 并发变更 | 比较数据库提交顺序 | 先于领取不得领取；先于发送重新判定；发送后保留原版回执。编辑按版本条件提交，同编号按回执重放。 |

| 读者动作 | 公开入口 |
| --- | --- |
| 恢复历史版为当前版 | 不提供 |
| 按画幅身份重排 | 不提供 |
| 保存配文时要求同时生成画面描述 | 不提供 |
| 编辑单篇的绘图参数 | 不提供 |
| 按单个条目放行 | 不提供 |
| 请求全篇复核 | 不提供 |
| 允许自动修订覆盖手改 | 不提供 |

跳过审核的绑定覆盖待定结论当前硬输入、全部验收条目登记、标题结语与适用的幅数核对。在领取和发送时由引擎重算。审核记录保留读者选择，普通审核的验收结果来自真实结论。 [生命周期验收用例](tests/test-production-lifecycle-state.md)
