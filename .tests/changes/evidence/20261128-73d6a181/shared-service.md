# CHANGES-C009、C010、C012 · 共享书库服务与在线备份

候选 `73d6a18149c351155945d302c2aad2e981de7117`。独立服务 QA 通过 [保障检查](../../../regression/evidence/20261128-73d6a181/assurance.md) 复用同一次运行，未另外重跑。正式 CLI、桌面控制通道和原生控制器使用隔离书库、受控模型和临时本机端口。

| 用例 | 观察结果 |
| --- | --- |
| CHANGES-C009 | 并发冷启动共用一个持锁进程，错误端点拒绝业务。CLI 和浏览器使用同一作品。保存、审片停点在继续前未绘图。已授权的全量制作停服后恢复，有限运行保留停点。 |
| CHANGES-C010 | 桌面接入保留进程、端口与阅读地址。拒绝或取消接入后原进程继续工作。常规停服等待，强停取消在途请求。终端正常结束与异常断开反映为不同状态。macOS 原生测试覆盖停止、重启和退出控制。 |
| CHANGES-C012 | CLI 和桌面在任务活动时均拒绝创建快照，候选目标目录未创建。空闲后两个入口快照均可校验，桌面快照可恢复到隔离目录。校验核对实际文件集并拒绝服务的私有归属或锁文件。 |

候选 macOS 安装包另补验同一进程和端口、CLI 快照和常规停服。真实窗口、系统托盘或快捷键未操作。[包内共享服务证据](packaged-shared-service.md)
