# SMOKE-C008、SMOKE-C009 · 撤销删除及退出重开

- 仅在 macOS arm64 候选 `676a5335` 的独立签核书库操作。《庄周梦蝶》第 2 版删除前出现确认，删除后书架为空，立即撤销后恢复为一张卡片。打开阅读停在第 3 幅，显示修订后的配文和原图。
- 从桌面控制台点「退出拾趣」。检查应用进程已经退出，本地端口拒绝连接。随后重开同一个应用，控制台仍显示原签核配置和已保存的 Codex 服务。启动服务后，书架仍是一张第 2 版卡片，打开第 3 幅仍显示新配文。
- 重启后逐幅从分镜列表打开五幅，每幅都加载了各自的图片，浏览器报告自然宽度均为 941 像素。界面未提示书库升级或恢复。只读检查数据库，退出前后均为 12 个生产任务，撤销后的删除记录数为 0。
- 测试结束从控制台恢复签核前的本机设置，读回默认书库目录、端口和 Codex 路径，退出应用。
