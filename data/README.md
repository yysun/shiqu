# 本地资料与运行数据

`library/` 是随代码版本化的只读书籍资料，共 24 本。原始下载件、逐书出处、版本范围、哈希与质量问题见 [catalog.json](library/catalog.json) 和 [来源说明](library/source-notices.md)。

只有 `library/` 与本说明纳入 Git。SQLite、媒体及其他运行文件仍由 `.gitignore` 排除。Docker 把书库复制到 `/app/data/library/`，运行数据挂载到 `/data`，两者独立。

重复候选、对照网页、下载检查和早期整理脚本已完整移到 `.data/research/book-source-research/2026-10-28/` 留存，不进入 Git，也不是应用的依赖。

只保留下载原件，正文可直接显示繁体。服务端在内存中剥离包装并添加引用编号，不转换正文用字；LLM 直接读取原文并输出简体故事。

全部 24 本均已接入本地全文选题与出处核对。长书按原文顺序分批读完再汇总候选，不做检索，不截断。分镜请求仅携带选中原文。

《山海经》采用维基文库18经HTML；《酉阳杂俎》采用识典同一JINANLIB02203转录的前20卷续10卷HTML与35个原字形PNG；《史记》采用维基文库《史記三家註》130卷HTML，十表保存实际单元格。三书具体古刻本信息未完整注明，不冒称已经确认同一古刻足本。《太平广记》为同一文渊阁本500卷TXT；《二刻拍案惊奇》统一采用漢川草廬转录的40卷TXT，第四十卷包含九折杂剧，不再使用独立HTML补卷。二刻所据刊本未注明、未收序/小引，不冒称已确认同一古刻本。

太平502件（500卷、提要、Readme）、二刻40件，以及新三书20/65/131件原件均逐件校验，以有序文件名和哈希清单的SHA256作为引用版本。运行时仅剥离包装并添加引用编号，不转换原字、不添标点或猜补误字。具体已知问题见catalog。原件中的“表略”等不补造。

HTML在内存中静态解析，不执行脚本，不另存MD/TXT。史记十表1581行、18555单元格（其中4203个空格位）保留，列号与跨度明确标为版式元数据；集解/索隱/正義保留身份。识典以公开SSR为原字基准，保留所有行型及小字，article的字形转换和省略不得覆盖原字。51处图片字的35个原PNG随书保存，阅读时原位置明确占位；另有2个原有□。史记有5个原有□。所有相关原段拒选，模型不猜字；原字形图只是书源资料，不是模型生成图片。具体限制见catalog与来源说明。
